# 성장 도감 — 로컬 읽기 전용 초안

본 게임과 연결되지 않은 설계 열람 화면입니다. 8계열의 96노드와 28조합 직업의 고유 특성, 합계 124성장 항목을 구분합니다. **124개 액티브 스킬이 아닙니다.** 계열의 단일 직업명 8개와 조합 직업명 28개는 제안이며 클릭해도 학습·장착·전직되지 않습니다.

```powershell
cd prototypes/mastery-catalog
python server.py                 # 구조 검사만, 서버 실행하지 않음
python -m unittest test_catalog  # 원본·결함 fixture·허용 경로 검사
python server.py --serve         # 127.0.0.1:8767, Ctrl-C로 해당 서버 종료
```

브라우저에서 `http://127.0.0.1:8767`을 엽니다. 포트 사용 중이면 다른 프로세스를 종료하지 말고 `--port 8768`처럼 비어 있는 포트를 지정합니다. 외부 인터페이스 바인딩 옵션은 없습니다. 사이트 배포·계정·네트워크 자료 다운로드·새 이미지가 필요하지 않습니다.

원본 `docs/content-drafts/research-expansion/mastery-nodes-v3.json`과 `hybrid-classes-v3.json`을 요청 시 읽습니다. 사본이나 별도 JSON을 관리하지 않습니다. 기존 `tools/validate_progression_drafts.py`를 읽기 전용으로 재사용하여 ID, 선행, 순환, 변형 대상, 조합 링크 등의 구조 오류가 있으면 HTTP 422로 화면을 차단합니다. 원본 경로·SHA256도 표시합니다. 서버는 페이지·JS·CSS·도감 API 네 경로만 제공하고 디렉터리 목록/파일 쓰기 API를 제공하지 않습니다.

UI는 시스템 한글 폰트와 기존 어두운 바탕/양피지 계열 색을 사용합니다. 계열을 선택하고 노드 버튼·선행조건 링크·변형 대상·조합 예시 액티브 링크로 이동합니다. 단계는 제안 트리 단계이며 캐릭터 레벨이 아닙니다. 수치, SP/장착 슬롯, 전직 가격, 재전직 정책은 확정하거나 실행하지 않습니다. 구조 검사 PASS는 효과의 밸런스나 전투 구현 PASS가 아닙니다.

현재 본 게임의 `inventory_menu.gd`에는 스킬 탭 이름이 있으나 이 도감 데이터를 읽는 연결은 없습니다. 본 게임의 SaveManager, GameState, 기존 런처 및 Godot 설정을 수정하지 않았습니다. Godot editor import가 필요 없는 별도 프로토타입이므로 편집기 종료 오류 해결을 주장하지 않습니다.

## 빌드 예시 확장

동일 API에서 `build-scenarios-v1.json` 원본도 읽고 기존 `validate_build_scenarios.py`를 재사용합니다. 12개 예시/60개 체크리스트, 두 계열·직업·조합 특성·학습 순서·액티브/변형·장비·약점·기본 우회·미정 SP·필요 구현을 열람할 수 있습니다. 노드 링크는 기존 상세로 이동합니다. 초반 지역은 시험 무대이며 초반에 모든 전직이 가능하다는 뜻이 아닙니다. 소스3 JSON의 경로/해시와 두 검증 결과가 표시되며 raw JSON을 제공하는 새 HTTP 경로는 없습니다. 빌드 검증은 기존 몬스터/아이템/월드/관련 초안도 읽지만 브라우저에 임의 파일을 노출하지 않습니다.
