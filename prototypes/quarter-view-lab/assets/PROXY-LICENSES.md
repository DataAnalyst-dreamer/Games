# 임시 배우와 글꼴 출처

이 폴더의 기사·슬라임은 핀의 새 디자인이나 64×96 신규 모션이 아니다. 기존 프로젝트에 포함된 Ninja Adventure 원본을 수정 없이 복사한 테스트 배우다. 원본 게임 파일은 변경하지 않았다.

| 샘플 파일 | 기존 Ninja Adventure 내부 경로 |
|---|---|
| proxy-knight.png | Actor/Character/Knight/SpriteSheet.png |
| proxy-slime.png | Actor/Monster/Slime/Slime.png |
| proxy-hit.wav | Audio/Sounds/Hit & Impact/Hit1.wav |
| proxy-swing.wav | Audio/Sounds/Whoosh & Slash/Slash.wav |

원본 위치: `game/assets/third_party/ninja_adventure/`. 원본 README의 제작자 표기는 Pixel-boy / AAA, 라이선스는 CC0. 배포된 전문을 `NinjaAdventure-LICENSE.txt`에 bytecopy했다. 본 샘플은 새로 인터넷에서 수집한 리소스를 사용하지 않는다.

Galmuri11.ttf는 `game/assets/fonts/galmuri/Galmuri11.ttf` 원본 bytecopy. 동봉 `Galmuri-LICENSE.txt`도 동일 원본의 라이선스 전문이다. 새 AI 배경의 출처/해상도/한계는 `ENVIRONMENT-SOURCE.md`에 분리했다.
