# 쿼터뷰 마을 입구 — 독립 플레이 샘플

## 2026-09-14 핀 정면 걷기 시험 적용

`Play-Quarter-View.cmd` 실행 후 아래 방향(S/↓)으로 이동하면 승인된 PixelLab 핀 모션을 볼 수 있다. 정면 대기는 입력 원본, 걷기는 생성 8장이다. 장비 포함 원본 66×96을 리사이즈 없이 사용한다. 실제 이동 23px당 한 프레임(속도 230px/s에서 10fps), 정지 시 원본으로 복귀한다. 정면 핀에 포함된 장비와 기존 무기가 중복 표시되지 않도록 했다.

다른 방향·공격·피격은 기존 임시 기사로 전환된다. 따라서 체형 전환이 보이며 완성된 다방향 캐릭터가 아니다. 전투 수치와 공격 판정은 변경하지 않았다. 아래의 기존 정지 디자인 비교 화면은 별도이며 이번 모션 적용과 무관하다. 추가 PixelLab 생성은 없었다.

기존 게임과 분리한 작은 2D 고정 시점 테스트다. AI 배경은 1672×941 원본을 FHD 논리 화면에 표시한다. 핀은 위의 정면 걷기 시험에만 적용됐고, 나머지 방향·전투 배우와 슬라임은 임시 배우다.

준비 완료 후 `Play-Quarter-View.cmd`를 더블클릭한다. PowerShell 7과 이미 작업 공간에 있는 Godot 4.4.1을 사용하며 설치/다운로드/실행 정책 변경을 하지 않는다. 오류가 나면 표시된 로그 경로를 공유하면 된다.

새 정지 디자인은 `Compare-Design.cmd`를 더블클릭하여 별도로 비교한다. 검·슬라임 **2개 후보만 유효(2/3)**하며, 핀은 투명 배경 추출 실패로 표시를 보류했다. Tab은 나란히/기존/후보, Z는 1배/2배 검수, B는 마을/어두운 판/밝은 판을 전환한다. Esc로 닫는다. 이 화면은 모션 테스트가 아니며 새 그림은 전투에 적용하지 않았다. 기본 `Play-Quarter-View.cmd`의 이동·공격·기존 임시 배우는 그대로다. 준비된 상태이므로 비교하려고 `-Prepare`를 다시 실행할 필요는 없다.

- WASD / 방향키: 이동, Space / 왼쪽 클릭: 공격
- R: 전투 처음부터, Esc: 이 샘플 종료
- F11: 독점 전체화면 ↔ 1280×720 창, H: 약한 화면 흔들림 (기본 꺼짐)
- L: 안내 HUD 한영 전환. 배우 표기는 한국어 고정이다.

PowerShell 7 검증 명령: `pwsh -NoProfile -File ./Run-Quarter-View.ps1 -VerifyOnly`. 소스가 바뀐 경우에만 `-Prepare`로 작은 프로젝트를 다시 준비한다. 준비의 GUI 단계와 `-CaptureOnly`는 검수용으로 잠시 실제 창을 열고 입력 검사/이미지 저장 후 스스로 종료한다. `-AttackOnly`는 실제 입력과 준비·접촉·회수 대표 이미지, 36프레임 PNG 및 로컬 HTML 재생기를 만든다. `-GripOnly`는 4방향 대기/접촉 8칸을 실제 배우 코드로 렌더한다. 검수에서만 카메라 또는 배우를 3배 확대하며 실제 플레이 카메라는 바꾸지 않는다. 재생기는 고정 60Hz 시뮬레이션의 관찰 자료이며 전체 모션 완성 판정은 아니다.

원본 `game/`, 기존 준비된 게임, 기존 세이브와 기존 실행기는 읽거나 수정하는 런타임 경로가 없다. 이 샘플에는 저장/불러오기 기능이 없다. 매 실행은 별도의 새 사용자 폴더를 쓰므로 설정이나 전투 진행을 이어받지 않는다. 엔진 로그와 캡처는 상위 `reviews/games-2026-09-12/runtime/quarter-view-*`에 보존된다.

나무 전경은 원본 배경의 육안 근사 다각형을 다시 그려 Y 정렬한다. 나무 줄기와 마을 입구 장애물은 거친 충돌이며 정밀한 타일맵/집 내부/건물 뒤 통과를 구현한 것은 아니다. 새 전투는 한 기사와 한 슬라임에 한정된다. 소스별 출처는 `assets/PROXY-LICENSES.md`, `assets/ENVIRONMENT-SOURCE.md`를 참고한다.
