# PRD — 《이슬란드 연대기 (Chronicles of Isleland)》

> BRD 1계층: 제품 정의. 하위 계층은 `02-requirements.md`(영역) → `03-features/`(기능·스펙).

## 1. 제품 정의

| 항목 | 내용 |
|---|---|
| 카테고리 | 엔터테인먼트 / 게임 |
| 한 줄 정의 | 귀여운 모험가가 되어 저주에 잠긴 중세 섬나라를 자유롭게 누비며 보물을 파밍하고 성장하는 16비트풍 도트 오픈월드 액션 RPG |
| 디바이스 | PC(Steam) 1차 / Nintendo Switch, 모바일(iOS·Android) 2차 |
| 사용자 역할 | 플레이어 (싱글플레이) |

## 2. 제품 목표
플레이어에게 '손맛 있는 전투 → 아이템 파밍 → 성장 → 더 깊은 탐험'의 중독적인 순환을 제공한다. 15분 단위의 짧은 보상 루프와 2~3시간 단위의 지역 공략 루프를 겹쳐, 메인 스토리 15~20시간·파밍 40시간 이상의 플레이 가치를 만든다. 아기자기한 도트 아트와 '귀엽지만 뭉클한' 서사로 하드코어 게이머가 아니어도 완주할 수 있는 캐주얼 지향 액션 RPG를 지향한다.

## 3. 타겟 사용자
10~30대의 도트 감성 게임 팬.
1. 스타듀밸리·젤다류의 탐험과 아기자기한 분위기를 좋아하지만 소울라이크급 난이도는 부담스러운 라이트~미들 게이머
2. 디아블로류 파밍의 '한 번 더' 루프를 좋아하는 파밍 게이머
3. Steam 인디게임을 큐레이션해서 구매하는 20~30대 PC 게이머(1차 타겟)와 Switch 휴대 플레이 선호층(2차 타겟)

## 4. 배경
16비트 도트 감성의 인디 게임 시장은 스타듀밸리·Eastward 등으로 검증된 안정적 수요가 있다. 그러나 도트 액션 RPG 중 '오픈월드 탐험 + 디아블로식 장비 파밍'을 캐주얼한 난이도로 결합한 타이틀은 드물다. 원작 기준 문서는 `docs/GDD-도트액션RPG-기획안.md`이며, 본 BRD는 그 GDD를 제품 요구사항 수준으로 구조화한 것이다.

## 5. 사용자 문제
파밍 RPG는 대부분 하드코어(디아블로·소울라이크)라서 라이트 유저는 진입이 어렵고, 반대로 아기자기한 도트 게임(농장·생활 시뮬)에는 전투의 손맛과 파밍의 도파민이 부족하다. '귀여운 그래픽 + 부담 없는 난이도 + 제대로 된 파밍·성장 루프'를 동시에 주는 게임이 없어, 두 취향을 모두 가진 유저는 갈증을 느낀다.

## 6. 해결 방안
1. 히트스톱·넉백·화면 흔들림으로 손맛을 극대화한 실시간 전투를 '예고 동작 0.5초 + 회피 무적'으로 읽고 피할 수 있게 설계해 난이도 부담을 낮춘다.
2. 6등급 장비 + 랜덤 옵션 + 재련으로 디아블로식 '한 번 더' 파밍 루프를 제공하되, 강화 실패로 장비가 파괴되지 않는 등 캐주얼 톤을 유지한다.
3. 5개 지방 심리스 오픈월드에 시야 랜드마크·정령 조각·보물 지도를 배치해 탐험 자체가 파밍이 되게 한다.
4. 4명의 개성 있는 SD 캐릭터와 3막 스토리로 회차 플레이를 유도한다.

## 7. 차별점
- 스타듀밸리류에는 없는 **액션 전투의 손맛과 장비 파밍 깊이**
- 디아블로류에는 없는 **아기자기한 톤과 낮은 진입장벽**
- 젤다류에는 없는 **랜덤 옵션 기반 파밍 리플레이성**
- 핵심: '전투력의 60%가 장비에서 나오는 파밍 중심 설계' × '실패 페널티 최소화(장비 파괴 없음, 사망 시 골드 5%·상한 있음)'

## 8. 대표 사용자 시나리오
퇴근한 20대 직장인 유저가 Steam에서 게임을 켠다. 여관에서 저장을 불러와 게시판 일일 의뢰 3개를 수주하고, 워프 비석으로 안개숲에 이동해 15분간 사냥하며 의뢰를 완료한다. 정예 몬스터가 드랍한 파란 등급 활의 랜덤 옵션을 확인하고 착용 중인 활과 비교 후 교체, 남은 장비는 분해해 강화석을 얻는다. 대장간에서 +7 강화에 성공하고, 상승한 전투력으로 미뤄뒀던 설산 지역 던전에 도전해 보스를 잡고 전설 등급 드랍 연출을 본다. 여관에서 저장하고 접속을 종료하기까지 약 1시간 — 다음 플레이의 목표(설산 월드 보스)가 자연스럽게 남는다.

## 9. 성공 지표 (KPI)

| 단계 | 지표 | 목표 |
|---|---|---|
| M1 게이트 | 외부 테스터 10인 타격감 평가 | 4/5 이상 |
| 데모 | 플레이 세션 중앙값 | 45분 이상 |
| 데모 | 튜토리얼 완주율 | 85% 이상 |
| 데모 | 첫 던전(첫 보스) 도달률 | 70% 이상 |
| 출시 | Steam 리뷰 긍정 비율 | 85% 이상 (매우 긍정적) |
| 출시 | 메인 스토리 완주율 | 40% 이상 |
| 출시 | 완주 후 파밍 잔존(엔드 콘텐츠 진입률) | 30% 이상 |
| 출시 | 환불률 | 8% 미만 |

| 플랫폼 이식(Switch·모바일) 입력·성능 차이 | UI를 게임패드 우선으로 설계, 내부 렌더 640×360 고정으로 성능 하한 보장 |
