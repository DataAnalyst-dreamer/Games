# 《이슬란드 연대기》 BRD 인덱스

기획 문서의 전체 구조와 위치. GDD(비전·시스템 서술)를 기초로 BRD(제품 요구사항 수준의 구조화 문서)를 구축했으며, **모든 기획 문서는 이 저장소에서 관리한다.**

## 문서 구조

| 계층 | 내용 | 위치 |
|---|---|---|
| GDD (원본 기획) | 게임 비전·시스템 전체 서술 — **v1.1** (결정 사항 반영) | `docs/GDD-도트액션RPG-기획안.md` |
| BRD 1. PRD | 제품 정의·목표·타겟·문제/해결·차별점·시나리오·KPI·리스크 | `docs/brd/01-PRD.md` |
| BRD 2. 영역 | 8개 능력 영역과 완료 판정 기준 | `docs/brd/02-requirements.md` |
| BRD 3. 기능·스펙 | 영역별 28개 기능 + 상세 스펙 (슬롯 8종) | `docs/brd/03-features/01~08` |
| BRD 4. 의사결정 | 미결정 사항 37건의 확정 기록 | `docs/brd/04-decisions.md` |
| 유저 플로우 | 핵심 플로우 7종 (mermaid + 분기/이탈/실패) | `docs/brd/user-flows.md` |
| 와이어프레임 | 주요 화면 10종 (ASCII 배치도 + 요소/인터랙션/상태) | `docs/ui/wireframes.md` |

## 영역(R1~R8) 구성

1. **캐릭터 & 성장** — 선택·커스터마이즈 / 레벨·스탯 / 스킬 트리 / 수평 성장
2. **전투 시스템** — 기본 액션(스펙 3) / 타격감 연출 / 스태미나 / 속성 상성 / 고유 메커니즘
3. **아이템 & 파밍** — 드랍·등급 판정 / 인벤토리·장착 / 강화·재련·분해(스펙 3) / 제작 / 파밍 소스
4. **오픈월드 & 탐험** — 심리스 이동 / 지도·핀·워프 / 낮밤·날씨 / 지역 기믹 / 탈것
5. **퀘스트 & 내러티브** — 메인 3막 / 사이드·의뢰 / NPC 호감도 / 대화·로컬라이징
6. **몬스터 & 보스** — 필드 AI / 지역 보스 3페이즈 / 정예·월드 보스
7. **게임 UI & 접근성** — HUD / 메뉴·인벤토리 / 설정·접근성
8. **시스템 기반** — 세이브/로드 / 사망·부활 / 골드 경제 / 데이터 파이프라인

## 문서 간 관계

```
GDD v1.1 (무엇을 만드나 — 서술)
   ↓ 구조화
PRD → 영역(R) → 기능(F) → 스펙(S)     ← 04-decisions.md 가 미결정 사항을 확정
   ↓ 행동 관점                ↓ 화면 관점
user-flows.md            wireframes.md
```

## 진행 원칙

- 기획 변경은 `04-decisions.md`에 결정 ID를 추가하고 GDD·해당 기능 문서를 함께 갱신한다.
- 밸런스 수치는 전부 `game/data/` 테이블로, 텍스트는 로컬라이징 key로, UI는 `docs/ui/wireframes.md` 기준으로.
- 구현 순서는 GDD 13장 로드맵(M1 전투 손맛 → M2 파밍 루프 → M3 오픈월드)을 따른다.
- 에이전트 팀 역할 분담은 `.claude/agents/README.md` 참조.
