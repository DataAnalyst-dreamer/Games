# 《이슬란드 연대기》 BRD 인덱스

기획 문서의 전체 구조와 위치를 정리한 인덱스. GDD를 기초로 BRD(제품 요구사항 수준의 구조화 문서)를 구축했다.

## 문서 구조

| 계층 | 내용 | 위치 |
|---|---|---|
| GDD (원본 기획) | 게임 비전·시스템 전체 서술 | `docs/GDD-도트액션RPG-기획안.md` |
| BRD 본체 | PRD → 영역(8) → 기능(28) → 상세 스펙(6+) | Manyfast 프로젝트 「이슬란드 연대기 (도트 오픈월드 액션 RPG)」 |
| 유저 플로우 | 핵심 플로우 7종 (mermaid + 분기/이탈/실패 케이스) | `docs/brd/user-flows.md` |
| 기본 와이어프레임 | 주요 화면 10종 (ASCII 배치도 + 요소/인터랙션/상태) | `docs/ui/wireframes.md` |

## BRD 영역(Requirements) 구성

1. **캐릭터 & 성장** — 선택·커스터마이즈 / 레벨·스탯 / 스킬 트리 / 수평 성장
2. **전투 시스템** — 기본 액션 / 타격감 연출 / 스태미나 / 속성 상성 / 고유 메커니즘
3. **아이템 & 파밍** — 드랍·등급 판정 / 인벤토리·장착 / 강화·재련·분해 / 제작 / 파밍 소스
4. **오픈월드 & 탐험** — 심리스 이동 / 지도·핀·워프 / 낮밤·날씨 / 지역 기믹 / 탈것
5. **퀘스트 & 내러티브** — 메인 3막 / 사이드·의뢰 / NPC 호감도 / 대화·로컬라이징
6. **몬스터 & 보스** — 필드 AI / 지역 보스 3페이즈 / 정예·월드 보스
7. **게임 UI & 접근성** — HUD / 메뉴·인벤토리 / 설정·접근성
8. **시스템 기반** — 세이브/로드 / 사망·부활 / 골드 경제 / 데이터 파이프라인

## 미결정 사항 (의사결정 대기)

Manyfast의 각 기능 슬롯에 **선택지형 질문**으로 등록되어 있어 앱에서 클릭으로 확정할 수 있다.
주요 항목: 강화 +7~+10 성공률, 재련 결과 확정 방식(즉시 vs 택1), 인벤토리 칸 수, 가방 가득 시 드랍 처리,
저스트 가드 판정 프레임, 진 엔딩 조건, 일일 의뢰 갱신 시각, 사망 골드 손실 상한, 게임 내 하루 길이,
모바일 조작 방식, 반지 중복 장착, 호감도 단계 구조 등.

추가로 유저 플로우 검토 중 발견된 GDD 공백은 `docs/brd/user-flows.md` 부록(G1~G9),
와이어프레임 검토 중 발견된 사항은 `docs/ui/wireframes.md` 부록 B에 정리되어 있다.
특히 **G7(골드 손실 상한)**과 **G9(장비 내구도 시스템 존재 여부 — 브람의 '필드 수리' 전제)**는
GDD 수정이 필요할 수 있는 우선 검토 항목이다.

## 진행 원칙

- 구현 전 해당 기능의 Manyfast 슬롯 질문이 해소되어야 한다(미해소 시 recommendedOption 기준으로 임시 진행하고 기록).
- 밸런스 수치는 전부 `game/data/` 테이블로, 텍스트는 로컬라이징 key로, UI는 `docs/ui/wireframes.md` 기준으로.
- 에이전트 팀 역할 분담은 `.claude/agents/README.md` 참조.
