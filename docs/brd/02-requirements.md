# 영역별 요구사항 (Requirements)

> BRD 2계층: 제품을 구성하는 8개 능력 영역. 각 영역의 세부 기능은 `03-features/` 아래 같은 번호의 문서 참조.
> 완료 판정 기준(AC)은 해당 영역이 "동작한다"고 말할 수 있는 최소 조건이다.

## R1. 캐릭터 & 성장 — 중요도 높음
플레이어가 4종의 플레이어블 캐릭터 중 하나를 선택·커스터마이즈하고, 레벨·스탯·스킬 트리와 요리·도감·정령 조각 같은 수평 성장 축으로 캐릭터를 키우는 영역. 전투 조작 자체는 R2, 장비를 통한 성장은 R3이 담당한다.

- [ ] 4종 캐릭터를 선택할 수 있고 각자 다른 주무기·고유 메커니즘·스킬 트리가 동작한다
- [ ] 레벨 1~50 경험치 곡선과 스탯 5종(STR/DEX/INT/VIT/LUK) 수동 분배가 동작한다
- [ ] 스킬 트리 3계열×6단계에서 포인트 투자·리셋이 가능하다
- [ ] 요리 버프·도감 보너스·정령 조각(4개=최대치 +1칸)이 실제 스탯에 반영된다

## R2. 전투 시스템 — 중요도 높음
실시간 액션 전투 전반 — 기본 공격·강공격·구르기·가드·스킬·퀵슬롯 조작, 히트스톱과 넉백 등 손맛 연출, 스태미나 관리, 5속성 상성과 상태이상. 몬스터 측 AI·패턴은 R6이 담당한다.

- [ ] 공격 3타 콤보·강공격·구르기(무적 0.3초)·저스트 가드가 키보드/패드 양쪽에서 동작한다
- [ ] 히트스톱 0.05~0.1초, 넉백, 카메라 셰이크가 적용되고 옵션으로 강도 조절이 가능하다
- [ ] 모든 적 공격에 최소 0.5초의 예고 동작이 있다
- [ ] 5속성 상성 적중 시 1.5배 데미지와 상태이상이 발동한다

## R3. 아이템 & 파밍 — 중요도 높음
6등급 아이템 체계, 랜덤 옵션, 드랍 판정, 인벤토리·장비 8슬롯, 강화·제작·재련·분해, 그리고 정예 몬스터·월드 보스·보물 지도 등 파밍 콘텐츠 소스를 다루는 게임의 핵심 재미 영역.

- [ ] 6등급(일반~유물) 장비가 등급별 옵션 개수 규칙대로 드랍되고 LUK이 희귀 등급 가중치에 곱연산된다
- [ ] 강화 +0~+10(+6까지 무실패, 이후 실패 시 강화석만 소실)과 재련(옵션 1줄 재굴림, 3회 제한, 신·구 택1)이 동작한다
- [ ] 장비 8슬롯 + 치장 3슬롯이 분리되어 있고 장비 비교 툴팁이 표시된다
- [ ] 7종 파밍 소스(필드/정예/미니 던전/지역 던전/월드 보스/채집/보물 지도)가 각자의 리스폰 규칙대로 보상을 준다

## R4. 오픈월드 & 탐험 — 중요도 높음
5개 지방 + 항구도시가 로딩 없이 이어지는 심리스 오픈월드와 탐험 경험 — 시야 랜드마크, 안개 지도, 워프 비석, 낮/밤·날씨, 지역 기믹, 탈것, 정령 조각·보물 지도 배치.

- [ ] 지역 간 이동이 로딩 없이 이어지고(청크 스트리밍) 던전 진입 시에만 로딩이 발생한다
- [ ] 방문 지역만 밝혀지는 안개 지도와 수동 핀 8종, 워프 비석 이동이 동작한다
- [ ] 낮/밤·날씨에 따라 출현 몬스터·상인·낚시 어종이 달라진다
- [ ] 지역별 기믹(추위 게이지, 안개 미로, 모래폭풍, 용암)이 각 지역에서 동작한다

## R5. 퀘스트 & 내러티브 — 중요도 중간
메인 스토리 3막과 엔딩 분기, 지역 사이드 퀘스트, 게시판 일일 의뢰, NPC 호감도, 대사·플레이버 텍스트. 모든 텍스트는 한/영 로컬라이징 key 구조를 전제로 한다.

- [ ] 메인 퀘스트 3막이 순차 진행되고 2막의 다섯 성물은 자유 순서로 공략 가능하다
- [ ] 진 엔딩/노멀 엔딩 분기 조건('마녀의 기억' 5개)이 동작한다
- [ ] 게시판 일일 의뢰 3개가 매일 갱신되고 완료·보상 지급이 동작한다
- [ ] NPC 호감도 3단계 상승에 따라 상점 할인·코스튬·미니 스토리가 개방된다

## R6. 몬스터 & 보스 — 중요도 높음
약 60종의 몬스터(지역당 일반 8~10종 + 정예 2종 + 지역 보스 1종)와 월드 보스의 행동 패턴·AI·스폰 규칙, 보스 3페이즈 구성, 도감 등록.

- [ ] 모든 몬스터가 상태머신 기반으로 동작하고 공격 전 예고 동작을 가진다
- [ ] 지역 보스 5종이 3페이즈(학습→강화→발악)로 진행되고 지역 기믹을 전투에 재활용한다
- [ ] 정예 몬스터가 30분, 월드 보스가 3일(실제 플레이 시간) 주기로 리스폰된다
- [ ] 처치한 몬스터가 도감에 등록된다

## R7. 게임 UI & 접근성 — 중요도 중간
HUD, 인벤토리·장비, 스킬 트리, 월드맵, 대장간, 상점·게시판, 도감, 설정 등 모든 게임 UI와 접근성 옵션. 모든 UI는 게임패드만으로 완주 가능해야 하며 `docs/ui/wireframes.md`를 기준으로 한다.

- [ ] 모든 UI 화면을 게임패드만으로 조작·완주할 수 있다
- [ ] 장비 비교 툴팁이 현재 장비 대비 증감 화살표를 표시한다
- [ ] 색약 모드에서 등급이 색상 없이도 아이콘으로 구분된다
- [ ] 화면 흔들림 강도·폰트 크기 조절이 즉시 반영된다

## R8. 시스템 기반 — 중요도 높음
세이브/로드, 사망/부활 규칙, 골드 경제 순환, 청크 스트리밍 성능 규칙, 데이터 테이블 주도 설계, 로컬라이징 체계.

- [ ] 여관 저장과 오토세이브(지역 이동·보스 클리어 시)가 슬롯 3개에서 동작한다
- [ ] 사망 시 골드 5%(상한 레벨×50) 손실 후 마지막 비석 부활이 동작한다
- [ ] 모든 밸런스 수치가 `game/data/` 테이블에서 로드되며 코드에 하드코딩이 없다
- [ ] 플레이어 주변 3×3 청크만 활성화되고 비활성 청크의 몬스터 AI가 정지한다
