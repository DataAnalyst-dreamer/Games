# R1. 캐릭터 & 성장 — 기능 명세

> 상위: `../02-requirements.md` R1 / 결정 참조: `../04-decisions.md`
> 슬롯 범례 — 전제: 사전 조건 · 트리거: 시작 조건 · 동작: 시스템/사용자 행동 · 결과: 완료 후 상태 · 예외: 실패·경계 처리 · 표시: 화면 표현 · 규칙: 제약 · 데이터: 테이블/저장

## F1-1. 캐릭터 선택·커스터마이즈 — 높음
새 게임 시작 시 4종 캐릭터(핀·리라·모리·브람) 중 1명을 선택하고 외형(헤어 컬러 8종, 피부톤 6종)을 커스터마이즈한다. 캐릭터별 시작 무기·고유 메커니즘·스킬 트리가 달라진다. 코스튬 장착은 치장 슬롯(F3-2)이 담당한다.

**근거**: 캐릭터별 플레이 스타일 차이로 회차 플레이를 유도하는 PRD 해결 방안 ④의 진입점.

| 슬롯 | 내용 |
|---|---|
| 전제 | 빈 세이브 슬롯이 선택되어 있어야 한다 |
| 트리거 | 타이틀에서 새 게임 선택 → 캐릭터 선택 화면 진입 |
| 동작 | 4종 캐릭터를 좌우 탐색하며 컨셉·주무기·고유 메커니즘 설명 확인. 헤어 8종·피부톤 6종 선택 시 도트 미리보기에 즉시 반영 |
| 결과 | 확정 시 세이브 데이터에 기록되고 오프닝(1막 도입) 재생 |
| 예외 | 시작 후 외형 변경은 **마을 미용실 NPC에서 골드 지불로 가능** (D-01). 직업(캐릭터) 변경은 불가 |
| 표시 | SD 도트 스프라이트 유휴 애니메이션 재생, 캐릭터 정보 텍스트 |
| 규칙 | 캐릭터 선택은 세이브 슬롯당 1회 |
| 데이터 | `game/data/characters.json` (시작 무기, 기본 스탯, 스킬 트리 ID, 고유 메커니즘 수치) |

## F1-2. 레벨·스탯 성장 — 높음
몬스터 처치·퀘스트·최초 발견으로 경험치를 얻어 레벨 1~50까지 성장. 레벨업 시 자동 상승분 + 스킬 포인트 1 + 스탯 포인트 3(STR/DEX/INT/VIT/LUK 수동 분배).

**근거**: 파밍과 별개로 플레이 시간 자체가 성장으로 이어지는 수직 성장 축. LUK으로 파밍 효율을 선택하는 빌드 다양성의 기반.

| 슬롯 | 내용 |
|---|---|
| 트리거 | 몬스터 처치, 퀘스트 완료, 최초 발견(지역·던전·요리 등) 시 경험치 획득 |
| 동작 | 누적 경험치가 요구치 도달 시 즉시 레벨업. HP/스태미나/공격력 소폭 자동 상승 + SP 1 + 스탯 3. 캐릭터 화면에서 스탯 분배 |
| 결과 | 레벨업 팡파레·이펙트, HP 전량 회복 |
| 예외 | 스탯 재분배는 **사제에게 골드 지불로 전체 리셋** (D-02), 비용 레벨×100G (D-03) |
| 표시 | HUD HP바 근처에 레벨과 경험치 게이지 |
| 규칙 | 최대 레벨 50. 경험치 곡선 단조증가. LUK→드랍률·크리, VIT→HP·방어, DEX→공속·회피 효율·원거리, INT→마법·쿨감, STR→물리·무기 요구치 |
| 데이터 | `game/data/exp_curve.csv`, `game/data/stats.json` |

## F1-3. 스킬 트리 — 높음
캐릭터별 3계열 × 6단계 트리(단계당 노드 2개, 계열당 12노드)에 SP를 투자해 액티브(슬롯 2개 장착)·패시브를 획득. 사제에게 골드로 전체 리셋 가능.

**근거**: 레벨업 보상을 선택의 재미로 전환하고, 저렴한 리셋으로 빌드 실험을 장려.

| 슬롯 | 내용 |
|---|---|
| 전제 | SP 1 이상 보유. 각 단계는 **이전 단계에 1포인트 이상 투자 시 개방, 레벨 제한 없음** (D-33) |
| 트리거 | 메뉴 스킬 탭 |
| 동작 | 계열 3개 중 원하는 노드에 포인트 투자. 액티브 스킬을 슬롯 1·2(Q/E, L/R)에 장착 |
| 결과 | 즉시 효과 적용, 슬롯 장착 스킬은 HUD에 아이콘·쿨타임 표시 |
| 예외 | 리셋은 마을 사제에서만, 전체 포인트 환불. 비용 **레벨×100 골드** (D-03) |
| 표시 | 계열별 6단계 세로 트리, 미개방 노드는 잠금 아이콘 |
| 규칙 | SP는 레벨업당 1 + 던전 보물·업적 추가. 캐릭터별 계열 구성 고유(핀=검술/수호/기사도) |
| 데이터 | `game/data/skills.json` (효과, 쿨타임, 스태미나 소모, 선행 조건) |

## F1-4. 수평 성장 (요리·도감·정령 조각) — 중간
레벨과 별개의 세 가지 영구 성장 축: 채집 재료로 버프 음식을 만드는 요리, 수집 완성률에 따른 도감 보너스, 4개 모으면 HP/스태미나 최대치 +1칸인 정령 조각.

**근거**: 탐험 자체를 영구 성장으로 보상해 오픈월드 탐험 동기를 만드는 GDD 5.3의 핵심 설계.

| 슬롯 | 내용 |
|---|---|
| 전제 | 요리는 모닥불 또는 마을 주방에서, 레시피와 재료 보유 시 |
| 트리거 | 정령 조각: 필드 숨겨진 조각과 상호작용. 도감: 처치·획득·제작·낚시 시 자동 등록 |
| 동작 | 요리 → 퀵슬롯에서 사용(예: 매콤 버섯구이 = 10분 공격력 +8%). 정령 조각 4개 → HP 또는 스태미나 +1칸 선택 |
| 결과 | 도감 카테고리(몬스터/아이템/요리/낚시)별 **25/50/75/100% 달성 시** 영구 보너스 (D-35) |
| 예외 | 버프 음식은 **서로 다른 효과 2개까지 동시 적용**, 같은 효과는 대체 (D-04) |
| 표시 | 적용 중 버프는 HUD HP바 아래 아이콘+남은 시간. 정령 조각 획득 시 n/4 표시 |
| 규칙 | 정령 조각 총량·지역별 분포는 레벨 설계 문서에서 관리, 수집 여부 세이브에 영구 기록 |
| 데이터 | `game/data/recipes.json`, `game/data/codex_bonus.json` |
