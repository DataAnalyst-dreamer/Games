# R2. 전투 시스템 — 기능 명세

> 상위: `../02-requirements.md` R2 / 결정 참조: `../04-decisions.md`

---

## F2-1. 기본 전투 액션 — 높음
기본 공격 3타 콤보, 강공격/차지, 구르기(무적 0.3초), 가드·저스트 가드, 스킬 슬롯 2개, 퀵슬롯 4개. 키보드+마우스와 게임패드 모두 지원.

**근거**: 게임의 1순위 검증 대상인 핵심 조작감. M1 게이트의 직접 평가 대상.
**성공 기준**: 외부 테스터 10인 타격감 4/5 이상 (M1 게이트)

| 슬롯 | 내용 |
|---|---|
| 전제 | 이동 가능 상태(대화·메뉴·컷신 제외)에서만 입력 수신 |
| 트리거 | 공격/강공격/구르기/가드/스킬/퀵슬롯 입력 |
| 동작 | 3타 콤보(마지막 타 데미지·넉백 강화), 구르기 0.3초 무적·스태미나 소모, 적중 직전 **6프레임(0.1초)** 내 가드 입력 시 저스트 가드 (D-05) |
| 결과 | 모든 액션은 입력 후 3프레임 이내 시작, 입력 버퍼링으로 콤보 연결 |
| 예외 | 스태미나 부족 시 구르기·강공격·가드 미발동, 스태미나 바 깜박임. **모바일: 가상 스틱+버튼**, 컨트롤러 연결 시 자동 전환 (D-06) |
| 표시 | 공격 범위·방향은 휘두름 이펙트로 즉시 인지 |
| 규칙 | 60fps 기준 정의, delta 기반 구현. 키 리매핑 지원 |
| 데이터 | `game/data/combat.json` (배율, 스태미나 소모, 무적 시간, 판정 프레임) |

### 스펙 S2-1a. 3타 콤보 공격
- **트리거**: 공격 입력 시 1타. 각 타 종료 전 입력 버퍼 구간 내 재입력 시 다음 타.
- **동작**: 각 타는 짧은 전진 이동 포함, 방향 입력으로 미세 조정. 3타 후 짧은 후딜레이.
- **결과**: 적중 시 타격감 연출 패키지(F2-2) 호출.
- **예외**: 콤보 중 피격·구르기 시 콤보 초기화.
- **표시**: 캐릭터별 공격 애니메이션 4~6프레임, 휘두름 이펙트.
- **규칙**: 타별 배율·버퍼 구간은 `combat.json`.

### 스펙 S2-1b. 구르기 회피
- **전제**: 스태미나 ≥ 소모량.
- **트리거**: 회피 입력 시 현재 방향(미입력 시 바라보는 방향)으로 즉시 발동.
- **동작**: 시작 직후 0.3초 무적, 이동 거리 고정. 공격·스킬 애니메이션의 특정 프레임 이후 구르기로 캔슬 가능.
- **결과**: 종료 후 즉시 입력 수신(경직 최소화). 리라는 헌터 마크 활성화.
- **예외**: 스태미나 부족 시 미발동 + 바 빨간색 깜박임.
- **표시**: 무적 구간 잔상 이펙트.
- **규칙**: DEX가 소모량 경감.

### 스펙 S2-1c. 가드·저스트 가드
- **전제**: 방패 또는 가드 가능 무기 장착.
- **트리거**: 가드 버튼 유지.
- **동작**: 일반 가드 = 피해 대폭 경감 + 스태미나 소모. 저스트 가드(적중 직전 6프레임) = 피해 0, 스태미나 소모 없음, 전용 이펙트·사운드.
- **결과**: 저스트 성공 시 적 경직, 핀은 '패리 슬래시' 입력 윈도우 개방.
- **예외**: 가드 불가 공격(잡기 등)은 붉은 예고 이펙트로 구분.
- **표시**: 가드 자세 스프라이트.
- **규칙**: 경감율·판정 프레임은 `combat.json`.

## F2-2. 타격감 연출 — 높음
히트스톱(0.05~0.1초), 피격 넉백, 카메라 셰이크, 도트 타격 이펙트, 데미지 숫자. 모든 강도는 접근성 옵션으로 조절.

**근거**: PRD 핵심 가치 '손맛'의 직접 구현. M1 게이트 합격 여부를 가르는 기능.
**성공 기준**: 타격감 4/5 이상 (M1 게이트)

| 슬롯 | 내용 |
|---|---|
| 트리거 | 공격이 대상에 적중하는 순간 |
| 동작 | 양측 0.05~0.1초 히트스톱, 피격자 넉백 + 흰색 플래시 + 점멸, 강공격·크리티컬 시 카메라 셰이크 추가 |
| 결과 | 학습 없이 '맞았다/맞혔다'를 눈과 손으로 즉시 인지 |
| 예외 | 흔들림 0% 설정 시 셰이크 완전 off. **데미지 숫자 기본 켜짐**, 옵션에서 끔 (D-07) |
| 표시 | 도트 스타일 이펙트 4~6프레임, 속성별 색상 |
| 규칙 | 수치는 `combat.json` × 접근성 배율 |

## F2-3. 스태미나 시스템 — 높음
구르기·강공격·가드가 공유하는 자원. 시간 경과로 회복, 정령 조각·장비 옵션으로 최대치·회복속도 성장.

**근거**: 난이도가 반응 속도가 아닌 자원 관리에서 나오게 해 라이트 유저도 전략으로 극복 가능(GDD 4.2).

| 슬롯 | 내용 |
|---|---|
| 트리거 | 구르기·강공격·가드(유지 중 피격 포함) 시 소모 |
| 동작 | 소모 중단 후 짧은 딜레이 뒤 초당 일정량 회복. DEX가 회피 효율 상승 |
| 결과 | 완전 고갈 시 향후 딜레이 페널티로 무분별한 연타 억제 |
| 예외 | 부족 시 해당 액션 미발동 + 빨간 깜박임 |
| 표시 | HP바 바로 아래 녹색 게이지 |
| 규칙 | 소모량·회복속도·고갈 페널티는 `combat.json` |

## F2-4. 속성 상성·상태이상 — 중간
화·수·뇌·풍·성 5속성. 상성 적중 시 1.5배 + 상태이상(화상/빙결/감전 등). 플레이어 속성은 무기·부적으로 결정되어 파밍과 직결.

**근거**: 속성 세팅이 파밍 목표가 되어 '장비를 바꾸는 이유'를 만든다.

| 슬롯 | 내용 |
|---|---|
| 전제 | 속성 무기·부적 또는 속성 스킬 |
| 트리거 | 상성 약점 속성 대상 적중 |
| 동작 | 1.5배 데미지 + 상태이상 게이지 누적, 가득 차면 발동(화상=지속 피해, 빙결=정지, 감전=행동 중단) |
| 결과 | 전용 이펙트·효과음 |
| 예외 | **상성 구조: 순환형 화→풍→뇌→수→화, 성(聖)은 마물 계열 특효** (D-08) |
| 표시 | 도감 등록 후 몬스터 HP바 옆 약점 아이콘, 상태이상 중 아이콘 깜박임 |
| 규칙 | 보스는 상태이상 저항치 보유 |
| 데이터 | `game/data/elements.json` (상성표, 상태이상 파라미터) |

## F2-5. 캐릭터 고유 메커니즘 — 중간
핀 '패리 슬래시'(저스트 가드 반격), 리라 '헌터 마크'(구르기 직후 자동 조준), 모리 융합 마법(속성 2종 연속 적중), 브람 3단 차지 + 필드 간이 제작.

**근거**: 캐릭터 선택이 외형이 아닌 플레이 스타일 차이가 되게 하는 GDD 3장의 핵심.

| 슬롯 | 내용 |
|---|---|
| 전제 | 해당 캐릭터로 플레이 중 |
| 트리거 | 핀: 저스트 가드 성공 → 반격 윈도우. 리라: 구르기 종료 후 일정 시간 내 사격 → 최근접 적 자동 조준. 모리: 서로 다른 속성 스킬 2개 연속 적중 → 융합 발동 가능. 브람: 공격 유지 → 3단 차지 |
| 동작 | 각 메커니즘은 캐릭터별 스킬 트리와 연동해 강화 |
| 결과 | 발동 순간 전용 이펙트·사운드 |
| 예외 | 모리 융합 마법은 **주요 6종만 구현** (D-09). 브람의 필드 능력은 **간이 제작**(소모품·재료 가공)이며 내구도 시스템은 없음 (D-31) |
| 표시 | 발동 가능 상태(마크 유효 시간, 융합 준비, 차지 단계)는 캐릭터 주변 이펙트 |
| 규칙 | 수치는 `characters.json` 캐릭터별 항목 |
