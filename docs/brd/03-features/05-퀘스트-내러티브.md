## F5-1. 메인 스토리 진행 — 높음
3막(출항 → 다섯 성물 → 재의 마녀) 메인 퀘스트 라인. 2막 성물은 자유 순서, 3막 최종 던전에서 진/노멀 엔딩 분기. 대사·연출은 `docs/story/` 시나리오가 소유.

**근거**: 파밍 루프에 방향성과 감정적 보상을 부여하는 베이스라인 콘텐츠. 엔딩 분기로 회차 유도.
**성공 기준**: 메인 스토리 완주율 40% 이상 (PRD KPI)

| 슬롯 | 내용 |
|---|---|
| 전제 | 3막은 다섯 성물 모두 회수 시 개방 |
| 트리거 | 전 단계 완료 시 다음 단계 자동 등록 |
| 동작 | 퀘스트 로그에서 목표 확인, 추적 설정 시 월드맵·미니맵에 목표 아이콘 |
| 결과 | 각 막 완료 시 오토세이브 + 회차 요소 기록(2막: 성물 개수별 안전지대 확장, 3막: 엔딩 분기) |
| 예외 | **진 엔딩 = 숨겨진 수집물 '마녀의 기억' 5개 전부 수집 후 최종전 진입** (D-19). 1막 순서: 섬 도착 → **첫 마을 습격 = 튜토리얼 전투** → 마을 확보 (D-26) |
| 표시 | 퀘스트 로그 메인/사이드/의뢰 탭, 추적 퀘스트는 HUD 한 줄 |
| 규칙 | 메인 퀘스트 포기 불가. 2막 성물 지역은 권장 전투력 표시하되 입장 제한 없음 |
| 데이터 | `quests/` JSON, `dialogue/` 로컬라이징 key |

## F5-2. 사이드 퀘스트·게시판 의뢰 — 중간
지역 NPC 사이드 퀘스트(지역 스토리·보상 중심)와 마을 게시판 일일 의뢰(매일 3개, 토벌·납품형, 가벼운 반복 파밍 목표).

**근거**: 15분 코어 루프에 '오늘의 할 일'을 제공하는 리텐션 장치.

| 슬롯 | 내용 |
|---|---|
| 전제 | 일일 의뢰는 마을 게시판 상호작용 |
| 트리거 | 게시판 → 오늘의 의뢰 3개 쪽지 카드 |
| 동작 | 수락 시 퀘스트 로그 의뢰 탭 추가, 진행도 실시간 갱신. 완료 후 게시판/NPC에 보고 |
| 결과 | 골드+재료 기본, 주간 누적(7회) 보너스 |
| 예외 | 갱신 시각 **현실(로컬) 자정** (D-20). 갱신 시 **완료·미보고분은 24시간 보고 유예, 미완료분 소멸** (D-21) |
| 표시 | wireframes 화면 8 |
| 규칙 | 동시 보유 3개, 포기 시 당일 재수주 불가. 목표는 레벨 구간 풀에서 추첨 |
| 데이터 | `quests/daily_pool.json` |

## F5-3. NPC 호감도 — 낮음
주요 NPC(지역당 3~4명)에게 선물·퀘스트로 호감도 상승 → 단계별 상점 할인·전용 코스튬·미니 스토리 개방. 연애 시스템은 범위 외.

**근거**: 마을을 기능 모음이 아닌 애착 대상으로 만들어 귀환 동기와 장기 리텐션 형성.

| 슬롯 | 내용 |
|---|---|
| 트리거 | 선물 메뉴로 아이템 전달 또는 관련 퀘스트 완료 |
| 동작 | NPC별 선호/비선호 아이템, 선호 시 상승폭 증가 |
| 결과 | 단계 도달 시 전용 보상 순차 개방 |
| 예외 | **3단계: 지인 → 친구 → 단짝** (D-22) |
| 표시 | 대화창에 호감도 단계 아이콘 |
| 규칙 | 선물 하루 1회 |
| 데이터 | `npcs.json` |

## F5-4. 대화·로컬라이징 시스템 — 중간
말풍선 + 도트 표정 이모지 대화 시스템. 모든 텍스트를 key 기반(`npc_fin_greet_01`)으로 관리해 한/영 전환. 긴 컷신 없이 짧은 대사와 연출로 감정 전달.

**근거**: 한/영 동시 출시와 '짧고 위트 있는 대사' 톤을 기술적으로 보장.

| 슬롯 | 내용 |
|---|---|
| 트리거 | NPC 근처 상호작용 키 |
| 동작 | 타이핑 효과 출력, 버튼으로 즉시 완성·다음. 선택지 2~3개 세로 목록 |
| 결과 | NPC 머리 위 표정 이모지 도트 연출 |
| 예외 | key 누락 시 key 문자열 그대로 표시 + QA 로그(묵음 크래시 금지) |
| 표시 | 화면 하단 고정이 아닌 NPC 머리 위 말풍선 기본 |
| 규칙 | 사용자 노출 텍스트 하드코딩 금지. 한글 픽셀 폰트 가독성 검증 |
| 데이터 | `dialogue/ko.json`, `dialogue/en.json` |
