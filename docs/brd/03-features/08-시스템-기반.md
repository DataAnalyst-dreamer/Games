# R8. 시스템 기반 — 기능 명세

> 상위: `../02-requirements.md` R8 / 결정 참조: `../04-decisions.md`

---

## F8-1. 세이브/로드 — 높음
여관 수동 저장 + 오토세이브(지역 이동·보스 클리어·워프·메인 퀘스트 단계 완료)를 슬롯 3개에 기록. 암호화 로컬 JSON.

**근거**: 진행 손실은 캐주얼 유저 이탈 1순위 요인이므로 안전망 이중화.

| 슬롯 | 내용 |
|---|---|
| 트리거 | 수동: 여관 카운터. 자동: 지역 경계 통과, 보스 클리어, 워프, 메인 단계 완료 |
| 동작 | 수동/오토세이브는 슬롯 내 별도 파일로 서로 덮어쓰지 않음. 로드 시 최신 선택 가능 |
| 결과 | 저장 완료 시 우하단 아이콘 1초 |
| 예외 | 파일 손상 시 경고 + 백업(직전 저장본) 복구 시도 |
| 표시 | 슬롯 카드: 캐릭터·레벨·플레이타임·현재 지역·저장 시각 |
| 규칙 | 사망 직후·전투 중·보스방 저장 불가. 포맷 버전 기록으로 마이그레이션 지원. **여관 저장 무료** (D-29) |
| 데이터 | 암호화 JSON 슬롯 3 + 슬롯별 오토세이브 + `settings.json` |

## F8-2. 사망·부활 규칙 — 높음
HP 0 시 골드 손실 후 마지막 상호작용 비석에서 부활. 아이템·경험치 손실 없음. 보스전은 F6-2의 별도 규칙.

**근거**: 실패 페널티 최소화는 PRD 차별점의 한 축이며, 사망 비용은 경제 안정화 Sink로도 기능.

| 슬롯 | 내용 |
|---|---|
| 트리거 | HP 0 → 사망 연출 → 부활 화면 |
| 동작 | 보유 골드 **5% 차감, 상한 레벨×50 골드** (D-25) → 마지막 비석에서 HP 전량 부활 |
| 결과 | 부활 후 사망 지점 방향 미니맵 표시(재도전 유도) |
| 예외 | 튜토리얼(첫 마을 도착 전) 구간 골드 페널티 없음. 보스전 사망은 골드 손실 없음 (D-23) |
| 표시 | 잃은 골드액 표시, 장엄하지 않은 가벼운 톤 |
| 규칙 | 부활 비석 = 워프 비석 동일 오브젝트 (D-28) |

## F8-3. 골드 경제 순환 — 중간
수급처(몬스터·퀘스트·장비 판매·보물)와 소비처(상점·강화·재련·스킬/스탯 리셋·여관 숙박·미용실·사망 페널티)의 균형 관리. 개별 가격은 R3, 총량 목표와 집계 구조는 이 기능이 소유.

**근거**: 경제 균형이 무너지면 파밍 게임의 장기 리텐션이 함께 무너지므로 출시 전부터 관리 구조 필요.

| 슬롯 | 내용 |
|---|---|
| 동작 | 레벨 구간(10/20/30/40/50)별 기대 보유 골드와 소비 이벤트 비용을 밸런스 문서로 정의, 전 가격 테이블이 참조 |
| 결과 | 골드 획득/소비 이벤트를 로컬 통계로 집계(옵트인) → 얼리액세스 보정 |
| 규칙 | 상점 판매가 = 구매가의 25%. 상점 구매 장비는 항상 동급 파밍보다 기대값 낮음(파밍 우위). 여관 숙박(버프+시간 스킵) 유료, 저장 무료 (D-29) |
| 데이터 | `economy.json` |

## F8-4. 데이터 테이블 파이프라인 — 높음
모든 밸런스 수치를 `game/data/` JSON/CSV로 관리, 부팅 시 로드·스키마 검증. 기획자가 코드 수정 없이 밸런싱.

**근거**: PRD 리스크 ④(파밍 밸런스 붕괴) 대응책. 수치 전수 테이블화가 얼리액세스 보정의 전제.

| 슬롯 | 내용 |
|---|---|
| 트리거 | 부팅 시 전체 테이블 로드 + 검증 |
| 동작 | 검증: 참조 ID 존재, 드랍 확률 합계, 경험치 곡선 단조증가, 필수 필드. 검증 스크립트 `tools/qa/`는 CI 실행 가능 |
| 결과 | 개발 빌드는 검증 실패 시 에러 중단, 릴리즈 빌드는 기본값 대체 + 경고 로그 |
| 규칙 | 코드 하드코딩 금지. 임시 상수는 `game/scripts/tuning.gd` 한 파일에만 |
| 데이터 | 테이블 목록·스키마는 `docs/specs/data_tables.md` |
