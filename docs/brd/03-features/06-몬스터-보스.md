## F6-1. 필드 몬스터 AI — 높음
지역당 8~10종, 총 약 50종의 일반 몬스터가 상태머신(대기/순찰/추적/공격/피격/사망)으로 행동. 모든 공격에 0.5초 이상 예고, 종별 고유 패턴. 신규 몬스터는 데이터+씬 상속만으로 추가.

**근거**: '읽고 피하는 전투' 원칙의 적 측 구현. 60종 물량을 감당하는 확장 구조 필수.

| 슬롯 | 내용 |
|---|---|
| 트리거 | 인지 범위 진입 시 추적, 일정 거리 이탈 시 복귀 |
| 동작 | 예고(점멸 또는 바닥 장판) → 공격 → 후딜레이 리듬. 지역당 최소 1종은 우선순위 타겟 학습 패턴(고블린 정찰병 증원 호출 등) |
| 결과 | 처치 시 드랍 판정·경험치·도감 등록 |
| 예외 | 비활성 청크 진입 시 AI 정지·상태 보존. 도주 시 HP 서서히 회복 후 원위치 복귀 |
| 표시 | HP바는 피격 시에만 머리 위, 일정 시간 후 숨김 |
| 규칙 | 골격 재사용·팔레트 스왑 변종 지원 |
| 데이터 | `monsters.json` (스탯, 속성, 패턴 ID, 드랍 테이블 참조, 도감 메타) |

## F6-2. 지역 보스전 (3페이즈) — 높음
지역 보스 5종(슬라임 킹, 올드바크, 서리 늑대왕, 모래거상 골렘, 재의 드래곤)과 최종 보스의 3페이즈 전투. 지역 기믹을 전투 기제로 재활용. 첫 클리어 확정 보상과 재도전 파밍 보상 구분.

**근거**: 지역 공략 루프(2~3시간)의 정점이자 파밍 최상위 보상처.
**성공 기준**: 첫 던전(첫 보스) 도달률 70% 이상 (PRD KPI)

| 슬롯 | 내용 |
|---|---|
| 전제 | 보스방 앞 체크포인트 비석 필수 (D-27) |
| 트리거 | 보스방 진입 → 입구 봉쇄 → 등장 연출 → 전투 |
| 동작 | P1(HP 100~66%) 기본 패턴 학습 / P2(66~33%) 패턴 강화 + 지역 기믹 결합 / P3(33~0%) 발악 + 연출 강화 |
| 결과 | 첫 클리어: 성물 파편 + 전설 1점 확정. 재도전 자유, 보상은 파밍 테이블 |
| 예외 | **보스전 사망 시 골드 손실 없이 보스방 앞 비석에서 즉시 재도전, 보스 HP 초기화** (D-23). **던전 내 퍼즐·개방 문 등 진행도 유지** (D-27) |
| 표시 | 화면 하단 고정 보스 HP바 + 이름, 페이즈 전환 연출 |
| 규칙 | 보스 상태이상 저항치 보유 |
| 데이터 | `bosses.json` (페이즈 임계값, 패턴 파라미터) |

## F6-3. 정예·월드 보스 — 중간
지역당 정예 2종(필드 네임드, 30분 리스폰, 강화 변종 + 고유 이름 + 강화 패턴 1개)과 월드 보스 1종(3일 리스폰, 전설 확정).

**근거**: 필드 파밍의 중간 목표와 장기 리텐션 목표(월드 보스 주기) 제공.

| 슬롯 | 내용 |
|---|---|
| 트리거 | 정예: 스폰 존 내 랜덤 위치. 월드 보스: 지역별 고정 제단 |
| 동작 | 정예: 스탯 배율 강화 + 패턴 1개. 월드 보스: 보스급 패턴을 필드에서, 주변 몬스터 난입 가능 |
| 결과 | 정예: 희귀~영웅 + 도면 확률. 월드 보스: 전설 1점 확정 |
| 예외 | 월드 보스 대기 중 제단에 남은 시간 표시. 타이머는 실제 플레이 시간 기준 (D-15) |
| 표시 | 정예는 이름표 + 등급 테두리 전용 HP바 |
| 데이터 | `farming_sources.json` |
