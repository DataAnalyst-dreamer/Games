## F4-1. 심리스 월드 이동 — 높음
5개 지방 + 항구도시(약 400×400타일×5)를 로딩 없이 이동. 64×64 타일 청크 스트리밍, 플레이어 주변 3×3 청크만 활성화. 던전 진입 시에만 별도 씬 로딩.

**근거**: '이음새 없는 하나의 세계' 경험의 기술적 기반이자 Switch·모바일 성능 하한을 지키는 제약.

| 슬롯 | 내용 |
|---|---|
| 트리거 | 청크 경계 통과 시 주변 청크 비동기 로드, 먼 청크 언로드 |
| 동작 | 활성 청크에서만 몬스터 AI·물리·파티클 동작. 비활성 청크 상태는 요약 데이터로 보존 |
| 결과 | 지역 경계 통과 시 지역명 배너 + BGM 크로스페이드 |
| 예외 | 로딩이 이동을 못 따라오는 예외 상황은 짧은 페이드로 가림(목표 발생률 0%) |
| 규칙 | 지역 간 로딩 화면 없음, 던전·건물 내부만 로딩 허용. 도보 횡단 약 25분 규모 유지 |
| 데이터 | `game/maps/` 청크 파일, `game/data/spawns/` 청크 메타 |

## F4-2. 월드맵·핀·워프 — 높음
방문 지역만 밝혀지는 안개 지도, 수동 핀 8종, 활성화한 워프 비석 간 빠른 이동. 지방별 탐험률과 보스 리스폰 상태 표시.

**근거**: 파밍 반복 동선 단축(워프) + 미탐험 영역 시각화(안개)로 탐험 동기 부여.

| 슬롯 | 내용 |
|---|---|
| 전제 | 워프는 한 번 이상 상호작용한 비석만 목적지 선택 가능 |
| 트리거 | 메뉴 또는 단축키로 월드맵 |
| 동작 | 커서 탐색, 핀 찍기/제거, 활성 비석 선택 → 확인 → 즉시 이동 |
| 결과 | 도착 비석 앞에서 재개 + 오토세이브 |
| 예외 | 전투 중 워프 불가. **워프 비용 무료** (D-16). **부활 비석 = 워프 비석 동일 오브젝트** (D-28) |
| 표시 | 미방문 영역 양피지 안개, 방문 시 반경 영구 공개. 지방별 탐험률 %, 보스 리스폰 아이콘. 던전 내부는 **미니맵만 제공(방문 구역), 층 지도 없음** (D-36) |
| 규칙 | 핀 8종 = **보물/몬스터/채집/낚시/NPC/던전/위험/메모**, 최대 **30개** (D-34). 미니맵·월드맵 탐험 데이터 공유 |
| 데이터 | 탐험 비트맵, 핀 목록, 활성 비석 → 세이브 |

## F4-3. 낮/밤·날씨 시스템 — 중간
게임 내 시간 순환과 지역별 날씨(맑음/비/눈/모래폭풍). 시간대·날씨에 따라 출현 몬스터·유령 상인·낚시 어종·채집물이 달라진다.

**근거**: 같은 지역을 시간대별로 다시 방문할 이유를 만들어 파밍 동선 다양성 확보.

| 슬롯 | 내용 |
|---|---|
| 트리거 | 시간은 실시간으로 흐르며 여관 숙박으로 아침까지 스킵 |
| 동작 | 밤: 야간 몬스터·유령 상인. 비: 전용 어종. 날씨는 지역별 확률 테이블 |
| 결과 | 조건부 콘텐츠는 도감에 출현 조건 힌트 |
| 예외 | **하루 = 현실 24분 (1분 = 게임 1시간)** (D-17) |
| 표시 | 시간대별 컬러 그레이딩(새벽/낮/노을/밤), 밤 광원 조명 |
| 규칙 | 날씨는 지역 정체성(설산=눈, 사막=모래폭풍) |
| 데이터 | `weather.json`, `spawns/` |

## F4-4. 지역 기믹 — 중간
설산 추위 게이지(방한복·모닥불), 안개숲 안개 미로(랜턴), 사막 온도차·유사, 화산 용암·내화 장비. 기믹은 지역 보스전에도 재활용.

**근거**: 지역마다 '다르게 노는 법'을 제공하고 기믹 대응 장비가 파밍 목표가 된다.

| 슬롯 | 내용 |
|---|---|
| 전제 | 대응 수단(방한복·랜턴·내화 장비)은 진입 전 파밍·구매로 확보 가능 |
| 트리거 | 기믹 영역 진입 시 게이지/효과 활성화 |
| 동작 | 추위: 게이지 차면 HP 서서히 감소, 모닥불·온천에서 회복. 안개: 랜턴 없이는 시야 축소·길 잃음. 용암: 접촉 시 지속 피해, 내화 장비로 경감 |
| 결과 | 극복 시 숨겨진 보상 지역 도달 |
| 예외 | **기믹 피해로도 사망 가능** (HP 1 정지 규칙 미적용) (D-18) |
| 표시 | 기믹 게이지는 HUD HP바 아래 전용 게이지 (wireframes 화면 3) |
| 데이터 | `region_hazards.json` |

## F4-5. 탈것 (통통 조랑말) — 낮음
중반부 퀘스트로 획득, 호출 탑승 시 이동속도 +60%. 탑승 중 전투 불가, 피격 시 자동 하차.

**근거**: 넓은 월드의 이동 피로를 줄이면서 아기자기한 톤을 강화.

| 슬롯 | 내용 |
|---|---|
| 전제 | 획득 퀘스트 완료. 실내·던전 호출 불가 |
| 트리거 | 호출 단축키 → 화면 밖에서 달려와 탑승 |
| 동작 | 이속 +60%, 채집·전투 입력 비활성 |
| 결과 | 피격 시 자동 하차, 재호출 가능(탈것 사망 없음) |
| 예외 | 수중·용암 지형에서 강제 해제 |
| 표시 | 통통 튀는 전용 애니메이션 + 방울 소리 |
| 데이터 | `mount.json` |
