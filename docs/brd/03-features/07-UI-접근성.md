> 상위: `../02-requirements.md` R7 / 결정 참조: `../04-decisions.md` / 화면 레이아웃: `../../ui/wireframes.md`

## F7-1. 인게임 HUD — 높음
좌상단 HP·스태미나 바와 버프 아이콘, 하단 퀵슬롯 4칸, 우상단 토글형 미니맵, 획득 로그, 추적 퀘스트 한 줄, 보스전 전용 HP바. (wireframes 화면 3)

**근거**: 도트 필드의 몰입감을 해치지 않으면서 전투·파밍에 필요한 정보만 제공하는 GDD 11장 'HUD 최소화' 원칙.

| 슬롯 | 내용 |
|---|---|
| 트리거 | 필드 진입 시 표시, 컷신·대화 중 자동 숨김 |
| 동작 | 미니맵 단축키 토글, 확대/축소 2단계. 퀵슬롯 숫자키/십자키 즉시 사용 |
| 결과 | 획득 로그 좌하단 3초 표시 |
| 예외 | HP 25% 이하 HP바 점멸 + 화면 가장자리 빨간 비네트(색약 모드에서 패턴 대체) |
| 표시 | 양피지·나무 프레임, 640×360 내부 해상도 기준 |
| 규칙 | HUD 요소 개별 표시/숨김 옵션 |

## F7-2. 메뉴·인벤토리 UI — 높음
인벤토리·장비·스킬·도감·퀘스트 로그를 탭으로 묶은 전체화면 메뉴. 격자 인벤토리, 등급 필터(LT/RT), 자동 정렬, 비교 툴팁, 캐릭터 미리보기. 게임패드만으로 완주 가능. (wireframes 화면 4·5·9)

**근거**: 파밍 게임에서 가장 오래 머무는 화면이 인벤토리이므로 비교·정리 편의성이 파밍 체감을 좌우.

| 슬롯 | 내용 |
|---|---|
| 트리거 | 전체 메뉴: **Tab / 패드 −(Select)**. 일시정지·설정: **Esc / 패드 +(Start)** — 분리 (D-37) |
| 동작 | LB/RB 탭 전환, LT/RT 등급 필터 순환. 장비 선택 시 비교 툴팁 자동 표시 |
| 결과 | 장착·사용·분해 지정 등 모든 조작이 메뉴 내 완결. **메뉴 오픈 중 게임 일시정지** (D-24) |
| 예외 | 파괴적 액션(분해 확정)은 Y 홀드로만 실행 |
| 표시 | 하단 입력 가이드 바 상시(패드/키보드 자동 전환) |
| 규칙 | 색·폰트는 `game/ui/theme.tres` 단일 테마. 등급 6색은 색약 대체 아이콘(●▲◆★✦❖) 항상 병기 |

## F7-3. 설정·접근성 옵션 — 중간
그래픽·사운드·조작·접근성 설정. 접근성: 화면 흔들림 4단계, 색약 모드(등급 아이콘 대체), 폰트 크기 2단계, 키 리매핑. 모든 변경 즉시 반영. (wireframes 화면 10)

**근거**: 라이트 유저까지 포용하는 캐주얼 포지셔닝의 실질적 구현, 콘솔 심사 대응.

| 슬롯 | 내용 |
|---|---|
| 트리거 | 일시정지 메뉴 → 설정 → 카테고리 탭 |
| 동작 | 슬라이더/토글 조절, 즉시 미리보기(흔들림 샘플, 색약 팔레트) |
| 결과 | 세이브 슬롯과 무관하게 계정 단위 저장 |
| 예외 | 카테고리별 기본값 복원 버튼 |
| 규칙 | 흔들림 0% 시 모든 카메라 셰이크·진동 완전 off. 데미지 숫자 토글(기본 켜짐, D-07). `settings.json` 별도 저장 |
