## F3-1. 아이템 드랍·등급 판정 — 높음
몬스터 처치·상자 개봉 시 드랍 테이블로 아이템 생성. 6등급 판정(LUK 곱연산), 등급별 랜덤 옵션 부여(옵션 풀 20종), 등급별 드랍 연출.

**근거**: '같은 철검이라도 옵션이 다르다'는 파밍 리플레이성의 핵심.
**성공 기준**: 완주 후 파밍 잔존율 30% 이상 (PRD KPI)

| 슬롯 | 내용 |
|---|---|
| 트리거 | 몬스터 사망, 보물상자 개봉, 보물 지도 발굴 |
| 동작 | 드랍 테이블(몬스터ID → 아이템ID/확률/수량범위) 추첨. 장비는 등급 판정 시 LUK을 희귀 이상 가중치에 곱연산. 옵션 개수: 고급 1 / 희귀 2 / 영웅 3+고유 효과 / 전설 고유 스킬 / 유물 세트 효과 |
| 결과 | 등급별 드랍 사운드·연출, 전설 이상은 전용 효과음 + 빛기둥 |
| 예외 | 인벤토리 가득 시 **마을 우편함으로 자동 전송, 보관 기한 없음** (D-10) |
| 표시 | 필드 드랍은 등급 색상 외곽선, 접근 시 자동 획득. 획득 로그 좌하단 3초 |
| 규칙 | 확률·가중치·옵션 풀 전부 테이블. 보스 첫 클리어는 전설 또는 성물 파편 확정 |
| 데이터 | `items.json`, `drop_tables.json`, `affixes.json` |

## F3-2. 인벤토리·장비 장착 — 높음
격자형 인벤토리 + 장비 8슬롯(무기/보조/투구/갑옷/신발/반지×2/부적) + 치장 3슬롯(모자/의상/백팩). 자동 정렬·등급 필터·장비 비교.

**근거**: 파밍 루프의 '정리·장착' 단계. 비교가 쉬워야 파밍 보상이 체감된다.

| 슬롯 | 내용 |
|---|---|
| 트리거 | 메뉴 인벤토리 탭 (캐릭터 미리보기 동반) |
| 동작 | 장비 선택 시 현재 장착 대비 증감 화살표 표시, 확정 시 즉시 장착. 등급 필터·자동 정렬·일괄 분해 지정 |
| 결과 | 장착 즉시 스탯 재계산, 무기·모자·의상은 필드 외형 반영 |
| 예외 | 기본 **40칸, 백팩 아이템으로 최대 80칸** (D-11). **동일 반지 2개 중복 장착 허용** (D-12) |
| 표시 | 비교 툴팁 나란히 표시, 상승 녹색 ▲ / 하락 빨간 ▼. 레이아웃은 `wireframes.md` 화면 4 |
| 규칙 | 치장 슬롯은 스탯 0. 무거운 무기는 STR 요구치 필요 |
| 데이터 | `items.json` 장비 필드 |

## F3-3. 강화·재련·분해 — 높음
대장간에서 +0~+10 강화(+6까지 무실패, 이후 실패 시 강화석만 소실), 옵션 1줄 재굴림 재련(장비당 3회), 미사용 장비 분해. 장비 파괴는 어떤 경우에도 없음.

**근거**: 파밍한 장비를 더 파고드는 재미 + 인벤토리 압박의 보상 전환 + '실패 페널티 최소화' 차별점.

| 슬롯 | 내용 |
|---|---|
| 전제 | 마을 대장간 NPC (브람은 필드 간이 제작 일부 가능) |
| 트리거 | 대장간 UI 강화/재련/분해 탭 → 대상 장비 지정 |
| 동작 | 강화: 강화석+골드, +6까지 100%, **+7~+10 = 70/55/40/25%** (D-14), 실패 시 강화석만 소실·단계 유지, **실패 천장 없음** (D-32). 재련: 옵션 1줄 재굴림 후 **신·구 택1**, 확정 시 횟수 차감 (D-13). 분해: 등급이 높을수록 산출 증가 |
| 결과 | 성공/실패 전용 연출, 즉시 스탯 반영 |
| 예외 | 장착 중 장비는 분해 불가. 재련 3회 소진 시 버튼 비활성 |
| 표시 | 성공률·소모 재료·실패 결과 명시. 남은 재련 횟수 n/3 상시 표시 |
| 규칙 | 강화 수치는 기본 스탯에 단계별 배율 |
| 데이터 | `enhance.json` (성공률/비용/배율, 분해 산출표, 재련 비용표) |

### 스펙 S3-3a. 장비 강화(+0~+10)
- **전제**: 대상 장비 + 강화석·골드 보유.
- **트리거**: 강화 탭 → 장비 선택 → 강화 버튼.
- **동작**: 재료 차감 → 성공 판정 → 성공 시 단계 +1·스탯 상승 / 실패 시 강화석만 소실.
- **결과**: 성공(모루 타격→빛) / 실패(연기) 연출, 툴팁 즉시 반영.
- **예외**: +10은 버튼 비활성. 재료 부족 시 수량 빨간색 + 비활성.
- **표시**: 현재→다음 단계 스탯 변화, 성공률, 소모 재료 상시 표시.

### 스펙 S3-3b. 옵션 재련
- **전제**: 남은 재련 횟수 ≥ 1.
- **트리거**: 재련 탭 → 장비·옵션 1줄 선택 → 재련 버튼.
- **동작**: 동일 등급 옵션 풀에서 새로 추첨, 나머지 옵션 불변.
- **결과**: 신·구 옵션 나란히 제시 → 택1 확정 → 횟수 1 차감.
- **예외**: 횟수 0인 장비는 버튼 비활성 + 사유 툴팁.
- **표시**: 남은 횟수 n/3.
- **규칙**: 비용은 등급·횟수에 따라 증가.

### 스펙 S3-3c. 장비 분해
- **전제**: 장착 중·잠금(즐겨찾기) 장비 제외.
- **트리거**: 분해 탭 → 다수 선택 → Y 홀드 확정.
- **동작**: 장비 제거 → 등급별 산출표로 강화석·재료 지급.
- **결과**: 획득 합계 결과창.
- **예외**: 영웅 이상 포함 시 확인 다이얼로그 1회 추가.
- **표시**: 잠금 장비는 목록에서 자동 제외.

## F3-4. 대장간 제작 — 중간
파밍한 도면 + 몬스터 소재·광석으로 장비 제작. 제작 장비는 동급 드랍보다 기본 스탯이 안정적(천장 역할). 도면은 소모되지 않는다.

**근거**: 드랍 운이 나쁠 때의 보증 수단으로 파밍 좌절을 막는다.

| 슬롯 | 내용 |
|---|---|
| 전제 | 도면 보유 + 재료·골드 충분 |
| 트리거 | 제작 탭 → 보유 도면 선택 |
| 동작 | 재료·골드 소모 → 즉시 제작(대기 없음). 등급 규칙대로 랜덤 옵션 부여 |
| 결과 | 인벤토리 추가 + 도감 등록 |
| 예외 | 도면 영구 보유 |
| 표시 | 필요 재료 보유/부족 색상 구분 |
| 규칙 | 브람 필드 제작은 소모품·재료 가공으로 제한 (D-31) |
| 데이터 | `blueprints.json` |

## F3-5. 파밍 콘텐츠 소스 관리 — 높음
7종 파밍 소스의 리스폰·보상 규칙 — 필드(상시), 정예(30분), 미니 던전(1일), 지역 던전(재입장 자유), 월드 보스(3일), 채집·낚시·채광(상시), 보물 지도(몬스터 드랍).

**근거**: 소스를 주기별로 분산해 '오늘 할 것'이 매일 생기는 리텐션 설계.
**성공 기준**: 데모 플레이 세션 중앙값 45분 이상 (PRD KPI)

| 슬롯 | 내용 |
|---|---|
| 트리거 | 정예·월드 보스는 처치 시점부터 타이머. 보물 지도 사용 시 지도에 X 표시 |
| 동작 | 주기 도래 시 재활성화, 보상 테이블 참조. 보물 지도는 X 지점 파기 → 보물 지급·소모 |
| 결과 | 월드 보스 클리어 시 전설 1개 확정 |
| 예외 | 타이머는 **실제 플레이 시간 기준, 오프라인 미포함** (D-15) |
| 표시 | 월드맵에 정예·월드 보스 리스폰 상태 아이콘 |
| 규칙 | 첫 클리어 보상과 반복 파밍 보상은 별도 테이블 |
| 데이터 | `farming_sources.json` |
