# 첫 데모 몬스터·아이템 콘텐츠 카탈로그 v1

2026-09-12 · **검토 초안 / 런타임 미반영**

## 범위와 상태 구분

- **기존 확정 방향:** 따뜻한 섬나라의 탑다운 액션, 마을–필드–유적 20~30분 데모, 일반 적 3종. 핀 몸체 64×96·FHD는 사용자 승인 기준이며 몬스터 전종을 동일 크기로 만드는 뜻은 아니다.
- **기존 데이터:** 아래 ID·패턴·수치는 현재 저장소를 읽어 기록한 스냅샷이다. 기존 데이터 주석의 `_balance_todo`까지 새로 확정한 것은 아니다.
- **제안:** 생태 묘사, 도감 문구, 실루엣과 예고 동작, 조우 구성. 이 문서는 원본 캐릭터·스프라이트를 복제하지 않는다.
- **결정 필요 / 보류:** 새 도구의 기능, 새 보상 지급, 기존 전투 규칙 변경. 구현하지 않았으며 해당 항목의 선택 전까지 데이터 변경을 멈춘다. 독립적인 기존 적 3종의 묘사·검증은 계속 가능하다.

## 2. 적 3종 제작 카드 — 아래 서술은 제안

### 방울 슬라임: 공격 후 빈틈을 알려 주는 기준선

- 생태: 물웅덩이와 오래된 돌틈에서 수분을 모으는 작은 생물. 안개가 짙은 곳에서는 몸속에 회색 가루가 맴돈다. 모든 개체가 본래 악하다는 설명은 피한다.
- 실루엣: 낮고 둥근 물방울, 커다란 두 눈, 몸속 한 덩어리의 하이라이트. 장식이나 왕관을 붙여 보스와 혼동시키지 않는다.
- 예고 → 공격 → 회수: 바닥에 넓게 눌림 → 공격 방향으로 몸 앞면이 튀어나옴 → 뒤쪽 젤리가 따라오고 원형으로 돌아옴. 눈·몸의 중심축이 프레임마다 무작위로 바뀌지 않는다.
- 대응 학습: 예고를 보고 옆으로 빠지거나 가드한 뒤 회수 시간에 반격. 첫 조우는 다른 적의 예고와 겹치지 않는 공간에 둔다.
- 도감 문구 초안: “이슬을 모아 통통해진다. 몸이 납작해지면, 곧 앞쪽으로 튀어 오를 참이다.”
- 주의: GDD에 있는 분열은 일반 `slime`에 새로 넣지 않는다. 기존 분열 필드는 정예 `elite_bunchi_spawn`에 있으므로 일반종의 기능처럼 소개하지 않는다.

### 뿔토끼: 방향을 읽고 옆으로 피하는 적

- 생태: 들판의 뿌리를 짧은 뿔로 파낸다. 겁먹으면 숨기보다 곧장 내달리는 성질이라는 해석으로 귀여움과 위험을 함께 준다.
- 실루엣: 뒤로 길게 누운 귀, 짧은 단일 뿔, 큰 뒷발. 현재 Racoon 대역과 구별되는 토끼 외형이 필수다.
- 예고 → 공격 → 회수: 앞발을 땅에 고정하고 귀를 접음 → 뿔·몸·먼지가 같은 방향으로 직진 → 앞발로 제동하고 귀가 늦게 따라옴. 예고 중 회전 여부는 실제 AI와 맞춘다.
- 대응 학습: 돌진 선에서 측면으로 이동하고 지나간 뒤 접근. 벽 충돌 기절 경로는 기존 코드에 있으나 이를 필수 퍼즐 열쇠로 쓰려면 별도 구현·검증이 필요하다.
- 도감 문구 초안: “귀가 바짝 눕고 뿔이 낮아지면 비켜 서자. 빠르지만 급하게 방향을 바꾸는 데에는 서툴다.”
- 주의: `horn_rabbit_big`은 별도 기존 정예 ID지만 이번 3종 재디자인 물량에 네 번째 신규종으로 추가하지 않는다. 기존 메인 퀘스트 연결은 보존한다.

### 버섯돌이: 위험 구역 밖으로 이동하게 하는 적

- 생태: 축축한 유적 돌벽 주변의 낙엽을 분해한다. 회색 포자가 쌓인 개체가 주변을 방어적으로 덮는다는 해석이다.
- 실루엣: 넓은 갓, 짧은 줄기·발, 갓 아래 굵은 주름. 녹색 바닥과 구별되는 황갈색·보랏빛 포인트를 시험하되 최종 팔레트는 실제 배경에서 확인한다.
- 예고 → 공격 → 회수: 갓이 부풀고 주름이 드러남 → 갓 아래에서 포자가 나오며 지면 경계 안에 번짐 → 갓이 내려오고 포자가 잦아듦. 화면 전체 흔들림으로 예고를 대신하지 않는다.
- 대응 학습: 위험 경계를 보고 밖으로 이동. 장판 안에서 구르기 무적만 반복하면 안전하다는 안내는 금지한다.
- 도감 문구 초안: “갓 아래가 부풀면 포자가 퍼진다. 용감하게 버티기보다, 잠시 바깥 공기를 마시는 편이 낫다.”
- 주의: `patrol_radius_px=0`은 순찰 없음이다. 추적을 포함한 모든 이동이 없는 완전 고정 포탑이라고 단정하지 않는다.

## 3. 조우 구성 제안

| 구간 | 배치 의도 | 통과 선택 | 관찰 항목 |
|---|---|---|---|
| 마을 밖 안전한 길 | 슬라임 단독으로 예고·반격 학습 | 싸우거나 넓게 우회 | 예고를 처음 보고 공격 방향을 알아보는가 |
| 초원 갈림길 | 뿔토끼의 긴 진행 방향과 여유 공간 | 직선 길 교전 / 둘레 길 우회 | 옆으로 피할 공간이 실제로 남는가 |
| 유적 앞 습한 터 | 버섯 장판과 접근 거리 학습 | 회수에 접근 / 장판 밖 경로 탐색 | 장식 풀과 위험 경계가 구분되는가 |

이는 배치 설계안이며 새 맵이나 우회 경로가 이미 구현되었다는 뜻이 아니다. 3종 동시 전투나 시간 제한은 첫 학습을 검증한 뒤에만 추가한다. 드롭 파밍을 하지 않으면 출구가 막히는 필수 소재 관문은 제안하지 않는다.

## 5. 확장을 위한 제안과 결정 경계

### 탐험 보상 도구 — 보류

병렬 초안 통합 결과, 현재 데모는 `story-world-demo-v1.md`의 **발견 정보 재사용** 제안으로 검토한다. 새 도구 아이템은 현재 필수 과제가 아니며 아래 내용은 후속 선택지로만 보류한다. 도구를 새로 선택해야 이 데모 검토를 진행할 수 있다는 뜻이 아니다.

GDD의 “다른 장소에서도 사용하는 발견 보상”에는 반복 사용 도구가 어울린다. 예를 들어 유적 문양을 읽는 조사 도구를 **새 아이템 제안**으로 검토할 수 있지만, 기존 아이템 ID는 아직 없으며 이 문서에서 새 ID·기능·지급 위치를 확정하지 않는다. 다른 스토리/스킬 초안과 통합하여 하나의 도구만 선택해야 한다. 새 UI·세이브 상태·퍼즐 정답이 함께 바뀌므로 결정 전 구현하지 않는다.

### 전투 규칙 설명 — 확인 필요, 현행 유지

버섯 장판의 `ignores_iframes=true`는 현재 코드에 있다. GDD의 “회피·가드가 항상 유효”와 함께 전달할 때, 구르기로 **범위를 벗어나는 행동**과 장판 안에서 **무적으로 버티는 행동**을 구별해야 한다. 현행 규칙을 바꿀지 여부는 플레이테스트 후 별도 결정이다. 이 문서는 피해량·무적 처리·가드 처리 어느 것도 수정하지 않는다.

## 6. 아트·QA 인계 체크리스트

- [ ] 각 적의 정면 한 포즈에서 슬라임/토끼/버섯이 색 없이도 식별된다.
- [ ] 예고·공격·회수의 중심축과 발 접지가 연속된다. 흔들리는 프레임을 프레임 수 증가로 감추지 않는다.
- [ ] FHD 실제 화면에서 핀과 적의 상대 크기, 장판 경계, 무기 도달 거리, 가림을 확인한다.
- [ ] 화면 해상도·아트 크기 변경이 감지 거리·이동 시간·공격 시간 변경으로 이어지지 않는다.
- [ ] `attack_vfx_offset_px`와 피해 판정 위치를 새 몸체에서 별도로 확인한다. 오래된 앵커 문서의 16px 몸체 가정을 새 자산에 그대로 적용하지 않는다.
- [ ] 기존 드롭 ID→아이템 ID, 아이콘, 이름 번역의 연결을 확인한다. 이름/아이콘 교체가 등급·가중치 변경으로 번지지 않는다.
- [ ] 일반 3종 및 기존 퀘스트용 정예의 처치 이벤트·드롭·저장 회귀를 확인한다.
