2026-09-12 · 제안 전용 · 기존 `../monsters-items-demo-v1.md`의 3종 및 데이터 보존

이 문서는 기존 목록 재요약이 아니라 **생태 관찰 6개와 새로운 물건 12개**를 추가한다. 이름·ID·배치·획득 방식 모두 미확정이며 런타임 데이터에 넣지 않았다. 12개는 새 전투 장비나 기능성 도구가 아니라 소재·장식·수집물 후보다. 제작법, 드롭 확률, 가격, 능력치, 강제 수집 개수를 정하지 않는다.

## 2. 기존 3종의 관찰·조우 변주 6개

새 몬스터 종·변종 스탯을 만들지 않는다. 같은 기존 `monster_id`를 서로 다른 장소에서 읽게 하는 배치·미술·서술 제안이다. 비전투 환경 모션도 아직 구현된 기능은 아니다.

### E01 · `draft_encounter_slime_gutter` · 슬라임 — 물받이 아래의 둥근 자리

`slime` / 초반 후보. 무너진 물받이 아래 작은 물방울 자국은 둥근데, 옆의 진흙 자국 하나만 타원으로 길다. 슬라임의 몸이 눌렸다 튀는 예고와 같은 방향성을 환경에 남긴다. 플레이어는 물받이 옆 넓은 길로 지나가거나 빈 터에서 기존 근접 패턴과 싸운다. 신규 물리·물길 퍼즐은 없다. `draft_item_dew_lacquer_chip`의 현장 설명으로 연결 가능. 생물학 근거가 아닌 창작이며, S4에서 차용한 정보 분리 원칙상 물방울 반짝임은 공격 예고보다 약하게 한다.

### E02 · `draft_encounter_slime_tally` · 슬라임 — 버려진 표찰의 반사

`slime` / 후속. 옛 운반함 주변에 점액이 묻은 금속 표찰이 놓여 있다. 슬라임의 젤리 안에 물건을 실제로 넣거나 처치 보상을 확정하는 대신, 주변 소품만으로 지나간 흔적을 암시한다. 돌담 안쪽의 교전 공간과 바깥쪽 통과 공간을 보이게 둔다. `draft_item_ferry_tally_half`의 한쪽 마모가 이곳 흔적과 맞는다는 서술 후보. 새 삼킴·훔치기 AI는 만들지 않는다.

### E03 · `draft_encounter_rabbit_brush` · 뿔토끼 — 덤불 사이의 낮은 문

`horn_rabbit` / 초반 후보. 덤불 아래 납작한 풀길과 바깥의 넓은 흙길을 나란히 보여 준다. 개방지와 덤불 경계라는 S1을 참고했지만 뿔의 긁힌 흔적은 창작이다. 토끼는 덤불 속 완전 은폐 상태에서 즉시 공격하지 않으며 귀·뿔·예고를 먼저 볼 수 있는 배치로 시험한다. `draft_item_brush_caught_braid`를 낮은 가지에 걸린 흔적으로 제안한다. 먹이로 유인하는 새 시스템은 없음.

### E04 · `draft_encounter_rabbit_fence` · 뿔토끼 — 낡은 울타리의 제동 자국

`horn_rabbit` / 후속. 굽은 울타리와 땅의 평행한 발자국은 누군가 여러 번 뛰어갔음을 말한다. 플레이어는 넓은 옆길을 택하거나 빈터에서 기존 돌진 회피를 시험한다. 벽 충돌 기절은 기존 기능 범위에서 QA하되, 울타리를 부수거나 길을 여는 열쇠로 삼지 않는다. `draft_item_horn_offcut_button`과 기존 `rabbit_horn`을 비교하는 장인 대화 후보. 실제 토끼의 뿔·제동 습성이라는 주장 없음.

### E05 · `draft_encounter_mushroom_steps` · 버섯돌이 — 두 무늬의 돌계단

`mushroom` / 초반 후보. 오래된 돌에 붙은 평평한 얼룩과 땅에서 퍼지는 포자 공격을 다르게 그린다. 전자는 저대비 정적 장식, 후자는 선명한 외곽·동적 예고이다. S2의 지의류 표면 관찰과 S4의 가독성을 결합한 창작. 계단 둘레의 안전 공간을 보고 기존 장판을 우회할 수 있게 배치한다. `draft_item_stone_bloom_rubbing`은 표면을 옮긴 종이 수집물이며 생물을 떼어내는 채집 기능은 아니다.

### E06 · `draft_encounter_mushroom_loom` · 버섯돌이 — 수선 작업장의 그늘

`mushroom` / 후속. 유적 가장자리의 버려진 천틀과 걸린 천 아래에 버섯돌이를 배치한다. 천의 장식 점선과 공격 장판의 경계를 혼동하지 않도록 재질·윤곽을 분리한다. S3의 밑그림 제작 흔적을 배경 소품으로 해석한 창작이며 버섯이 자수를 만들었다는 설정은 아니다. `draft_item_pricked_pattern_leaf`를 이전 주민의 생활 흔적으로 연결할 수 있다. 천을 자르거나 불태우는 새 기믹은 없음.

## 4. 기존 소재를 살리는 퀘스트 연결 후보

새 퀘스트 명칭·NPC·결말은 스토리팀의 6퀘스트/4발견 문서에서 통합한다. 아래는 번호 대신 **역할**로 연결하며 정본을 만들지 않는다.

통합 cross-reference 제안: 길안내 역할에는 E03·I02, 주인 찾기에는 I02 또는 I05, 재사용에는 I01·기존 `slime_jelly`, 생활 흔적에는 I04·I09가 어울린다. 이는 스토리팀의 기존 물건을 교체하는 지시가 아니라 **동일 물건으로 합칠 수 있는 후보**이다. 최종 퀘스트/발견 ID를 확인하기 전 임의의 참조 키를 만들지 않는다. E01~E06 제목의 `draft_encounter_`도 문서용 제안 ID이며 런타임 ID가 아니다.

| 기존 소재와 현재 연결 | 새 서술·연결 후보 | 구현 경계 |
|---|---|---|
| `slime_jelly` → 기존 `blueprint_iron_sword`·`blueprint_iron_greaves` | 장인이 I01을 보고 “재료가 같아도 바르는 손은 다르다”는 식으로 옛 수선 흔적을 해석한다. | 기존 제작량·비용 유지. I01을 필수 제작 재료로 대체하지 않음 |
| `rabbit_horn` → 기존 `blueprint_leather_cap` | I07의 둥근 모양을 뾰족한 뿔과 비교해 사냥/생활의 대비를 보여 준다. E03의 발길 관찰과 이어도 좋다. | 새 단추 제작법·토끼 길들이기 없음 |
| `mushroom_cap` → 기존 `blueprint_leather_vest` | I10·I12를 통해 포자 위험 안내와 이전 주민의 관찰 습관을 연결한다. | 음식·약효 주장, 요리 레시피 추가 없음 |
