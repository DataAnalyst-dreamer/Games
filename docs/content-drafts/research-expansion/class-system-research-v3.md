# 직업 확장 참고 조사 v3 — RO·랑그릿사·CQ

2026-09-13. 최신 사용자 요청에 따라 **4인=고정 직업 제약은 최종 방향에서 제외**한다. 핀·리라·모리·브람의 인물 정체성은 유지하되, 많은 스킬과 조합 전직을 설계한다. 본 문서는 외부 게임의 실제 구조와 우리 설계 제안을 분리하며 실게임 코드를 바꾸지 않는다.

## 확인된 공식 자료

각 요약은 해당 출처당 200단어 미만이다. 공식 본문을 직접 열어 확인했다. 오래된 안내의 수치를 최신 서버 전체에 일반화하지 않는다.

### RO-1 — Ragnarok Online PC / 북미 운영사 안내

[WarpPortal: Ragnarok Online Basic Controls](https://support.warpportal.com/kb/a630/ragnarok-online-basic-controls.aspx), 2013-10-29 작성·2021-07-20 수정. 본문 II/III는 Base Level과 Job Level을 나누고, Job Level 상승 때 스킬 포인트로 새 기술을 배우거나 기존 기술을 강화한다고 설명한다. Novice에서 첫 직업을 선택하는 흐름도 명시한다. 이는 **PC 원작 운영 안내**이며 Ragnarok M·Origin·X 등의 모바일 전직/다중직업 규칙이 아니다.

### RO-2 — PC Renewal 스킬 선행 조건

[공식 Job Skill 페이지](https://renewal.playragnarok.com/gameguide/classes_skill.aspx?c=48)는 기술마다 마스터 레벨·선행 기술·장비 조건을 구분한다. 특정 기술은 선행 기술의 특정 랭크를 요구한다. 우리에게 유용한 원리는 **스킬 명단이 아닌 의존 관계가 있는 투자 구조**다. 실제 외부 기술명·계수는 복사하지 않는다.

### LG-1 — Langrisser Mobile 전직

[Zlongame: Class Transfer](https://us-news.zlongame.com/sysmz/894.jhtml), 2019-01-02 게시·2019-03-18 갱신 표기. 영웅마다 초기 클래스와 고유 분기 경로가 있고, 재료로 숙련·전직하며 경로에 따라 스킬과 병사를 해금한다. 경로 변경에는 별도 자원이 필요하고, 앞 경로에서 얻은 스킬/병사를 이후에도 이용할 수 있다고 설명한다. 이는 **모바일판 당시 안내**다. 희귀도별 경로 수나 비용을 오늘의 모든 영웅에 일반화하지 않는다.

### CQ-1 — Crusaders Quest 모바일 원작

[LoadComplete: About CQ](https://cq.loadcomplete.com/en/about-cq/), 2023-10-05 표기. 공식 설명은 연속 블록 조작과 용사 조합의 깊이를 핵심으로 제시한다. **서로 다른 숙련 트리 두 개를 결합해 한 인물이 새 직업이 되는 구조를 설명한 자료가 아니다.** 따라서 CQ는 캐릭터 개성과 조건부 기술 연계의 참고이며, 조합 전직의 직접 근거로 취급하지 않는다. PC 본가와 모바일 파생판을 혼동하는 경우가 아니라 원래 모바일 게임이다.

## 실제 구조의 차이와 우리 설계 추론

| 참고 | 실제 확인 구조 | 가져올 설계 원리(우리 판단) | 가져오지 않을 것 |
|---|---|---|---|
| RO | 직업 성장과 선행 기술/랭크 | 투자로 다음 선택이 열리고 직업 역할이 보이는 트리 | 이중 경험치 경제·원작 직업명/스킬명/정확한 수치 |
| 랑그릿사 모바일 | 영웅별 경로와 스킬/병사 계승 | 다른 경로의 배움이 다음 빌드의 재료가 되는 구조 | 영웅 희귀도로 전직 다양성 제한, 병사 부대 조작, 유료희소재화 강제 |
| CQ | 블록 사용과 용사 조합 | 조건-행동-결과 연결로 개성을 만드는 기술 | 블록 전투·가챠·파티 조작을 직접조작 게임에 자동 도입 |

**8숙련 계열 + 두 계열 조합 직업은 우리 창작 설계안**이다. 위 세 게임이 동일한 시스템이라는 뜻이 아니다. PoE/Titan Quest의 실제 구조는 별도 담당 조사와 통합하며 이 문서는 미검증 세부를 대신 채우지 않는다.

## 후속 데이터 제작 기준

검술(blade)·수호(guard)·궁술(bow)·기교(trick)·원소(element)·생명(life)·신앙(faith)·제련(forge)을 각 12노드로 설계한다. 계열마다 액티브 4, 행동변형 4, 패시브 3, 핵심특성 1. 두 활성 계열·기본 액티브 슬롯 2·액티브별 행동변형 1은 **이번 설계 초안의 운용 전제**이며 외부 게임 사실이 아니다.

노드는 선행 ID·조건·행동·효과·대가·장비·애니메이션을 포함한다. 고정 인물로 계열을 잠그지 않는다. 피해량·시간·SP 비용·해금 레벨은 미정. 실게임 데이터와 별도 문서 영역에 저장하고 그래프 순환·중복 ID·없는 선행을 검사한다. 신앙/생명은 자동 부활·무한 회복을 기본 제공하지 않으며, 설치물 AI 등 미구현 기능을 명시한다.

이전 v1/v2의 '전직 없음'은 당시 범위 기록이다. 이번 요청의 확장 방향을 막는 제약으로 적용하지 않는다.
