# 리서치 기반 콘텐츠 확장 — 연결·검증 원칙

2026-09-12 · 적용 전 소재집. 새로운 시스템 채택 문서가 아니다.

## 근거와 적용의 구분

Inkle의 공식 [인터랙티브 글쓰기 가이드](https://www.inklestudios.com/ink/web-tutorial/)는 방문·선택 이력에 따른 조건부 대사와 선택지, 분기 후 연결을 설명한다. 이를 참고해 이번 소재는 ‘설명문을 더 많이 넣기’뿐 아니라 **이미 본 정보에 다르게 반응하기**로 확장한다. 이는 설계원리를 참고한 제안이며 Inkle의 작품·대사를 가져오거나 이 프로젝트에 ink를 설치한다는 뜻이 아니다.

예를 들어 물건의 흔적을 먼저 본 경우에는 NPC가 관찰을 확인하고, 먼저 대화한 경우에는 같은 흔적이 나중에 답이 된다. 이 순서를 모두 허용하려면 발견 여부·의뢰 상태·보상 수령 여부를 구분해야 한다. 이 상태 설계와 아래 테스트 규칙은 본 프로젝트를 위한 자체 제안이다.

## 소재 연결의 최소 단위

관찰 가능한 환경 흔적 → 물건 또는 정보 → 기존 NPC의 해석 → 선택적 행동 → 짧은 재방문 반응.

- 모든 물건에 퀘스트를 강제로 붙이지 않는다. 일부는 세계를 설명하는 수집·장식 후보로 남긴다.
- 신규 퀘스트가 기존 메인 진행을 막거나 필수 드롭 파밍을 추가하지 않는다.
- 3종 몬스터의 조우 변주는 신규 AI·새 몬스터 종으로 계산하지 않는다.
- v2의 직업별 플레이 성향은 당시 설명용이었다. 2026-09-13 사용자 요청 이후 성장 체계는 [조합 전직 v3](class-progression-v3.md)로 확장한다.
- 첫 데모에는 검증 가능한 소수만 고른다. 소재 수가 곧 구현 분량·플레이타임은 아니다.

## 제안의 데이터 상태

`draft_` ID는 원고 참조용이다. 런타임 등록·번역 key 추가·드롭률·아이템 지급·세이브 변경은 이번 작성에 포함하지 않는다. 새 스킬의 효과 방향은 창작하되 피해량·소모량·쿨타임을 임의 확정하지 않는다.

각 카드의 외부 출처는 자료에서 확인한 사실/설계원리와, 그 원리를 바탕으로 새로 쓴 판타지 설정을 구분한다. 실존 문화·생태 자료를 참고했다고 해서 게임 속 묘사가 실제 문화·생물의 사실이라는 뜻은 아니다.

## 구현 전 반드시 확인할 순서

1. 의뢰 이전에 물건/정보를 발견한다.
2. 의뢰를 먼저 받고 나중에 발견한다.
3. 두 해결 경로를 모두 시도하거나 순서를 바꾼다.
4. 완료 직전/직후 저장하고 다시 진입한다.
5. 완료된 NPC와 다시 대화한다.

각 순서에서 목표가 막히지 않고, 완료·소비·보상은 의도한 횟수만 적용되어야 한다. 대체 해결법을 모두 수행해야 하는 AND 조건으로 잘못 구현하지 않는다. 퀘스트 대상이 전투/수집으로 먼저 사라지는 경우의 복구 경로도 설계한다.

## 진행·중단 경계

새 소재 문서 작성·출처 검토·중복 검사와 사용자가 요청한 조합 전직 설계까지 진행한다. 주요 인물의 배경 변경, 강제 탐험 도구, 전투/경제 수치·저장 데이터의 실제 변경은 적용 전에 필요한 결정을 확인한다. 조합 전직 방향 자체는 이미 사용자가 요청했으므로 다시 미승인 방향으로 취급하지 않는다. 이번 콘텐츠 작성은 시각적으로 거절된 핀 다리 변형 방식을 계속 사용한다는 승인도 아니다.
