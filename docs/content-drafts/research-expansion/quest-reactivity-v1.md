# 퀘스트 반응 보충 v1 — 미등록 글 초안

2026-09-13 · 기존 6퀘스트/4발견에 대한 32상태 카드, 선택 분기 포함 40대사 쌍. 게임 데이터·정본·기존 초안 JSON은 변경하지 않았다. 이번 신규 JSON은 실제 QuestSystem 상태나 localization key 목록이 아니다.

## 원자료와 경계

- [퀘스트 원안](story-quests-v2.md)의 SQH-V2-01~06 및 ENVH-V2-01~04와 검증용 draft 코드를 일대일 참조한다. 해당 문서의 R1~R4 기존 리서치를 재사용했으며 새 웹 조사를 수행했다고 주장하지 않는다.
- [데모 v1](../story-world-demo-v1.md)의 마을 확보 이후 발췌, 동굴 손잡이 정보 재사용을 유지한다. [세계관 5.1절](../../story/world-bible.md), [핀 2.1절](../../story/characters.md), [본편 1막](../../story/main-storyline.md)을 대조했다.
- 새 인물·지역·역사·성물 능력·브람 기원/공개 시점·축문·호감도 보상은 없다. 본문 생활 대사는 이번 창작 제안이다. 테오는 조사 안내, 머루는 생활 돌봄, 로젤은 목축 실무, 핀은 성급한 단정 대신 확인하는 태도를 유지한다.
- `location_anchor`는 `game/data/world_objects.json`에 존재하는 인근 장소를 참조할 뿐 정확한 배치 좌표/새 소품 등록을 뜻하지 않는다. ENVH-V2-03의 동굴 입구 anchor는 진입 경로 참조이며 발견 자체는 원안대로 **동굴 안쪽**에 놓는다.
- 선택은 원안의 식탁/짐받침, 판 고정/유지, 여관/작업장, 가지 직접 정리/보고만 분기한다. 표지 두 힌트와 장화 두 조사 경로는 추가 필수 증거나 새로운 보상 분기로 만들지 않는다. 아무 대사도 완료 게이트로 사용하지 않는다.

## 표시·선택 조건

`start/progress/complete/revisit/observe`는 문서 상태 라벨이다. 기존 런타임 state에 자동 대응시키지 않는다. 선택 완료와 환경 상태가 실제 성립한 뒤 해당 줄만 보여야 한다. 진행 중 문장은 단서를 확인했을 때의 후보로, 모든 경로에서 자동 재생하는 공통 힌트가 아니다. 특히 장화 progress는 **밑창 비교 경로에서만** 사용하고 머루에게 물어 해결한 경로에 이 단서를 요구하지 않는다. 로젤의 표지 progress는 선택 힌트 요청 시에만 사용한다. 가지 보고 후 revisit는 실제 정리된 소품으로 바뀐 뒤에만 표시한다.

`hud_short`는 154px 생산 HUD를 목표로 한 단문 후보다. 최대13 Unicode 문자 제한을 두었고 실제 최장11자다. 이후 [실제 Godot 폰트 측정](../../qa/reactivity-font-width-20260913.md)에서40문장 최대101px/154px 초과0을 확인했다. 실제 Label은11px이고 큰글씨 부모15 설정에도11px를 유지했으므로15px 접근성 통과는 아니다. 생산 연결과 밝은 배경 대비는 미검증이다. `expanded`는 선택 대화 패널용(최장38자)이며 HUD toast에 그대로 넣지 않는다. 다음 표의 화자는 확장 대사 기준이고 단문은 관찰 요약이다. 핀 대사는 핀 발췌 전용이며 다른 플레이어블에 자동 적용하지 않는다.

## 검증 결과

- `python tools/validate_quest_reactivity.py`: PASS, 카드32/분기별문장40, HUD 최대11자/확장 최대38자. 이 문자수 검사기 자체는 폭을 측정하지 않아 render_width=UNTESTED/runtime=UNCONNECTED를 출력한다. 별도 Godot 측정 결과는 위 후속 링크와 JSON 메타에 기록한다.
- `python -m unittest discover -s tools -p test_validate_quest_reactivity.py -v`: 7 tests PASS(exit0). 실제 문서 1건 + 중복ID/없는 참조/없는 상태/문자 수 초과/불법 선택/없는 장소 6개 오염 거부 검사.
- 참조 파일·원안 ID/code 매핑·화자·장소 anchor·상태 완전성·텍스트 길이를 검사한다. 실제 퀘스트 실행, 저장/로드, 분기 렌더, 전체 캐논 자동 검증이 아니다. 구조 통과만으로 반응을 게임에 연결하지 않는다.
- 32카드는 새로운 퀘스트32개가 아니며 기존6퀘스트의24상태+4발견의8상태다. P1/P2 순서와 20~30분 실측 전 가설은 원안을 유지한다. 반복 방문 대사는 추가 보상·쿨타임·현실 시간 조건을 만들지 않는다.

추가 사용자 결정: 이 글 초안 단계에서는 없음. 채택/구체 배치/실제 패널 연결은 별도 검수와 작업이 필요하다. 본게임 소스 freeze 유지. classes 독립 DA: 글·구조 범위 필수 수정0, 7테스트 재실행·32카드/40분기/최장11·38자 및 MD-JSON 대조 통과. 문자수 정책과 검증기 상수의 향후 drift 방지는 후속 개선이다. 후속11px 폭 측정은 별도 DA 대기이며 게임 연결은 여전히 미검증이다.
