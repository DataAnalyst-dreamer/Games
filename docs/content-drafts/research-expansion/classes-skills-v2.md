## 3. 공통 컨셉 규칙

- 이하 **12개 모두 신규 제안**. `cx2_*`는 검토 식별자이지 실제 `skills.json` 노드 ID가 아니다. v1 핀 6노드와 동명·동효과를 피했다.
- 슬롯 입력은 `skill_1`/`skill_2`를 뜻하며 키 리매핑을 존중한다. 방향은 기존 조작 정책을 따르고 새 마우스 지면 지정 조작을 강제하지 않는다.
- 모든 액티브의 효과계수·거리·지속·소모·쿨타임은 미확정. 표의 대가는 정성 설계이며 숫자로 채택하지 않는다.
- 예고는 플레이어 자세의 판독 요구다. 기존 적 예고 최소 시간이나 저스트 가드 창을 바꾸지 않는다.
- 재사용은 **연결 후보**이지 이미 구현되었다는 뜻이 아니다. 캐릭터별 실행 기반·슬롯 시스템은 후속 연결이 필요하다.
- 스킬은 탐험 선택을 돕지만 필수 통행 열쇠가 아니다. 전직·수영·점프·속성 퍼즐·파티·가챠·새 상태이상 체계를 전제하지 않는다.

## 4. 핀 — 신규 3컨셉

### CX-F1 / `cx2_fin_measured_cut` — 간격 베기 · 공격 · 첫 데모 후속 우선 후보

- **입력·예고·효과:** 슬롯 입력 → 검을 옆으로 모아 짧은 후퇴 준비를 알림 → 현재 정면을 한 차례 베고, 유효 타격 뒤 뒤로 짧게 물러남. 전진 베기와 달리 접근이 아니라 교전 종료 선택이다.
- **제약·대가:** 물러나는 동안 추가 공격/가드 불가, 무적 없음. 뒤가 벽이면 이동만 중단하고 공격 범위는 늘어나지 않음. 피니셔 강화·스태미나 회복·자동 반격 아님.
- **애니메이션 요구:** 발을 붙인 준비, 정면 베기, 뒤꿈치로 후퇴, 균형 복구. 상체 그림 전체를 흔드는 방식 금지. 검 궤적은 실제 판정 크기 안에서 종료.
- **재사용 / 신규:** 근접 Hitbox·공격 방향·충돌 이동 후보 재사용 / 슬롯 실행, 공격 후 후퇴 단계·취소 경계 신규. 64×96 본체와 장비 여백 별도.
- **QA:** 벽 뒤/빈 공간에서 공격 범위 동일; 후퇴 중 피해 수신; 타격 1회; 물러나며 방향이 뒤집히지 않음. **검증 질문:** 후퇴가 회피 무적으로 오인되지 않는가?
- **근거:** 기존 검·방패 직접조작 + R1/R2 원리 + 동작 자체는 우리 창작. 실제 적용 승인이나 완성 약속이 아닌 우선 검토 후보.

### CX-F2 / `cx2_fin_low_brace` — 낮춘 방패 · 방어 · 후속

- **입력·예고·효과:** 슬롯을 누르는 동안 몸을 낮추고 방패를 바닥 쪽에 붙임. 일반 가드 가능한 정면 피격의 넉백을 억제하는 고정 자세.
- **제약·대가:** 이동·공격 불가, 기존 가드 피해/소모 유지. 저스트 가드 창 확장·무적·가드 불가 공격 차단 없음. 스태미나 부족 시 해제. v1 일반 가드 비용 경감과 다름.
- **애니메이션 요구:** 무릎 굽힘→방패 버팀→충격 움찔→일어남. 정면/측후면 보호 범위를 색만 아닌 방패 방향으로 표시.
- **재사용 / 신규:** 가드 판정·자원·넉백 후보 재사용 / 방어자 넉백 억제 조건과 고정 자세 신규.
- **QA:** 가드 불가/후방 피격 보장; 고갈 후 자세 해제; 넉백 제거가 피해 제거로 번지지 않음; 경직 취소로 무한 방어 금지.
- **근거:** 기존 방패 기제 + R1/R2 + 우리 창작.

### CX-F3 / `cx2_fin_route_mark` — 돌아갈 표식 · 유틸 · 후속

- **입력·예고·효과:** 비전투 상태에서 슬롯 입력 → 검을 거두고 발치에 임시 천 표식을 놓음 → 걸어온 갈림길을 눈으로 다시 찾는 단일 개인 표식. 재사용하면 이전 표식 이동.
- **제약·대가:** 액티브 슬롯 기회비용, 설치 동작 중 피격으로 취소. 퀘스트 정답·미발견 지도·순간이동·부활 지점 제공 없음. 지역 이탈 시 제거하는 임시 정보.
- **애니메이션 요구:** 웅크려 설치·작은 천 펄럭임. 적 위험 표식보다 대비 낮게, 충돌과 무관한 소품임을 표시.
- **재사용 / 신규:** 상호작용 소품 표현 후보 재사용 / 임시 개인 표식·장면 정리 신규. 세이브 영구 수집과 분리.
- **QA:** 중복 무한 설치 금지; 설치가 통로를 막지 않음; 전투 취소 후 표식 미생성; 미발견 목표 위치 누설 없음.
- **근거:** 핀의 지키는 서사·탐험 방향 + R1의 정보 위계 + 우리 창작. 표식 스킬로 슬롯을 쓸 가치가 있는지 후속 평가하며 필수 기능으로 확정하지 않음.

## 5. 리라 — 신규 3컨셉, 모두 후속

### CX-L1 / `cx2_lyra_still_string` — 고요한 시위 · 공격

- **입력·예고·효과:** 슬롯 유지로 정지 조준, 시위를 놓는 순간 정면의 좁은 선으로 관통하지 않는 단일 화살 발사. 헌터 마크가 유효하면 기존 고유 조건으로 최초 목표 방향만 정하며 지형을 통과하지 않음.
- **제약·대가:** 준비 중 이동·가드 불가, 피격 취소. 빈 공간으로 쏠 수 있고 무조건 명중 아님. 유지 길이에 비례한 신규 차지 단계는 넣지 않음.
- **애니메이션 요구:** 활 당김·고정·놓음·시위 복귀. 예고선 폭과 화살 판정 일치, 정면 구별.
- **재사용 / 신규:** 기존 고유 메커니즘 기획·Hitbox 후보 / 활 투사체, 조준 유지, 헌터 마크 실행 연결 신규.
- **QA:** 벽 차폐; 마크 만료 전후 목표 처리; 취소 시 유령 화살 없음; 이펙트 밖 명중 없음.
- **근거:** 기존 활·마크 + R1/R3 + 우리 창작.

### CX-L2 / `cx2_lyra_branch_sweep` — 가지 쓸기 · 방어

- **입력·예고·효과:** 슬롯 입력 → 활을 몸 앞에 가로로 듦 → 가까운 정면 적을 짧게 밀어낸 뒤 원거리 자세 복귀. 피해보다 근접 탈출 여지에 집중.
- **제약·대가:** 접근을 허용해야 닿음, 방패/저스트 가드 판정 없음, 공격 중 피해 가능. 보스·넉백 저항 적 밀림 보장 안 함. 구르기나 마크 자동 발동 없음.
- **애니메이션 요구:** 활 가로막기·밀어내기·후딜. 화살 발사와 명확히 다른 실루엣.
- **재사용 / 신규:** 근접 판정·넉백 후보 / 활 전용 근접 상태와 무기 포즈 신규.
- **QA:** 후방 적 미적용; 다중 적 접촉 중 중복 판정 없음; 넉백 저항 때도 무적이 생기지 않음.
- **근거:** 기존 원거리 기동형 + R2 + 우리 창작. 핀 v1 방패 밀치기와 역할 유사성은 있으나 리라의 가드 없는 긴급 거리 회복으로 한정, 차별성이 부족하면 삭제 후보.

### CX-L3 / `cx2_lyra_dry_twig` — 마른 가지 소리 · 유틸

- **입력·예고·효과:** 슬롯 입력 → 정면으로 마른 가지를 던져 착지 소리 발생 → 아직 플레이어를 추적하지 않는 반응 가능 일반 적이 소리 지점을 조사하도록 제안.
- **제약·대가:** 소리 발생으로 원치 않는 적도 움직일 수 있음. 전투 중인 적의 어그로 삭제·보스 강제 유인·은신·기억 초기화 없음. 미반응 적도 명확히 표시할 필요.
- **애니메이션 요구:** 손 던짐·작은 착지 먼지·적 고개 돌림. 시각 신호만으로도 소리 위치를 알 수 있게 함.
- **재사용 / 신규:** 투척 표현·적 상태기계 후보 / 소리 조사 상태·반응 태그 신규. AI 확장이므로 첫 데모 범위 제외.
- **QA:** 벽 너머 소리 규칙 일관; 전투 적 유인 불가; 조사 종료 후 원래 행동 복귀; 길찾기 불가 지점 교착 없음.
- **근거:** 기존 추적 사냥꾼 서사 + R1/R2 + 우리 창작.

## 6. 모리 — 신규 3컨셉, 모두 후속

### CX-M1 / `cx2_mori_ember_stroke` — 잔불 획 · 공격

- **입력·예고·효과:** 슬롯 입력 → 지팡이 끝으로 정면에 한 획을 그림 → 짧은 전방 화속성 공격. 기존 융합 규칙의 서로 다른 속성 연속 적중 중 한 입력으로만 사용.
- **제약·대가:** 사거리가 짧아 접근 위험. 지면에 지속 화재나 환경 발화 생성 안 함. 자체 재시전만으로 융합 발동 불가, 새 융합 조합 추가 없음.
- **애니메이션 요구:** 지팡이 획·짧은 불꽃 전진·소멸. 피해 종료 뒤 남는 장식 불꽃으로 지속 피해를 오인시키지 않음.
- **재사용 / 신규:** 기존 화속성 데이터·Hitbox 후보 / 시전 상태·속성 적중 이력 연결 신규.
- **QA:** 같은 속성 반복으로 융합 불가; 빗나감은 연속 적중으로 집계하지 않음; 벽/장식 발화 없음.
- **근거:** 기존 속성·융합 기제 + R1/R3 + 우리 창작.

### CX-M2 / `cx2_mori_folded_sign` — 접힌 보호문 · 방어

- **입력·예고·효과:** 슬롯 입력 → 손앞에 작은 문양을 접음 → 짧은 동안 전방에서 오는 방어 가능 피해를 완화. 방향 고정된 임시 방어로 시전 사이 숨 쉴 틈을 만듦.
- **제약·대가:** 지속 중 공격 불가, 후방·가드 불가 공격에는 무효. 무적/반사/저스트 가드/속성 적중 없음. 별도 마나 자원을 도입하지 않음.
- **애니메이션 요구:** 문양 펼침·앞쪽 곡면·피격 균열·접힘. 보호방향 밖에 원형 전신 보호막을 그리지 않음.
- **재사용 / 신규:** 방향 가드·피해 완화 후보 / 마법 보호 상태·종료 규칙 신규.
- **QA:** 피해완화만 적용; 보호문이 융합 적중으로 집계되지 않음; 유지 중 공격 예약 중복 발사 없음.
- **근거:** 기존 마법사 + R1/R2 + 우리 창작.

### CX-M3 / `cx2_mori_unfinished_note` — 미완의 각주 · 유틸

- **입력·예고·효과:** 슬롯 입력 → 지팡이를 접어 작은 글자 조각 표시 → 현재 보유한 융합 준비 이력을 스스로 지움. 잘못 이어 둔 순서를 포기하고 다음 유효 적중부터 새 연결을 시작하는 조작.
- **제약·대가:** 공격·회복 효과 없음, 슬롯과 행동 시간 사용. 융합 준비를 저장·복제·연장하거나 조합 조건을 생략하지 않음. 비어 있으면 실패 안내만 하고 소비하지 않는 안.
- **애니메이션 요구:** 기존 속성 기호가 지워지는 짧은 손짓, 공격 이펙트와 분리.
- **재사용 / 신규:** 융합 기획의 이력 개념 / 이력 명시적 삭제·HUD 상태 동기화 신규. 두 슬롯 중 유틸 채택 가치가 낮으면 삭제할 백로그 후보.
- **QA:** 로드/일시정지 뒤 이력 부활 금지; 비어 있을 때 소비 없음; 이미 발동한 공격 피해를 취소하지 않음.
- **근거:** 기존 서로 다른 속성 연결 + R3의 맥락적 연결 원리 + 우리 창작. 조합 규칙 변경 없음.

## 7. 브람 — 신규 3컨셉, 모두 후속

### CX-B1 / `cx2_bram_split_line` — 갈라놓는 선 · 공격

- **입력·예고·효과:** 슬롯 유지 → 기존 3단 차지 표기를 사용해 해머를 세움 → 놓으면 전방의 좁은 선을 내려침. 원형 휩쓸기 대신 방향 선택에 보상을 주는 공격 후보.
- **제약·대가:** 차지 중 노출·발동 방향 고정, 후딜 존재. 지면 균열은 장식이며 벽/지형 파괴·땅속 충격파 없음. 기존 3단계를 늘리지 않음.
- **애니메이션 요구:** 단계별 해머 높이·몸통 긴장·내려침·끌어올림. 최고 단계와 낮은 단계 모두 타격선 식별 가능.
- **재사용 / 신규:** 기존 3단 차지 기획·근접 판정 / 해머 차지 실행·선형 판정·회수 상태 신규.
- **QA:** 단계 경계 중복 발동 없음; 벽 너머 적 미적중; 단계가 달라도 애니메이션/판정 방향 일치.
- **근거:** 기존 차지 해머 + R1/R2 + 우리 창작.

### CX-B2 / `cx2_bram_set_down` — 무게 내려놓기 · 방어

- **입력·예고·효과:** 차지 중 슬롯 입력 → 공격하지 않고 해머를 몸쪽으로 내려놓음 → 차지를 포기하고 짧은 정리 동작 뒤 이동 가능 상태 복귀.
- **제약·대가:** 쌓은 차지 전부 소실, 무적·피해·자원 환급 없음. 이미 내려치는 유효 공격 중에는 취소 불가. 회피 스태미나 비용 우회 없음.
- **애니메이션 요구:** 타격과 다른 몸쪽 내려놓기·무릎 펴기. 지면 타격 VFX를 쓰지 않음.
- **재사용 / 신규:** 차지 단계·상태 전이 후보 / 취소 가능 시점·차지 폐기 상태 신규.
- **QA:** 타격 직전 연타로 후딜 삭제 불가; 다음 차지가 이전 단계 상속 안 함; 차지 없으면 불발 안내.
- **근거:** 기존 차지 기제 + R2의 대응/대가 + 우리 창작.

### CX-B3 / `cx2_bram_sorted_parts` — 가지런한 부품 · 유틸

- **입력·예고·효과:** 비전투에서 슬롯 입력 → 작은 작업천을 펴고 기존 간이 제작 목록을 열되, 현재 재료로 만들 수 있는 소모품·재료 가공을 먼저 표시하는 준비 기술 후보.
- **제약·대가:** 새 레시피·재료 절약·장비 수리·무상 제작 없음. 전투 진입 시 작업 종료, 실제 제작은 기존 재료/레시피 조건 그대로. 기존 필드 제작 접근은 잠그지 않고 이 후보는 목록 정리 편의만 제공.
- **애니메이션 요구:** 앉기·부품 정리·작업천 접기. 재료 소비 성공 전 완성품이 생긴 연출 금지.
- **재사용 / 신규:** 기존 제작/인벤토리 설계 후보 / 브람 필드 제작 연결·제작가능 필터 UI 신규.
- **QA:** 필터가 부족 재료를 생성하지 않음; 취소 시 소비 없음; 기존 메뉴 경로와 동일 결과. 편의만으로 액티브 슬롯 가치가 낮으므로 구현 우선순위 최하위, 기본 제작 UI로 흡수할지는 후속 결정.
- **근거:** 기존 간이 제작 고유 기제 + R3의 능력 간 연결 + 우리 창작.

## 8. 우선순위·제작 의존·검증

**첫 데모 우선 후보는 CX-F1 하나뿐**이다. 현재 기본 캐릭터 모션·FHD 실행 검증을 밀어내지 않으며, 기본 공격/충돌/슬롯 실행 연결 이후 검토한다. 나머지 11개는 후속 백로그다. 본 문서에는 새 이미지/스프라이트가 없고 애니메이션 요구만 있다.

공통 애셋 검증: 64×96 캐릭터 몸체의 형태와 발 기준점을 유지한다. 장비·효과는 별도 여백에 그려 셀 경계에서 잘리지 않게 한다. FHD 실제 플레이 크기, 회색조, 겹치는 적 예고에서도 준비→유효→회수가 읽히는지 확인한다. 화면상의 후퇴 픽셀 수를 월드 이동 거리로 곧바로 쓰지 않는다.

| 검증 항목 | 결과 |
|---|---|
| 공식 1차 자료 본문/URL 확인 | 3건, 2개 개발사, 각 출처 요약 200단어 미만 |
| 캐릭터별 성향 | 4명 × 2 = 8, 전직 아님 |
| 신규 컨셉 | 4명 × 3 = 12, 직업당 공격/방어/유틸 각 1 |
| 개별 카드 필수 요소 | 식별자, 역할, 입력·예고·효과, 대가, 애니메이션, 재사용/신규, QA, 근거 포함 |
| v1 핀 6노드 보존 | 교체 없음. 핀 신규 3개는 후퇴 타격·넉백 억제·임시 표식으로 차별화 |
| 실게임 수치·데이터·코드 변경 | 없음. 컨셉 검증은 문서 QA이며 엔진 테스트 통과 주장 아님 |

**결정 경계:** 현재 즉시 필요한 주요 결정 없음. 컨셉을 실제 스킬로 채택할 때 슬롯 기회비용·수치·해금 위치를 검토한다. AI 조사, 임시 표식, 제작 UI 등 신규 구현을 첫 데모에 확대하거나 기존 고유 메커니즘을 잠그는 변경이 필요하면 해당 항목을 중단하고 사용자 결정을 요청한다. 특히 CX-M3/CX-B3은 선택 가치가 낮을 수 있다는 불확실성을 숨기지 않는다.
