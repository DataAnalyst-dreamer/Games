# 조합 전직·스킬 트리 v3

2026-09-13 · 사용자 요청을 반영한 **설계안**, 실행 구현 아님.

## 방향과 규모

기존 4인 고정 직업을 최종 성장 한계로 보던 v1/v2 초안을 대체한다. 핀·리라·모리·브람은 서사 인물이고, 직업은 플레이어가 선택하는 성장 결과다. 직업이 바뀌어도 출신·성격·스토리 역할은 바뀌지 않는다.

초기 설계 범위는 **기본 계열 8개, 단일 심화 직업 8개, 서로 다른 두 계열 조합 직업 28개**, 합계 36개다. 주/부 순서만 뒤집은 조합을 별도 직업으로 세지 않는다. 이것은 사용자가 숫자를 지정한 것이 아니라 다양성과 제작 가능성을 함께 고려한 제안이다. 향후 계열을 추가할 수 있는 데이터 구조로 둔다.

각 계열 12노드(액티브4·행동 변형4·패시브3·핵심 특성1), 계열 합계96노드. 여기에 조합 전직 고유 특성28개를 더해 **124개 성장 노드**를 설계한다. 124개의 별도 액티브/애니메이션을 완성했다는 뜻이 아니다. 실제 명세는 `mastery-nodes-v3.json`, `hybrid-classes-v3.json`에서 관리한다.

## 레퍼런스의 실제 구조와 우리 적용

- **PoE 1:** 공용 패시브 트리에서 출발 위치가 다르며, 스킬 젬에 연결하는 보조 젬이 행동을 바꾼다. 전직은 별도 전직 트리다. 따라서 ‘아무 스킬 두 개를 조합하면 자동으로 새 전직’이라고 설명하지 않는다. 우리는 공용 학습 가능성과 행동 변형의 원리를 가져오며 젬 거래·장비 소켓 RNG·거대 패시브 숫자를 복제하지 않는다. [공식 게임 소개](https://www.pathofexile.com/game), [공식 전직 안내](https://www.pathofexile.com/ascendancy/classes)
- **Titan Quest 원작:** 두 마스터리 선택, 마스터리 투자로 상위 단계 해금, 기본 스킬을 바꾸는 Modifier가 있다. 원작 매뉴얼 pp.25–28 기준이며 후속 DLC·TQ II의 현재 규칙과 혼합하지 않는다. 우리는 두 계열의 결합을 전직 정체성으로 삼고, 원작의 마스터리 선택 철회 불가 규칙은 채택하지 않는다. [공식 배포 매뉴얼](https://cdn.akamai.steamstatic.com/steam/apps/4540/manuals/TQManual_US.pdf)
- 라그나로크·랑그릿사·크루세이더 퀘스트는 [별도 판본별 조사](class-system-research-v3.md)를 따른다. ‘전직 분기’, ‘다른 분기에서 익힌 기술의 활용’, ‘고유 기술 간 연계’를 구별한다. 원작 스킬명·트리 배치·블록 전투나 가챠를 가져오지 않는다.

이하 규칙·직업·스킬은 우리 창작 제안이며 참조작의 사실 설명이 아니다.

## 8계열의 역할

| 계열 ID | 계열 | 핵심 선택 | 단일 심화 직업 |
|---|---|---|---|
| blade | 검술 | 근접 연격, 틈에 들어가고 빠지기 | 검성 |
| guard | 수호 | 방향·접지·방어 후 기회 | 성채수호자 |
| bow | 궁술 | 사거리·사선·정지 준비 | 명사수 |
| trick | 기교 | 위치·미끼·도구를 통한 틈 | 그림자보행자 |
| element | 원소 | 속성 순서·시전 위치·변환 | 대원소술사 |
| life | 생명 | 회복 타이밍·지속 구역·생장 | 생명의지기 |
| faith | 신앙 | 서약의 조건·보호·빛 | 서약인도자 |
| forge | 제련 | 차지·가열·설치물과 회수 | 명장 |

신앙은 새 종교·신·성물의 진실을 확정하는 설정이 아니다. 생명·신앙은 치유 역할이 겹치지 않게 각각 ‘시간/구역 유지’와 ‘조건/방향 약속’에 집중한다. 제련은 경제 무한 제작, 기교는 영구 은신으로 연결하지 않는다.

핀의 추천 출발은 검술/수호, 리라는 궁술/기교, 모리는 원소/생명, 브람은 제련/수호다. **추천이지 인물별 계열 잠금이 아니다.** 시작 지급·고유 기제 이전의 실제 값은 기존 세이브를 조사한 뒤 이관한다.

## 성장 흐름 — 제안

`기본 조작 습득 → 1계열 선택 → 1·2단계 기술 → 두 번째 계열 체험 → 조합 전직 또는 단일 심화 → 상위 기술·행동 변형으로 빌드 완성`

1. 모든 계열을 처음부터 도감에서 미리 볼 수 있지만, 학습 화면은 선택한 계열과 가까운 후속 노드부터 펼친다. 미해금 기술도 효과·선행·장비 제한·단점을 숨기지 않는다.
2. 동시에 활성화하는 계열은 최대2개다. 다른 계열을 시험해 본 기록은 보존하되, 비활성 계열의 노드·패시브가 전투에 누적되지 않는다.
3. 각 트리는 4단계로 확장한다. 선행 노드와 계열 내 **현재 투자량**을 함께 만족해야 한다. 단계 해금 수치·SP 획득량·최고 레벨은 플레이테스트로 결정하며, 누적 소비 이력을 이용한 환불 해금 편법은 허용하지 않는다.
4. 조합 전직은 두 계열을 선택하고 **각 계열의 1단계 액티브 하나 이상과 2단계 노드 하나 이상**을 배운 뒤, 공통 전직 체험 과제를 마치고 명시적으로 선택한다. 현재 트리의 액티브는 1·3단계에 있으므로 존재하지 않는 ‘2단계 액티브’를 요구하지 않는다. 전직 이름만 자동 표시하는 것이 아니라 고유 특성 선택이 열린다. 과제는 조합별 새 대서사 28개가 아니라 공격·회피·거리·상호작용의 검증 가능한 변주로 만든다.
5. 단일 심화는 다른 계열을 포기한 빌드다. 해당 4단계 핵심 특성을 사용할 수 있으며, 같은 시점의 총 SP 예산에서 조합 빌드와 비교한다. 단일 심화의 보상량은 미확정이다.
6. 한 빌드는 **단일 계열 핵심 특성 또는 조합 고유 특성 중 하나만 활성화**한다. 두 마스터리의 핵심 특성 두 개+조합 특성을 모두 쌓는 구조가 아니다.

## 스킬 조합과 조작

- 현재 조작과 첫 실행 테스트를 위해 액티브 슬롯2개를 기준으로 설계한다. 성장 노드가 많다는 이유로 모든 기술을 동시에 단축키에 추가하지 않는다. 기본 공격·가드·회피는 별도 기본 조작이다.
- 각 액티브는 배운 변형 중 **하나**를 연결한다. 연결 대상은 `modifies`로 명시하며 같은 색/원소라는 이유만으로 아무 스킬에나 붙지 않는다. 변형은 ‘부채꼴 대신 좁은 관통’, ‘즉발 대신 설치’처럼 행동을 바꾸고 대가를 가져야 한다.
- 조합 고유 특성은 조건-후속 행동을 연결하는 규칙이다. 무한 자동 시전이나 입력 없이 모든 스킬이 발동하는 루프를 만들지 않는다. 파생 피해/회복은 자신 또는 다른 특성의 발동 조건으로 재귀 집계하지 않는다.
- 전직 직업명이 특정 무기 애니메이션을 자동으로 생성하지 않는다. 스킬별 장비 태그를 검사하며 현재 무기로 사용할 수 없는 액티브는 설명과 함께 장착 불가 처리한다. 장비 교체를 통한 쿨타임/발동 횟수 리셋도 금지한다.
- 방패가 없는 궁술+수호는 사격 준비 자세·접지 패시브로 설계한다. 마법+검술은 검에 시전 모션을 얹는 후보로 분리한다. 여러 무기 기술의 동시 사용을 위해 보이지 않는 자동 무기 교체를 추가하지 않는다.

장비 보완안: ‘초점도구’는 스태프만 뜻하지 않고 허리의 시전 매개나 장비에 장착하는 촉매도 포함한다. 한손 무기+방패, 양손 활로도 시전할 수 있는 **명시적인 포즈**가 필요하다. 전투 중 원소 시전이 해당 무기의 공격/가드와 동시에 실행되지는 않는다. 검술+궁술은 검/활 두 무기 세트를 **플레이어가 수동 전환**하는 추가 기능이 있어야 완성된다. 전환은 회수 동작이 끝난 뒤에만 허용하고 슬롯 두 개와 각 스킬 쿨타임을 공유한다. 이 기능은 현재 미구현이며 자동 전환으로 우회하지 않는다.

설치 특성의 회수/방출은 해당 설치 스킬 슬롯을 다시 누르는 문맥 행동 후보로 둔다. 설치·회수·방출 상태를 UI에 표시하고, 3번째 숨은 액티브 슬롯을 요구하지 않는다. 원소+제련의 방출은 저장 완료 후에만 가능하다. 두 슬롯 안에서 이런 동작이 혼동된다면 슬롯 확장은 실제 조작 검증 후 사용자에게 확인한다.

## 탐험·아이템·적과의 연결

- 퀘스트 해결에 특정 전직/스킬을 반드시 갖추라고 요구하지 않는다. 힘으로 밀기·원소 반응 등 스킬별 편의 경로를 추가하더라도 관찰/기본 상호작용의 대체 경로를 남긴다.
- 아이템은 직업명 제한보다 `검/방패/활/초점도구`, `근접/투사체/시전/설치` 태그로 빌드를 지원한다. 희귀품 하나가 없어서 전직 자체가 불가능해지지 않게 한다. 신규 드롭·수치·제작식은 아직 반영하지 않는다.
- 기존 3종은 회피 가능 예고·접근·구역 위험 검증에 사용한다. 36직업을 위한 적 면역36종을 만들지 않는다. 보스에 통하지 않는 제어 기술은 피해/자세 유틸 등 대체 가치가 필요하다.
- 회복·방어도 단독 플레이에서 작동해야 한다. 파티원 존재를 전제로 한 특성, 무한 회복, 긴 준비 중 강제 피격을 QA 항목으로 둔다.

## 변경·환불·세이브

**D-142 사용자 결정:** 마을에서 계열 조합 재선택을 허용하되 **상당히 높은 골드 + 수집 아이템 + 가벼운 레벨다운**을 모두 요구한다. 레벨다운은 새 직업에 적응하는 초반의 서투름이다. 무료 자유 변경 제안은 이 조건부 방식으로 대체한다. [재전직 정책](retraining-policy-v1.md)에 비용 기준·재료 후보·레벨 회복·중복 성장 방지·저장 규칙을 정리했다. 구체적 금액/수량/하락 폭은 검토안이며 실행 반영 전이다. 같은 직업 내 스킬 재배분과 실제 계열 변경은 구분한다.

환불은 하위 노드부터 하거나 영향받는 노드를 일괄 되돌리는 미리보기를 제공한다. 부모만 제거한 고아 노드, 비활성 계열 잔존 패시브, 빈 슬롯의 유령 변형을 막는다. 기존 캐릭터 성장 저장소와 새 `mastery_ids`, `learned_nodes`, `active_slots`, `modifiers`, `identity_trait`, `schema_version`을 연결할 마이그레이션 검증이 필요하다.

## 단계별 실제 제작

| 단계 | 산출물 / 통과 조건 |
|---|---|

## 결정 경계

사용자가 지시한 ‘넓은 트리와 조합 전직’ 및 D-142의 유료·재료·레벨다운 조건을 반영한다. 8계열/36직업/124노드, 활성 계열2는 초기 설계 제안이다. 재전직 가능 여부와 세 가지 부담 조건을 다시 미결정으로 취급하지 않는다. 구체적인 밸런스 값·슬롯 확장·저장 데이터 이관에 필요한 판단은 실행 반영 전에 확인한다. 작업 중 이미지 생성은 즉시 공유하며 새로운 외형 정체성 선택이 필요할 때만 해당 아트를 멈춘다.
