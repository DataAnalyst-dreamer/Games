# 첫 데모 — 스토리·세계관 실행 초안 v1

2026-09-12 · 상태: 콘텐츠 검토용 제안, 게임 데이터 미반영

게임의 이름은 《이슬란드 연대기》를 유지한다. 크루세이더 퀘스트는 아트·캐릭터 표현의 참고작이지 새 게임명이 아니다. 사용자 확정 아트 조건은 핀 몸체 64×96, FHD 1920×1080이다. 이 문서는 새로운 왕국·종족·성물·주요 인물을 추가하지 않는다.

## 1. 확정 설정과 데모의 경계

| 확정 사실 | 근거 |
|---|---|
| 섬나라 이슬란드, 재의 날로부터 300년 후, 다섯 지방과 브릿지포트 | `docs/story/world-bible.md` 1장 |
| 마을의 결계 파편과 지역 보스가 지키는 성물의 핵은 다르다 | 같은 문서 2.2절 |
| 민들레 마을은 하틀랜드의 목축 마을이며 중심에 민들레 홀씨 모양 결계석이 있다 | 같은 문서 5.1절 |
| 핀은 유물 조사단 견습 기사이며 정해진 자리만 지키는 것에 회의를 품었다 | `docs/story/characters.md` 2.1절 |
| 본편은 도착→마을 습격→파편 반응→마을 확보→메아리 굴→후속 이야기 순서다 | `docs/story/main-storyline.md` 2장 |
| 메아리 굴은 지역 보스 던전이 아닌 튜토리얼용 소형 동굴이다 | 같은 문서 `main_a1_s06` |
| 첫 검증 규모는 20~30분, 플레이어 1명·NPC 3명·적 3종, 목적지 2경로·2해결법이다 | `docs/plans/cq-redesign-roadmap.md` T07~T12, GDD 1.2절 |

**검증용 발췌 제안:** 마을을 확보한 직후의 민들레 마을에서 출발하여 메아리 굴을 탐사하고 귀환한다. 정식 게임의 첫 30분 전체를 새로 정의하지 않는다. 시작 안내에 ‘마을 확보 이후 탐험 구간 테스트’라고 표시한다. 습격·성물 반응을 삭제하거나 이미 플레이했다고 속이지 않는다.

로드맵의 ‘유적’은 이 초안에서 메아리 굴의 오래된 석조 흔적을 표현하는 환경 제작 라벨이다. 독립된 신전이나 새 정식 지명을 추가하지 않는다. 동굴을 다른 던전으로 교체하는 결정을 하지 않는다.

## 2. 한 줄 목표와 인물 역할

**핀은 메아리 굴까지 안전하게 다녀올 길을 직접 찾는다. 더 많은 적을 쓰러뜨리는 것뿐 아니라 주변을 살피는 일도 누군가를 지키는 방법임을 경험한다.**

| 등장 인물 | 기존 역할 | 데모 역할 제안 | 넘지 않을 선 |
|---|---|---|---|
| 핀 | 씩씩한 견습 기사 | 검·방패와 관찰로 길을 개척한다 | 과거의 불안을 장문의 회상이나 새 비극으로 확장하지 않음 |
| 테오 | 유물 조사단장, 구조적 안내자 | 탐사 목적과 귀환 기준을 알려준다 | 성물의 새 능력이나 마녀의 진실을 폭로하지 않음 |
| 머루 할머니 | 여관지기 | 출발·귀환의 온기, 기존 저장 기능 안내 | 호감도 조건이 있는 축문 복선을 무료 대사로 옮기지 않음 |
| 로젤 | 청년 목자, 차기 원로 후보 | 목초지 길에 대한 관찰 힌트 | 성물에 대한 열등감을 이번 짧은 데모에서 완결하지 않음 |

핀 외 3명만 대사·상호작용 대상으로 삼는다. 다미·몽실이 퀘스트와 뭉치의 본편 이야기는 유지하되 이번 발췌에서 재작성하지 않는다. 이 데모는 본편의 감정선 전체 검증을 대체하지 않는다.

## 3. 20~30분 체험 구성 — 측정 전 목표치

| 구간 | 목표 시간 | 플레이 내용 | 확인할 감정·정보 |
|---|---|---|---|
| 마을 | 3~4분 | 조작 확인, 테오의 짧은 의뢰, 머루·로젤 선택 대화 | 돌아올 곳이 있고 출발 이유를 안다 |
| 필드 | 6~8분 | 멀리 보이는 동굴 입구로 두 경로 중 선택, 선택 전투·관찰 | 안내 화살표 없이도 목적지를 추론한다 |
| 메아리 굴 | 7~10분 | 하나의 장애물을 두 방법으로 해결, 상자와 표식 발견 | 전투와 관찰 모두 진행에 기여한다 |
| 귀환·재사용 | 4~8분 | 다른 경로로 귀환 가능, 발견한 정보를 다른 장소에 적용, 보고·저장 | 같은 장소를 다시 볼 이유가 생긴다 |

합계 20~30분은 플레이테스트 목표이지 현재 실행 가능한 분량이라는 뜻이 아니다. 시간을 맞추려고 강제 대기·반복 사냥·이동거리만 늘리지 않는다.

## 4. 경로 두 개와 해결법 두 개를 독립시킨다

### 두 진입 경로 — 환경 배치 제안

- **목초지 큰길:** 입구가 계속 보이고 방향 파악이 쉽다. 슬라임의 접근·뿔토끼의 돌진을 피하거나 싸우며 전진한다. ‘큰길로 가면 모든 적 처치’ 같은 숨은 문을 만들지 않는다.
- **언덕 가장자리 샛길:** 돌아가지만 낮은 적 밀도와 관찰 포인트를 제공한다. 버섯의 예고 동작과 식생의 빈 공간으로 통과 시점을 읽는다. 점프·수영 등 아직 없는 이동 능력을 필수로 요구하지 않는다.

두 길은 동굴 전면 공간에서 합류하며 양방향으로 오갈 수 있다. 샛길은 숨겨진 보상일 수 있지만 정답 암기가 필요한 비밀 벽으로 만들지 않는다. 마을에서 완전한 공략을 말하는 대신 동굴 입구·담장 틈·발자국으로 단서를 제공한다.

### 동일 장애물의 두 해결법 — 구현 제안

목표는 동굴 안쪽 상자로 통하는 통로의 개방이다. 두 진입 경로 어느 쪽에서도 아래 두 방법을 고를 수 있어야 한다.

| 방법 | 플레이 행위 | 같은 최종 상태 | 복구 조건 |
|---|---|---|---|
| 전투 접근 | 앞쪽의 적을 처리하고 그 뒤의 손잡이를 조작 | 통로 개방 | 적을 먼저 제거한 뒤 탐험해도 퍼즐·상자 유지 |
| 관찰 접근 | 주변의 낮은 우회 공간을 발견하고 반대편 손잡이를 조작 | 통로 개방 | 실패·이탈해도 손잡이는 소모되지 않음 |

두 손잡이를 모두 당길 필요는 없다. ‘안쪽 문은 적 전멸 AND 퍼즐 완료’로 구현하면 대체 해결법이 아니므로 실패다. 적은 문 열쇠를 떨어뜨리지 않으며 퀘스트가 전투를 은밀히 강제하지 않는다. 동일한 동굴의 공간적 우회만으로 검증하여 새 도구·물리 상자·속성 마법 시스템을 필수로 추가하지 않는다.

**실제 연결 주의:** 기존 퀘스트 `quest_main_a1_06_echocave`는 `object:echo_cave_puzzle_01` 상호작용과 `item:iron_ore` 수집을 사용한다. 두 방법의 성공을 같은 퍼즐 완료 이벤트로 연결하는 별도 검증이 필요하다. 문서 작성만으로 해당 분기가 구현됐다고 보지 않는다.

## 5. 다른 장소에서도 쓰는 발견 보상

**추가 아이템 대신 ‘정보’ 재사용 제안:** 동굴의 손잡이 옆에 반복되는 손잡이 방향 표식을 발견한다. 귀환길의 별도 작은 보관 공간에서 동일 표식을 보고 작동 가능한 손잡이를 알아낸다. 최초 발견 시 일지에 한 줄만 남기고 지식이 없어도 관찰·직접 조작으로 해결할 수 있다.

- 이 표식은 지역 배치 문법을 가르치는 시각 정보다. 새 고대 문자·종교·성물의 힘으로 설명하지 않는다.
- 동굴의 기존 보물상자 보상 `iron_ore`는 변경하지 않는다. 두 번째 공간의 수치 보상은 기존 승인 테이블을 재사용하고, 새 경제 수치는 여기서 만들지 않는다.
- 저장 후에는 정보 확인 여부·두 공간의 개방 여부·상자 수령 여부를 각각 복원해야 한다. 완료 상태를 하나로 뭉쳐 중복 보상이 발생하지 않게 한다.
- 정보 보상으로 T09 요건을 충족했는지는 실제 화면에서 사용자가 ‘아까 본 것과 같네’라고 연결하는지 확인해야 한다. 단순 장식 반복만으로 완료 판정하지 않는다.

## 7. 저장·순서·완료 검증 체크리스트

- [ ] 큰길→전투, 큰길→관찰, 샛길→전투, 샛길→관찰의 4조합 모두 통로를 연다.
- [ ] 테오 대사 스킵 이후에도 목표를 다시 읽을 수 있다.
- [ ] 선택 NPC를 만나지 않아도 진행 가능하고 손잡이 힌트는 환경에서 읽힌다.
- [ ] 적을 먼저 잡아도, 먼저 우회해도, 양쪽 손잡이를 순서대로 눌러도 완료는 1회다.
- [ ] 동굴 입구·통로 개방 후·상자 획득 후에 종료/재진입하여 상태를 검증한다.
- [ ] 귀환 정보 재사용은 발견 전에도 논리적으로 작동하며 발견 후에는 의미가 더 잘 읽힌다.
- [ ] 본편 퀘스트·세이브를 테스트 시작 상태로 덮어쓰지 않는다. 발췌 테스트는 격리한다.
- [ ] 실제 20~30분 소요와 FHD 말풍선·랜드마크 가독성은 사용자 실행 테스트로 측정한다.

## 8. 보류·결정 경계와 정합성 메모

이 문서는 구현할 수 있는 초안을 제공하지만 메인 스토리 순서·지방 지도·주요 인물 설정을 승인 없이 바꾸지 않는다. 발췌형 데모를 정식 오프닝으로 대체하거나 메아리 굴을 새 유적으로 교체하려면 그 지점에서 사용자 결정 후 진행한다. 현재는 그러한 변경 없이 작업 가능하다.

기존 문서의 정합성 이슈도 별도 보류한다. `world-bible.md` 1.6절에는 ‘전원 대륙 출신’과 브람의 이그니스 출생·귀향이 함께 적혀 있다. 또한 같은 문서 7.1절 폭로 시점은 `main-storyline.md`의 세 번째 성물 회수 시점과 일치하지 않는다. 핀 중심 메아리 굴 발췌에는 영향을 주지 않아 원본을 임의 수정하지 않았다. 장기 본편·브람 콘텐츠 확정 전 확인이 필요하다.

구현 근거: `game/data/quests/act1_hartland.json`, `game/data/world_objects.json`, `docs/story/quests-act1-hartland.md` MQ06. 이 초안은 기존 ID를 참조했지만 코드·퀘스트·대사 데이터를 변경하지 않았다. 전체 본편 내러티브 검증 완료나 실행 테스트 통과를 의미하지 않는다.
