## 통합 확인

- 정면 모션 실행 테스트(`prototypes/fin-front-test`)와 이 콘텐츠 데모는 별개다. 콘텐츠 초안은 아직 실행 씬에 들어가지 않았다.
- 세 문서의 주인공·64×96 몸체·FHD 화면 기준과 기존 세계관을 유지한다. 성장 체계는 최신 v3에 따라 새로운 조합 전직으로 확장하며, 과거의 직업 추가 금지 범위는 더 이상 적용하지 않는다.
- 정보 재사용을 현재 탐험 보상 검토안으로 삼고 신규 도구 아이템은 선택지로 보류한다.
- 스킬 문서의 공격·구르기·가드 검증은 후속 본 게임 통합 테스트이며, 현재 정면 테스트에 구현된 기능이 아니다.
- 스토리 문서의 ‘유적’은 기존 메아리 굴의 환경 표현이지 새로운 정식 지역 추가가 아니다.

## 결정이 필요해지는 경계

조합 전직·많은 스킬의 설계는 사용자의 최신 요청에 포함된다. **마을 재전직의 높은 골드·수집 아이템·가벼운 레벨다운 세 조건은 D-142 사용자 결정**이며, 정확한 금액·수량·하락 폭과 실제 반영은 아직 미정이다. 직업 자격/환불·적응 재통과 보상 방지·현재 HP/스태미나 처리도 재전직 정책의 구현 전 설계 가정이다. 새 조작의 실제 반영, 새 탐험 도구, 본편 시작 순서 변경, 기존 무적/장판 규칙 변경에 필요한 결정은 적용 전에 확인한다. 원본의 브람 출신·후반 폭로 시점 불일치도 해당 본편을 확정하기 전에 확인한다. 승인 전에는 관련 실제 데이터 변경을 멈춘다.
