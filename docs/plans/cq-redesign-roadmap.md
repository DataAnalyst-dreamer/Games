# 크루세이더 퀘스트 방향 리디자인 — 순차 작업 목록

2026-09-12 · 기준 GDD v1.2 / D-136~D-138 · 작업 브랜치 `stage/astra-cq-redesign-01`

## 목표

젤다 같은 탐험 자유도 + 크루세이더 퀘스트를 참고한 캐릭터·SD 도트·표현력 있는 액션. 2D 탑다운 직접 조작과 섬나라 세계관 유지. 첫 제작 단위는 20~30분의 마을–필드–유적이며 플레이어1, NPC3, 적3이다. 전체 출시 규모·새 경제 수치는 이 데모 평가 후 결정한다.

## 순서와 완료 조건

2026-09-13 상세 추적은 [중앙 작업 관리표](master-work-register.md)를 따른다. 아래 T01~T12는 상위 완료 게이트이며 ‘대기’는 아트 시안·문서의 독립 병렬 준비까지 중단했다는 뜻이 아니다. 몬스터3·소품2 시안, 뿔토끼 알파v2, 콘텐츠/성장/재전직 설계가 준비되었으나 본 게임 적용 완료와 구분한다. 핀 핵심 포즈는 편집 원본·제작 경로 선택 대기이며, 정면 FHD 프로토타입 실행을 본 게임 FHD 이관 또는 4방향 보행 완료로 집계하지 않는다.

최신 실행 산출물: `prototypes/fin-front-test` 정면 FHD 테스트가 실행 가능하다. `../qa/fin-first-execution-test.md` 참고. 정면 동작 블로킹 단계이며 T04 전체 4방향 완료나 T12 콘텐츠 데모 완료는 아니다. 병렬 콘텐츠 초안은 `../content-drafts/README.md`에 묶었다.

후속 사용자 검토: 다리 분리·압축 모션의 연결 결함으로 정면 동작 품질은 미통과. 기술 검사 통과와 구분하며, 해당 변형 방식으로 에셋 확장을 진행하지 않는다. 제작 방식 리서치 이후 다음 아트 작업을 정한다. 스토리·퀘스트·직업·스킬·몬스터·아이템의 리서치 기반 소재 작성은 독립적으로 병렬 진행한다.

## 시안 이후 제작 시 주의점

- 기존 시트 규격과 신규 시트 규격을 같은 것으로 추정하지 않는다. 애셋마다 방향·프레임·피벗을 명시한다.
- 960×540 자체가 시야 타일 수를 정하지 않는다. 최종 시야는 viewport / camera zoom / tile size로 계산한다. 현재 640×360, camera zoom=2, 16px tile의 가로 시야는 20타일이다.
- 새 아트의 공격 준비 모션에 맞춰 hitbox 시작/종료를 정의한다. 이미지 파일 교체만으로 완료 처리하지 않는다.
- 실루엣·색면·반동을 우선하고, 부드러움을 위해 무조건 중간 프레임만 늘리지 않는다.
- 기존 테스트의 기대값을 그대로 신뢰하지 않는다. T02의 과거 스모크는 잘못된 시트 해석을 정답으로 검사하고 있었다.

## 후속 기획 쟁점

24/72시간 실제 플레이 리스폰과 현실 자정 일일 의뢰의 혼용, 성장으로 사실상 막히는 탐험, 퀘스트 선택 결과의 표현은 T09 전에 작은 데모 기준으로 재설계한다. 현재 세이브·경제에 영향을 주는 일괄 수치 변경은 이번 T01~03에서 수행하지 않는다.
