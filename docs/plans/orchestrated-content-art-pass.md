# 콘텐츠·아트 병렬 제작 패스

## 2026-09-13 결과와 변경

- 콘텐츠: 퀘스트6·발견4, 조우6·아이템12 문서 작성. 직업12개 컨셉 초안 이후 새 사용자 요구에 따라 [조합 전직 v3](../content-drafts/research-expansion/class-progression-v3.md)로 확장, 8계열96노드+28조합특성 작성. 기존4직업 한계 폐기.
- 아트: 핀 접지1·몬스터3·소품2 [시안 공유](../art/preview/parallel-pass/README.md). 5장은 실제 알파가 없고 핀 포즈도 접지/동일성 미통과. 런타임 교체 없음. 실패한 다리 절단 방식 재사용 없음.
- 검수: 작성자와 다른 에이전트가 교차 비판 검토. 불가능한 전직 단계 조건·생명 구역 종료 충돌·장비 제약·발동 행동 누락을 찾아 수정. 구조 검사와 시각/전투 품질은 별개로 기록.
- 다음 게이트: 핀은 편집 가능한 원본에서 연결된 핵심 포즈를 확보해야 한다. 직업은 단면 설계·SP/세이브/장비/조작 정책 확인 후 실행에 연결한다. 콘텐츠 전체와 직업36개가 이미 플레이 가능하다는 뜻이 아니다.

사용자 지시: 오케스트레이터가 전체 조율·교차 검토·공유를 담당하고 서브 에이전트가 독립 산출물을 제작한다. 주요 선택이 필요하면 해당 작업을 멈추고 질문한다. 새 시안·실행 화면은 생성 사실과 한계를 함께 공유한다.

## 담당과 순서

| 작업선 | 콘텐츠 패스 | 아트 패스 |
|---|---|---|
| 스토리 담당 | 외부 리서치 → 퀘스트6·발견4 | 아이콘/환경 소품 시안 |
| 몬스터 담당 | 생태·공예 리서치 → 조우6·아이템12 | 일반 적3종 정지 시안 |
| 직업 담당 | 전투 설계 리서치 → 4인 성향·스킬12 | 핀 핵심 걷기 포즈 재제작 |
| 오케스트레이터 | 설정·ID·범위 교차 검토, 통합 문서 | 결과 직접 확인, 결함·규격·출처 검토, 사용자 공유 |

동시 슬롯 제약에 따라 각 콘텐츠 초안을 마친 담당부터 아트 작업에 배치한다. 각각의 스크립트·에셋·문서 경로를 분리해 동시에 같은 파일을 덮어쓰지 않는다.

## 현재 확정 아트 기준

- 핀 몸체64×96, FHD1920×1080. 장비·모션 패딩 별도.
- 기존 정면B의 외형 유지. 현재 다리 절단·압축 방식은 결함 확인으로 사용 중단.
- 모션의 핵심 포즈를 먼저 검토한다. 단순히 프레임 수/투명 배경 검사가 통과했다고 동작 품질을 통과시키지 않는다.
- 새 몬스터와 소품은 검토 시안부터 시작한다. 일반종/정예를 혼동시키는 장식이나 새로운 능력을 아트만으로 확정하지 않는다.
- 시안 그림, 규격 정리 후보, 최종 런타임 에셋의 상태를 명시한다. 새 시안을 자동으로 기존 게임에 적용하지 않는다.

## 승인 경계

캐릭터 정체성/의상 변경, 새 몬스터 종 또는 새 주요 지역, 신규 아이템 효과/드롭/경제 변경, 새 직업·스킬 채택은 사용자 결정 전에 확정·반영하지 않는다. 기존 범위 안의 원화 초안·동작 포즈·소품 시안·콘텐츠 아이디어는 작성 후 공유한다.

AI 이미지 도구가 정확한 프레임 연결이나 픽셀 규격을 충족하지 못하면 그 사실을 기록한다. 완성도를 과장하거나 실패한 절단 모션을 다른 이름으로 다시 적용하지 않는다.
