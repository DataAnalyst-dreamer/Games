최신 작업 세션: [배우·무기 미술 통일 패스](unified-art-pass-20260914.md). 선행 실행은 [쿼터뷰 비교 파일럿](quarter-view-pilot-20260913.md)이다. 기존 본편 준비 결과는 [후속 개발 패스](next-pass-20260913.md)이며 새 시점 실험과 구분한다.

## 운영·상태 기준

오케스트레이터의 역할은 **분해·누락 추적·충돌 조정·품질 게이트·사용자 승인 관리**다. 전문 담당이 문서·아트·코드·검증 산출물을 제작한다. 아래 담당은 역할 배정이며 에이전트가 현재 실행 중이라는 뜻이 아니다. 이 문서 작성 완료 후 백그라운드에서 계속 작업한다고 약속하지 않는다. 실제 실행 여부는 별도 작업 세션에서 확인한다.

상태 표기: `문서`=설계 산출물, `아트`=이미지 생성, `검수`=한정 검사, `적용`=본 게임 연결, `실행`=해당 동작 실제 검사. 한 단계의 완료를 다음 단계 완료로 올리지 않는다. `대기`는 미작업 또는 선행조건 대기, `보류`는 품질 실패·선택 필요다. 이미 존재하는 프로토타입 기능과 이번 리디자인 적용은 구분한다.

선행조건 열의 작업 ID는 완료가 필요한 단방향 선행이다. 반복 협의는 아래 공동명세 참조로 분리하며 선행 간선으로 세지 않는다. **문서 명세 동결 → 개별 단면 → 통합 검사** 순서다. 공동명세 참조: C03↔A11(퀘스트/소품 상태), C04↔A12(아이템/아이콘), C06↔R01(성장/재전직), C07↔R06(성장 저장 인터페이스). C07 단면은 동결된 저장 인터페이스·테스트 저장소로 먼저 만들고 실제 거래/이관 검사는 R06 및 B03에서 완료한다. C03/C04의 후속 연결 검수도 A11/A12 산출 후 B02/B03 통합에서 수행한다.

확정: 핀 외형·몸체64×96, 게임 FHD1920×1080, 크루세이더 퀘스트 기반 SD 표현, 조합 전직 확장 방향. 기존 본편은 직접 조작 탑다운이며 D-143으로 별도 고정 2D 쿼터뷰 비교 샘플만 승인됐다(전체 전환 미확정). D-142의 **마을 재전직+높은 골드+수집 물품+가벼운 실제 레벨다운**도 사용자 지정이다. 8계열/36직업/124노드, 재전직 가격·수량·1~2레벨 및 기본2레벨은 설계 제안이지 전체 승인·실행 완료가 아니다.

## 다음 관리 게이트

1. **AI 중심 핀 제작 경로 조사(A01)**: 최신 사용자 요청에 따라 외주 의뢰는 보류하고 AI 제작 도구의 동일성·연속 프레임·편집·내보내기 시험 경로를 조사한다. 외형·몸체64×96·FHD는 유지한다. 계정 연결·비용 발생·외부 서비스 자료 전달은 먼저 확인한다. 도구 소개나 접근 가능성만으로 보행 품질·제작 경로 확보를 완료 처리하지 않는다. 기존 다리 절단/압축과 독립 생성 아틀라스의 실패도 그대로 남긴다.
2. **아트 생성→게임 적용 사이 누락 방지**: 뿔토끼v2 투명화는 전수측정 완료지만 프린지·실제 표시·모션 미검증. 표지/천도 상태별 환경 자산과 인벤토리 아이콘을 별개로 관리한다.
3. **성장 문서→실제 레벨/세이브 사이 누락 방지**: 가격·재료·경험치 곡선·SP지급원장·거래 원자성이 모두 선행되어야 재전직 실행 완료다. JSON 구조 PASS만으로 올리지 않는다.

대표 차단사항은 **핀 프레임을 제대로 제작할 원본·편집 경로 부재**와 **실제 성장/경제/세이브 데이터에 대한 통합 검토 미완료**다. 오케스트레이터가 직접 산출물 제작으로 이를 덮지 않고 전문 담당의 근거·검수·승인을 관리한다.

인계 완료 확인(문서 단계만): 재전직 정책 E11의 ‘자격·현재 자원·재통과 보상 안전장치’에서 직업 자격/현재 투자량 재검사, 현재 HP·스태미나 초과분 제한, 적응 재통과 시 전량회복 포함 중복 이벤트 차단을 실제 파일로 확인했다. E04 인덱스에도 뿔토끼v2 링크·원본 보존·반투명 프린지·미적용 상태가 반영됨을 확인했다. 따라서 두 담당의 문서/메타데이터 보완은 완료이며, R04~07 실행 검사와 E05 게임 배경 합성·모션 검수는 여전히 미완료다. 에이전트 지속 실행을 뜻하지 않는다.

현재 파일은 관리용 문서다. 새 게임 데이터·실제 골드/아이템/레벨·세이브를 수정하지 않았다. 관리표상 ‘대기’ 항목을 수행하려면 후속 실행 작업을 명시적으로 시작하고, 신규 이미지/게임 화면은 작성 시 공유하며 중요한 선택은 해당 작업을 멈추고 확인한다.
