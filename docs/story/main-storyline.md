## 0. 로컬라이징 key 규칙

씬마다 접두어를 고정한다. 실제 JSON(`game/data/dialogue/`)은 다음 단계에서 이 key를 그대로 옮긴다.

```
main_a{막}_{지방코드}_s{씬번호}_{용도}_{일련}
```

| 지방코드 | 지방 |
|---|---|
| (없음, 1·3막) | 하틀랜드 공용/첨탑 |
| htl | 하틀랜드 |
| eld | 엘드우드 |
| frs | 프로스트헤임 |
| smr | 사마르 |
| ign | 이그니스 |
| brp | 브릿지포트 |

예: `main_a1_s03_npc_alarm_01`(1막 3번째 씬, NPC 경고 대사 1번), `main_a2_eld_s02_boss_taunt_01`. 회차 전용 대사는 `main_ng_` 접두어.

## 1. 전체 구조도 — "독립 완결 조각 + 공유 감정축"

**공유 감정축(한 문장 정의)**: 한때 이름과 사랑을 가졌던 존재가 안개 속에서 괴물이 되었다는 사실을 다섯 지방에서 되풀이해 배우고, 그 배움이 결국 '재의 마녀' 자신에게도 그대로 적용된다는 것을 깨닫는 것.

- 2막의 다섯 지방은 서로 참조 없이도 완결되는 **독립 조각**이다(도입-갈등-회수의 3단 구조를 각자 안에서 닫는다). 어떤 순서로도, 몇 개만 골라도 이야기가 무너지지 않는다(D-30, GDD 7.5 "2막 성물 5개는 자유 순서").
- 다섯 조각을 관통하는 **공유 축**은 "성물 회수"가 아니라 "괴물에게도 사연이 있었다"는 반복된 배움이다. 이 반복이 쌓일수록(회수한 성물 개수 기준, 어느 지방인지는 무관) 중반 폭로(4장)와 3막 최종전의 정서적 낙차가 자동으로 쌓이도록 설계했다.
- 각 지방 절 말미의 "순서 분기 대사"는 이 축이 실제로 순서를 인지하고 있다는 것을 플레이어에게 증명하는 장치다(테오의 우편, 3장 참조).

```
[1막: 출항] (고정 순서)
 섬 도착 → 습격=튜토리얼 전투(D-26) → 성물 파편 반응 → 마을 확보 → 첫 던전 → 톤 계약 서브퀘스트 → 2막 개방
                                                                              │
                                                                              ▼
[2막: 다섯 성물] (자유 순서 — 아래 5개, 어떤 조합·순서든 가능)
 ┌───────────┬───────────┬─────────────┬───────────┬─────────────┐
 │ 하틀랜드  │ 엘드우드  │ 프로스트헤임 │ 사마르    │ 이그니스    │
 │ (뭉치)    │ (올드바크)│ (서리늑대왕) │ (골렘)    │ (재의 드래곤)│
 └───────────┴───────────┴─────────────┴───────────┴─────────────┘
                    │ 완료 순서 무관, "3번째 성물 회수" 시점에 자동 발동
                    ▼
        [2막 중반 폭로] 브릿지포트 · 오델의 문서고 (4장)
                    │ 나머지 지방은 계속 자유 진행
                    ▼
[3막: 재의 마녀] (고정 순서, 성물 5개 회수 시 개방 — GDD F5-1)
 첨탑 진입 → 재판정의 흔적 → 나선 계단(다섯 유품) → 처형대 → 최종전(3페이즈)
                    │
                    ├─ 마녀의 기억 5/5 ─▶ 진 엔딩 (D-19)
                    └─ 마녀의 기억 <5 ─▶ 노멀 엔딩
```

| 막 | 순서 | 플레이 목표 | 톤 |
|---|---|---|---|
| 1막 | 고정 | 튜토리얼·거점 확보·서사 톤 계약 | 밝음 → 짧은 반전 → 온기 |
| 2막 | 자유(5개 중 순서 무관) | 오픈월드 본편, 파밍·육성 중심 | 지방별로 밝기 편차(7.1 톤 가이드 준수 — 이그니스·엘드우드에 무게 집중) |
| 3막 | 고정 | 최종 던전, 엔딩 분기 | 무겁지만 "여운"으로 회수 |

## 2. 1막: 출항

민들레 마을 습격을 튜토리얼 전투로 배치하라는 D-26을 그대로 따른다. 신규 기능 NPC **테오**(유물 조사단장, 중년, 인간, 하틀랜드 팔레트와 무관한 외지인 어투)를 도입해 1막의 안내자 역할을 맡긴다 — 개인 서사는 만들지 않고 오직 구조적 기능(안내·성물 지식 제공·2막 개방 트리거)만 수행한다.

### main_a1_s01 — "안개 건너 뭍으로"
- **장소**: 브릿지포트 부두
- **등장**: 주인공, 테오(조사단장), 항구 인부들(무명)
- **목표**: 이동·상호작용 튜토리얼(전투 없음)
- **핵심 대사**(테오):
  - "다 왔다, 이슬란드야."
  - "안개가... 예상보다 짙군."
  - "짐부터 챙기자."
- **연출**: 안개 이모지(🌫️) 배경, 소품 — 주인공이 목에 건 정체불명의 낡은 파편 목걸이(클로즈업 없이 아이콘으로만 암시)
- **게임플레이 훅**: 이동/카메라/상호작용 튜토리얼
- **복선**: 아니오

### main_a1_s02 — "초원으로 가는 길"
- **장소**: 하틀랜드 진입로 → 민들레 마을 어귀
- **등장**: 주인공, 테오, 머루 할머니(여관지기, 기능 대사만), 로젤·핀토(원경 등장, 대사 없음)
- **목표**: 평화로운 마을 첫인상 — 습격 전 "지킬 것"을 눈에 담아두기
- **핵심 대사**(머루 할머니):
  - "손님이 다 있네."
  - "밥은 먹었수?"
  - "얼른 앉으라니까."
- **연출**: 밝은 톤, 이모지(😊), 빨래 널린 마당·닭 쫓는 아이 등 생활 소품으로 평온함을 과시(대비 효과용 사전 포석)
- **게임플레이 훅**: 없음(순수 탐험/연출), 마을 시설 위치 안내
- **복선**: 아니오

### main_a1_s03 — "그림자가 내려앉다" (습격 = 튜토리얼 전투, D-26)
- **장소**: 민들레 마을 광장·외곽
- **등장**: 주인공, 안개에 물든 들짐승 무리(약체 몬스터), 테오, 로젤
- **목표**: 기본 공격·구르기·가드 튜토리얼(약체 몬스터 3~4마리 처치)
- **핵심 대사**(로젤, 경보):
  - "짐승들이 이상해!"
  - "안개가 짙어졌어!"
  - "다들 피해!"
- **연출**: 사이렌 대신 마을 종소리 SFX, 화면 가장자리 잿빛 안개 파티클 침입, 표정 이모지(😨→😤)
- **게임플레이 훅**: 전투 튜토리얼(공격 3콤보·구르기·가드 순차 입력 유도)
- **복선**: 아니오(단, 습격 몬스터 중 하나가 마을 아이의 옛 반려동물이었다는 설정은 s07에서 회수)

### main_a1_s04 — "파편이 답하다" (성물 파편 반응)
- **장소**: 민들레 마을 중심 결계석(민들레 홀씨 모양) 앞
- **등장**: 주인공, 테오, 로젤, 마을 원로 1인(무명)
- **목표**: 결계석에 접근 시 주인공만 파편이 공명하는 사건 목격
- **핵심 대사**(테오):
  - "...방금 그거 봤나?"
  - "결계석이 울렸어."
  - "너한테만."
- **핵심 대사**(로젤, [세계관 바이블 5.1 설정 — 개인 서사는 characters.md 소관이므로 감정 묘사 없이 사실 전달만]):
  - "나는 반응 없는데."
  - "왜 너만..."
- **연출**: 결계석 짧은 발광 이펙트, 로젤 표정 이모지(😳)
- **게임플레이 훅**: 없음(컷 연출, 스킵 가능)
- **복선**: **예** — "성물지기" 개념이 여기서 최초 언급(테오가 옛 조사 자료에서 아는 척 설명하는 대사로, 4.3 복선표 진입 전 사전 정보 제공). 축문 문구는 아직 등장시키지 않는다(과다 노출 방지).

### main_a1_s05 — "마을을 되찾다" (마을 확보)
- **장소**: 민들레 마을 전역
- **등장**: 주인공, 잔당 무리(습격 우두머리 격 정예 몬스터 1체 — "덩치 뿔토끼"급), 마을 사람들
- **목표**: 잔당 소탕, 마을 완전 확보 → 대장간·상점·여관·게시판 등 시설 개방
- **핵심 대사**(머루 할머니, 종료 후):
  - "그래, 살았구나."
  - "국이나 먹자."
- **연출**: 전투 종료 후 마을 불빛이 하나둘 다시 켜지는 연출(어두운 색조 → 원래 팔레트 복귀)
- **게임플레이 훅**: 첫 정예 몬스터 전투, 클리어 시 마을 시설 오픈 + 오토세이브(막 완료 기준과 별개, 구간 완료 세이브)
- **복선**: 아니오

### main_a1_s06 — "메아리 굴" (첫 던전)
- **장소**: 하틀랜드 외곽 소형 동굴(지역 던전이 아닌 별도 튜토리얼용 미니 던전)
- **등장**: 주인공, 테오(입구까지 동행 후 대기)
- **목표**: 스킬 슬롯·퀵슬롯 사용 튜토리얼, 소형 퍼즐 1개, 보물상자 1개
- **핵심 대사**(테오, 입구):
  - "여긴 나 혼자 못 가."
  - "네가 다녀와."
  - "조심히."
- **연출**: 동굴 내 반딧불형 발광 이끼로 길 안내(가독성 우선)
- **게임플레이 훅**: 스킬 슬롯 사용, 첫 스킬 포인트 획득처, 퀘스트 로그 튜토리얼
- **복선**: 아니오

### main_a1_s07 — "몽실이를 찾아서" (톤 계약 서브퀘스트, 1막 말미)
리서치 01의 "튜토리얼 직후 가벼움 뒤 반전형" 배치. 세계관 바이블 7.1절이 지목한 '뭉치' 서사(2막 하틀랜드 본편)의 **예고편** 역할만 하고, 뭉치 자신과의 전투·작별은 2막 본편에 남겨 중복을 피한다.

- **장소**: 마을 외곽 목초지 → 안전지대 경계
- **등장**: 주인공, 마을 아이 다미(1회성 기능 NPC), 안개에 옅게 물든 아기 뿔토끼 한 마리
- **목표**(가벼운 도입): 다미의 잃어버린 애완 뿔토끼 "몽실이"를 찾아달라는 의뢰
- **전개**(작은 반전): 안전지대 경계에서 발견한 몽실이는 이미 안개에 옅게 물들어 두 눈이 뿌옇다. 공격성은 없고, 다미를 보자 도망치기 바쁘다.
- **핵심 대사**(다미):
  - "몽실아, 나야!"
  - "왜 도망가..."
  - "무서운 거야?"
- **핵심 대사**(주인공, [캐릭터별 분기]): 몽실이를 잡을지, 그냥 놓아줄지 선택지 제공(전투 강제 아님 — 붙잡기 미니게임 or 대치 후 퇴각)
- **마무리**(뭉클함 회수): 몽실이는 결국 숲 너머로 사라진다. 다미는 울지 않고, 대신 목초지 쪽 안개를 가리키며 조용히 말한다.
  - "저 안개 속에..."
  - "몽실이 같은 애들이..."
  - "또 있을까?"
- **연출**: 다미 표정 이모지(😢→🙂, 억지 웃음), 몽실이 퇴장 시 페이드아웃(추격 없음)
- **게임플레이 훅**: 사이드 퀘스트(비전투 or 저강도 추적), 보상은 소량 골드+요리 재료(하틀랜드 지역 사이드 퀘스트 보상 테이블과 공유)
- **복선**: **예** — "안개에 물든 것들도 원래는 무해했다"는 공유 감정축의 최초 체험판. 2막 하틀랜드 본편(뭉치) 및 4개 지방 보스 전원에게 그대로 적용되는 패턴을 여기서 처음 심는다.

### main_a1_s08 — "다섯 개의 길" (2막 개방)
- **장소**: 민들레 마을 결계석 앞 (s04와 동일 장소, 대비 연출)
- **등장**: 주인공, 테오, 마을 원로
- **목표**: 성물 파편 다섯 조각의 존재와 위치(다섯 지방)를 공표, 월드맵 개방
- **핵심 대사**(테오):
  - "다섯 지방 모두에..."
  - "성물이 잠들어 있대."
  - "어디부터 갈래?"
- **연출**: 월드맵 UI 오픈 연출과 동기화(다섯 지방 아이콘이 순서 없이 동시에 밝아짐 — "자유 순서"를 시각적으로 각인)
- **게임플레이 훅**: 월드맵 전체 개방, 메인 퀘스트 로그에 5개 지역 퀘스트 동시 등록(순서 무관, GDD F5-1)
- **복선**: 아니오

## 3. 2막: 다섯 성물

각 지방은 **도입 → 갈등 → 성물 회수**의 3단 구조로 독립 완결된다. 성물 회수 직후 해당 '마녀의 기억'이 열리며(4.4절 세계관 바이블 표 그대로), 완료 순서에 따라 안내자 **테오의 우편**(마을 우편함, GDD 7.4) 대사가 달라진다 — 새 NPC를 지방마다 만들지 않고, 이미 확보된 우편함·테오 캐릭터를 재사용해 "순서를 알아채는 서사"를 구현한다.

> 공통 로컬라이징 규칙: 지방 코드 + `letter_teo_first_0X`(그 지방이 플레이어의 1번째 성물일 때) / `letter_teo_last_0X`(5번째, 즉 마지막일 때). 2~4번째로 완료할 경우는 중립 대사(`letter_teo_mid_0X`, 본문 생략 — 담당 산출물 표에만 기재)로 채운다.

### 3.1 하틀랜드 — 새벽뿔피리 · 거대 슬라임 킹 '뭉치'

**로그라인(확장)**: 온순했던 마을의 늙은 반려 슬라임 '뭉치'가 거대한 괴물이 되어 돌아왔다 — 아이들은 지금도 그를 뭉치라고 부른다. 1막 말미(몽실이)에서 배운 것을 이번엔 되돌릴 수 없는 규모로 다시 배운다.

| 단계 | 장소 | 핵심 내용 | 게임플레이 훅 |
|---|---|---|---|
| 도입 | 목초지 경계 | 가축 실종 신고 누적, 아이들은 "뭉치가 돌아왔다"고 기뻐하지만 어른들은 두려워한다 | 필드 탐색, 목격 단서 수집 |
| 갈등 | 안전지대 밖 습지 | 정예 몬스터(뭉치의 "새끼" 격 분열체) 격파, 로젤이 "괴물이면 처치해야 한다"와 "그래도 뭉치다"는 마을 여론 사이에서 갈등하는 것을 목격(개인 서사는 characters.md) | 지역 던전 입구까지 필드 보스급 소전투 |
| 성물 회수 | 지역 던전 '민들레 뿌리굴' | 거대 슬라임 킹(뭉치) 전투 — 방어만 하고 공격하지 않는 구간에 움직임이 느려지는 패턴(세계관 바이블 5.1) | 지역 던전 30~40분, 보스 3페이즈 |

- **핵심 대사**(로젤, 던전 앞): "뭉치… 미안." / "그래도 가야 해." / "다녀올게."
- **지역 보스전의 서사적 의미**: 공유 감정축의 **개시 선언** — "처치가 아니라 작별"이라는 이 게임 전체의 보스전 문법을 여기서 처음 명문화한다. 전투 중 저항을 멈추면 느려지는 패턴은 "싸우지 않아도 되는 순간이 있다"는 것을 손맛으로 가르친다.
- **성물 회수 직후 '마녀의 기억' 획득 연출**: 뭉치가 사라진 빈터로 돌아오면 새벽뿔피리 핵이 옅게 빛난다. 손을 대는 순간 세피아톤 도트 회상(1~2분): 어린 셀라가 임명식에서 새벽뿔피리를 받는 장면, "손을 내밀지 않으면 아무것도 태어나지 않는다"는 축문이 **처음으로 진짜 맥락**에서 들린다(4.3 복선표 #1 회수 지점 아님 — 이건 진짜 원본, #1은 그 문구가 왜곡되어 전해진 결과물).
- **공유 감정축에 더하는 것**: "작별해도 된다"는 최초의 허락.
- **순서 분기**:
  - 첫 번째로 완료 시(`main_a2_htl_letter_teo_first_01`): "정말 다섯 조각 중 하나가…" / "맞구나, 진짜였어." / "나머지도 부탁해."
  - 마지막(5번째)으로 완료 시(`main_a2_htl_letter_teo_last_01`): "이걸로 다 모였어." / "제일 가까운 델 두고…" / "왜 마지막이었을까."

### 3.2 엘드우드 — 이끼눈동자 · 고목 정령 올드바크

**로그라인(확장)**: 숲의 요정들이 안개 속에서 부르는 자장가를 따라가면 다시는 돌아오지 못한다 — 그 노래는 아주 오래전 누군가를 위로하려던 것이었다.

| 단계 | 장소 | 핵심 내용 | 게임플레이 훅 |
|---|---|---|---|
| 도입 | 반딧불 마을 | 최근 실종자 발생, 마을은 "노래를 따라가지 말라"는 금기를 재확인하는 반딧불제 준비 중 | 마을 탐색, 윌로·페른 기능 대사(개인 서사 제외) |
| 갈등 | 언다인 호수 안개 미로 | 랜턴 필요 기믹, 노래에 흘려 실종된 마을 사람 흔적 추적 | 랜턴 기반 미로 탐험, 안개 몬스터 전투 |
| 성물 회수 | 지역 던전 '가라앉은 뿌리' | 고목 정령 올드바크 전투 — 자신도 잊은 자장가를 무의식중에 흥얼거리며 싸운다 | 지역 던전, 청각 단서 기반 패턴(흥얼거림 박자에 공격 예고 동기화) |

- **핵심 대사**(윌로, 미로 진입 전): "노래가 들려도…" / "따라가지 마." / "네 노래를 불러."
- **지역 보스전의 서사적 의미**: 아름다운 것과 위험한 것이 같은 얼굴을 할 수 있다는 것을 몸으로 겪게 한다 — 안개가 순수한 악의가 아니라 슬픔이라는 세계관(3.1절)을 전투 감각으로 선체험시킨다.
- **마녀의 기억 획득 연출**: 올드바크가 쓰러지며 뿌리 사이로 빛이 새어 나오는 이끼눈동자 핵. 손을 대면 젊은 셀라가 요정들에게 "듣는 법"을 배우는 회상 — 훗날 사람들이 수상히 여긴 "낯선 말버릇"의 기원이 드러난다.
- **공유 감정축에 더하는 것**: 괴물의 행동에도 "리듬"과 "의미"가 있다는 것 — 다음 지방들에서 보스 패턴을 서사로 읽는 습관을 만든다.
- **순서 분기**:
  - 첫 번째(`main_a2_eld_letter_teo_first_01`): "숲이 노래를 부른다고?" / "무섭지 않았어?" / "너답다, 정말."
  - 마지막(`main_a2_eld_letter_teo_last_01`): "이 노래... 어디서 들은 것 같아." / "다른 지방에서도." / "우연이 아니겠지."

### 3.3 프로스트헤임 — 서리방패 · 서리 늑대왕

**로그라인(확장)**: 겨울 축제가 다가오지만 모락 마을은 밤마다 늑대 울음소리에 떨고 있다 — 그 늑대왕은 한때 마을을 지키던 목양견 무리의 우두머리였다.

| 단계 | 장소 | 핵심 내용 | 게임플레이 훅 |
|---|---|---|---|
| 도입 | 모락 마을 온천가 | 온천 개장제 준비 중 야간 습격 반복, 방한복 필요(하코 기능 대사) | 추위 게이지 튜토리얼, 방한복 파밍 |
| 갈등 | 빙판 협곡 | 이졸데가 몰래 돌보는 늙은 개 한 마리와 조우(개인 서사는 characters.md), 늑대왕 무리 정찰 | 빙판 미끄러짐 기믹 전투 |
| 성물 회수 | 지역 던전 '서리 이빨 굴' | 서리 늑대왕 전투 — 마을 쪽 종이 울리면 잠깐 귀를 세우는 동작 | 지역 던전, 환경(빙판) 활용 페이즈 |

- **핵심 대사**(게른 원로, 던전 앞): "저 녀석, 원래…" / "우리 개였어." / "잊으면 안 돼."
- **지역 보스전의 서사적 의미**: 목격자(게른 원로)가 실존한다는 것 자체가 이 지방의 무게 — "괴물이 된 것도, 원래 무엇이었는지도" 둘 다 인간의 기억 속에 아직 살아있다는 증거. 4.3 복선표 #3(게른 원로의 축문 언급)과 정서적으로 직결.
- **마녀의 기억 획득 연출**: 서리방패 핵을 손에 쥐면 결정 표면에 성에가 낀 채로 회상 재생 — 초기 역병 국지 발생 당시 셀라가 마을 하나를 지켜내고 처음 "영웅"이라 불리는 장면.
- **공유 감정축에 더하는 것**: 지켜낸 힘이 훗날 죄로 뒤집힐 수 있다는 아이러니의 원점 — 이후 지방(사마르·이그니스)에서 반복될 패턴의 예고.
- **순서 분기**:
  - 첫 번째(`main_a2_frs_letter_teo_first_01`): "늑대왕이... 목양견?" / "믿기지 않지만" / "게른 원로가 기억한대."
  - 마지막(`main_a2_frs_letter_teo_last_01`): "마지막까지 남아있던 목격자였어." / "이제 다 들었으니" / "돌아가면 다시 물어볼까."

### 3.4 사마르 — 포궁 항아리 · 모래거상 골렘

**로그라인(확장)**: 장사꾼들이 두려워하는 '모래 밑에서 걷는 거인'은 사실 오래전 오아시스를 지키다 잊힌 파수 석상이었다.

| 단계 | 장소 | 핵심 내용 | 게임플레이 훅 |
|---|---|---|---|
| 도입 | 샘터 마을 오아시스 | 대상 행렬 습격 소문, 낮/밤 온도차 기믹 소개(다라 기능 대사) | 낮/밤 장비 전환 튜토리얼 |
| 갈등 | 사구 지대 | 유수프가 골렘을 무서워하지 않고 신기해하는 것을 목격(개인 서사 제외), 모래폭풍·유사 기믹 | 유사 회피, 모래폭풍 시야 제한 전투 |
| 성물 회수 | 지역 던전 '파묻힌 성소' | 모래거상 골렘 전투 — 악의가 아니라 "오아시스를 지키라"는 낡은 명령만 반복하는 존재 | 지역 던전, 명령 해제형 기믹(특정 오브젝트 파괴로 패턴 완화) |

- **핵심 대사**(유수프, 전투 전): "그만 지켜도 돼." / "이제 괜찮아." / "우리가 왔잖아."
- **지역 보스전의 서사적 의미**: "처치"보다 "임무 해제"에 가까운 전투 프레이밍 — 선의로 시작된 것이 낡은 명령으로 오해받을 수 있다는 것을 가르친다. 이는 셀라의 치료 행위가 저주로 와전된 전말(세계관 바이블 4.1)을 플레이어가 먼저 몸으로 겪게 하는 장치.
- **마녀의 기억 획득 연출**: 포궁 항아리 핵에서 물방울이 맺히며 회상 — 기근이 한창일 때 셀라가 상인·유랑민에게 나누어 주는 장면. 그녀가 귀족보다 평민 편에 서 있었다는 것이 드러난다.
- **공유 감정축에 더하는 것**: 선의가 임무·소문으로 뒤틀려 오해받는다는 구조 — 3막 진실("왕실이 감춘 진실")로 가는 논리적 다리.
- **순서 분기**:
  - 첫 번째(`main_a2_smr_letter_teo_first_01`): "명령 때문이었다고?" / "그것도 슬프네." / "다음 지방은 또 뭘까."
  - 마지막(`main_a2_smr_letter_teo_last_01`): "지키라는 명령, 낡은 믿음…" / "다 겹쳐 보이는군." / "이제 알겠다, 조금은."

### 3.5 이그니스 — 잔불화로 · 재의 드래곤

**로그라인(확장)**: 폐허가 된 대장간 성소에서 매일 같은 시각 울리는 망치 소리 — 그 소리를 따라가면 아직 식지 않은 화로가 있다.

| 단계 | 장소 | 핵심 내용 | 게임플레이 훅 |
|---|---|---|---|
| 도입 | 잉걸 마을 대장간촌 | 오르카가 폐허 성소 소문을 조사 중, 내화 장비 필요(시나 기능 대사) | 내화 장비 파밍 튜토리얼 |
| 갈등 | 용암대지 | 그루드가 "성소엔 아무도 새 불을 피우지 않는다"는 금기 재확인, 망치 소리의 정체에 접근 | 용암 회피 기믹 전투 |
| 성물 회수 | 지역 던전 '폐허 성소' | 재의 드래곤 전투 — 다섯 보스 중 셀라의 진실에 가장 가까운 존재 | 지역 던전, 5개 지방 중 최고 난도(★★★★) |

- **핵심 대사**(오르카, 던전 앞): "이 안엔..." / "아직도 그분을..." / "기다리는 게 있어."
- **지역 보스전의 서사적 의미**: 다섯 보스 중 유일하게 "그녀"를 직접 언급하는 전투 — 처형 당일 구하지 못했다는 자책이 안개와 뒤섞여 폭주했다는 진실이 가장 직접적으로 드러난다. 3막 최종 진실의 감정적 예고편.
- **드래곤의 마지막 대사**(패배 시, `main_a2_ign_boss_defeat_01`):
  - "그녀는..."
  - "태우려던 게..."
  - "아니었어."
- **마녀의 기억 획득 연출**: 잔불화로 핵을 손에 쥐면 손끝이 따뜻해지며 회상 — 처형 당일, 잔불화로로 처형장의 아이를 감싸려던 마지막 순간. 5개 중 가장 늦게, 가장 무겁게 배치되며(세계관 바이블 4.4), 재의 드래곤 처치 직후가 아니라 **잿빛 첨탑 진입 직전 지역**에서 열린다(3막 진입 조건과 별개 트리거).
- **공유 감정축에 더하는 것**: 축의 완성 — "괴물에게도 사연이 있었다"는 패턴이 이번엔 마녀 자신의 사연과 정확히 같은 모양임을 플레이어가 스스로 눈치채게 만든다.
- **순서 분기**:
  - 첫 번째(`main_a2_ign_letter_teo_first_01`): "그녀라니, 누구 얘기지?" / "너도 궁금하지." / "더 알아봐야겠어."
  - 마지막(`main_a2_ign_letter_teo_last_01`): "이제야 다 이어지는군." / "처음부터 한 사람 얘기였어." / "첨탑으로 가야겠다."

## 4. 2막 중반 폭로 — "재판 기록이 이상하다"

리서치 01 원칙(반전은 결말 직전이 아니라 중반에 배치)에 따라, **완료한 지역 스토리가 몇 번째 지역이든 관계없이 성물 핵을 3개 회수한 시점**에 자동으로 발동하는 메인 퀘스트 이벤트다.

- **트리거**: 성물 핵 누적 3/5 달성 시 자동 등록(`main_a2_mid_reveal`), 브릿지포트로 이동하라는 목표 아이콘 표시.
- **장소**: 브릿지포트 문서고(오델의 근무지)
- **등장**: 주인공, 오델(왕실 사서), 테오
- **드러나는 것**:
  - 오델이 최근 활성화된 성물 파편들의 공명 때문에 봉인 서고 일부가 저절로 열렸다며 낡은 재판 기록 한 장을 보여준다.
  - 기록 속 **피고인의 이름 칸이 훼손**되어 있고, 처형 사유가 통용되는 "마녀의 저주" 서사와 날짜·정황이 어긋난다는 것이 드러난다.
  - 오델이 옛 목격담 하나를 인용한다: "그날 그 사람은... 누군가를 구하려던 것 같았다더군." — 이름도, 성물지기라는 신분도 아직 밝히지 않는다.
- **아직 감춰지는 것**: 피고인의 본명(셀라), "성물지기"라는 신분과 다섯 성물 모두 반응했다는 사실, 안개의 진짜 정체(슬픔+혼돈), 축문의 정확한 유래. 이 정보들은 각 지방 나머지 지역 스토리(4.3 복선표 #1~4)와 3막 초입(#5)에서 순차적으로 채워진다.
- **핵심 대사**(오델):
  - "이 기록, 이상해."
  - "이름이 지워졌어."
  - "누가, 왜 지웠을까."
- **연출**: 낡은 양피지 클로즈업(도트 소품), 오델 표정 이모지(🧐), 배경음 일시 정지로 무게감 부여(컷신 아님, 스킵 가능한 대사 시퀀스로 유지)
- **게임플레이 훅**: 순수 서사 이벤트(전투 없음), 완료 시 브릿지포트 NPC(카이·페트라)의 잡담 대사 폭에 "요즘 소문" 카테고리 추가(사이드 콘텐츠 훅, 구현은 대사 데이터 담당)
- **이후 진행**: 나머지 지방 자유 진행 계속, 각 지방에서 회수하는 마녀의 기억이 이 폭로의 빈칸을 하나씩 채워가는 구조로 계속 강화된다.

## 5. 3막: 재의 마녀

### 5.1 첨탑 진입 조건
- 다섯 성물 핵 전부 회수 시 자동 개방(GDD F5-1, "전 단계 완료 시 다음 단계 자동 등록"). 마녀의 기억 개수는 진입 조건이 아니라 **엔딩 분기 조건**(D-19)이다 — 혼동 방지를 위해 퀘스트 로그에 "성물 5/5"와 "마녀의 기억 X/5"를 별도 표기.
- 진입 직전 지역에서 5번째(이그니스) 마녀의 기억이 아직이면 마지막 기회로 열림(3.5절).

### 5.2 첨탑 내부 구간
잿빛 첨탑은 재의 날 처형이 실제로 벌어진 장소다. 구간마다 다섯 성물의 상징(주권·지혜·수호·풍요·생명)이 메아리처럼 배치되어, 최종전 전 플레이어가 지금까지 쌓아온 것을 정리하게 한다.

| 구간 | 장소 | 내용 | 게임플레이 훅 |
|---|---|---|---|
| ① 재판정의 흔적 | 첨탑 초입 | 무너진 재판정 잔해, 피고인 이름이 긁힌 석판(중반 폭로의 실물 확인) — 이번엔 다른 문헌으로 **본명 "셀라"가 처음 확정**된다(`main_a3_s01_plaque_01`) | 환경 탐험, 잔당 몬스터 소전투 |
| ② 나선 계단 | 첨탑 중단 | 다섯 층에 각 성물 상징을 딴 시련 1개씩 배치(주권=인도 퍼즐, 지혜=질문형 기믹, 수호=방어 유지 구간, 풍요=나눔 트리거, 생명=불씨 옮기기) — 완료한 지방 순서와 무관하게 5개 모두 여기서 재확인 | 소형 퍼즐 5종, 저항 없는 안전한 복습 구간 |
| ③ 처형대 | 첨탑 상단 직전 | 안개가 가장 짙은 곳. 환경 연출로 재의 날 처형 장면이 실루엣으로 재생(대사 없이 이모지·소품만으로) — 마녀의 기억 보유 개수에 따라 실루엣의 선명도가 달라짐(연출 분기, 5/5 시 가장 또렷) | 순수 연출 구간, 전투 없음 |
| ④ 최상층 | 첨탑 정상 | 최종전 아레나 | 보스전 |

- **핵심 대사**(테오, ① 구간): "이름이... 셀라?" / "처음 듣는 이름이야." / "너는 알고 있었어?"

### 5.3 최종전 — 재의 마녀 (3페이즈, GDD 8.2)

| 페이즈 | HP | 서사적 의미 | 연출 |
|---|---|---|---|
| 1페이즈 | 100~66% | **공식 서사 그대로의 마녀** — 세상이 300년간 두려워한 모습. 순수한 분노와 혼돈, 대사 없음 | 잿빛 안개 폭풍, 표정 없는 가면형 실루엣 |
| 2페이즈 | 66~33% | **균열** — 공격 패턴에 방어적 동작(플레이어를 감싸듯 팔을 드는 궤적)이 섞여 나오기 시작. 축문이 끊어진 채 흘러나온다 | 대사 파편(`main_a3_boss_p2_01`): "손을... 내밀지..." |
| 3페이즈 | 33~0% | **발악이 아니라 절규** — 안개가 부분적으로 걷히며 인간 실루엣이 언뜻 비친다. 공격이 오히려 "밀어내려는" 방향으로 바뀐다(죽이려는 게 아니라 다가오지 말라는 몸짓으로 재해석) | 마녀의 기억 보유 개수만큼 실루엣이 또렷해지는 연출 분기(개수는 전투 밸런스에 영향 없음, 순수 비주얼) |

- **핵심 대사**(3페이즈, `main_a3_boss_p3_01`, 재의 잠긴 목소리): "손을 내밀지 않으면..." / "아무것도..." / "...태어나지 않는다."

### 5.4 엔딩 분기 (D-19)

#### 노멀 엔딩 (마녀의 기억 5개 미만)
- **씬 시퀀스**: 마녀 소멸 → 안개가 첨탑 주변부터 서서히 걷힘 → 주인공 홀로 첨탑 정상에 남음 → 다섯 성물 핵이 하나로 합쳐지려는 조짐(완전히 하나가 되지는 않음, 은은한 빛만) → 테오 도착, 세상이 안전해졌음을 확인 → 마지막, 옅은 안개 사이로 사람 형상이 잠깐 비쳤다 사라지는데 카메라가 확인하기 전에 흩어진다.
- **마지막 대사**(테오, `main_a3_end_normal_teo_01`): "끝난 건가..." / "안개가... 걷힌다." / "고생했어, 정말."
- **주인공 마지막 대사**: [캐릭터별 분기]
- **여운 처리 원칙**: "실패"로 읽히지 않도록, 세계는 확실히 구원되었음을 명시(안전지대 통합, 안개 소멸)하되 "누구였는지는 끝내 확인하지 못했다"는 미완의 앎만 남긴다. 엔딩 카드 문구(`main_a3_end_normal_card_01`): "안개는 걷혔다. / 그녀의 이름은, / 아직 아무도 모른다."

#### 진 엔딩 (마녀의 기억 5/5)
- **씬 시퀀스**: 마녀 소멸 → 안개가 완전히 걷히며 셀라의 모습이 온전히 드러남(평온한 표정) → 다섯 성물 핵이 하나로 재결합 → 셀라가 축문을 완결된 문장으로 직접 말함 → 주인공에게 짧게 감사 → 빛이 되어 흩어짐(죽음이 아니라 놓여남으로 연출) → 브릿지포트 등대 장면으로 전환(오델·카이 등장), 역사 정정을 예고
- **핵심 대사**(셀라, `main_a3_end_true_sela_01`): "손을 내밀어줘서," / "고마워." / "이제, 됐어."
- **마지막 대사**(오델, 등대 장면, `main_a3_end_true_odel_01`): "이름을 다시 쓸 거야." / "셀라라고." / "이번엔 제대로."
- **주인공 마지막 대사**: [캐릭터별 분기]
- **엔딩 카드 문구**(`main_a3_end_true_card_01`): "안개는 걷혔다. / 그녀의 이름은, / 셀라였다."
