# 복선 추적표 — 《이슬란드 연대기》

> 문서 버전: v1.2 (2026-09-08, QA 후속 커밋 — D-56·D-59·D-60 반영)
> 근거: `docs/story/world-bible.md` 4.3절(복선 설계표 최초안)·4.4절(마녀의 기억), `docs/story/main-storyline.md`, `docs/story/characters.md`(NPC 대사 key 소관)
> 역할: 세계관 바이블 4.3절의 설계를 **씬 단위로 확장**한 구현 추적표. 세계관 바이블과 충돌 시 세계관 바이블이 우선한다.
> 갱신 규칙: NPC 개인 서사·호감도 대사 쪽 key는 narrative-designer(`characters.md`)가, 메인 플롯·환경 오브젝트·지역 스토리 쪽은 main-storyline 담당 작가가 각자 담당 항목만 갱신한다. **서로의 섹션을 덮어쓰지 말 것** — 신규 항목·수정 시 이 표(하나의 표 체계)에만 반영하고, 별도 사본 문서를 새로 만들지 않는다.
> v1.1 병합 이력: 이 문서(v1.0, F-01~18)와 narrative-designer가 별도로 만든 `foreshadowing.md`(NPC 대사 key 기반, A 버전을 일시 덮어썼던 버전)를 QA가 병합했다. B 버전에서 확인된 실제 NPC 이름·key는 A 버전의 자리 표시(placeholder) key를 대체했다(§A 표 하단 "병합 시 정정" 참고). B 버전이 제안한 5개 슬롯은 모두 기존 F-01~05에 1:1로 대응해, **신규 F-ID 추가는 없었다**.
> 총 항목: **18개** (요구 최소 15개 충족, 병합 후에도 항목 수 불변 — 상세는 문서 하단 갱신 이력 참고)

## 표 읽는 법
- **1회차 인지 난도**: 낮음(누구나 알아챔) / 중(주의 깊게 봐야 함) / 높음(재플레이·완전 탐색해야 알아챔)
- **회수 위치**: 이 복선의 의미가 실제로 드러나는 지점(main-storyline.md 참조)
- **담당 산출물**: 실제 구현 시 만들 대사 key·아이템 id·도감 id 등 구현 단서

## 놓쳤을 때의 안전장치 요약 (재확인)

- **마녀의 기억(F-11~15)**: 지역 던전 재입장이 자유이므로(GDD 6.5) 영구 소실되지 않는다. 추가로 **3막 진입 시 호감도와 무관하게 자동으로** 브릿지포트 오델이 놓친 기억을 구술 요약본으로 대신 들려주는 보완 장치를 둔다(D-56, main-storyline.md 5.1절에 명문화. 정확한 UI·연출 타이밍은 퀘스트 설계 문서에서 확정).
- **축문 계열(F-01~05)**: 순차 노출형이라 일부를 놓쳐도 F-05가 전체를 소급 확정하는 설계다. **v1.1에서 발견된 충돌(F-05가 "오델 호감도 단짝 도달 + 3막 진입"으로 게이팅되어 있어 D-19 안전장치가 무력화될 수 있음, QA 리포트 Blocker B-1)은 D-56으로 해소했다** — 축문 전문·구술 요약본은 이제 3막 진입 시 호감도 무관 자동 제공이고, 오델 단짝 미니 스토리(`npc_bridgeport_odel_bff_01`)는 별개의 호감도 종속 **추가 정보**로 재정의되었다(상세는 F-05 행의 "D-56 반영" 각주 참고).
- **지방 전설(F-06~10)**: 각 지방 초반부터 반복 노출되는 대사·플레이버라 놓치기 어렵게 설계했다(인지 난도 낮음~중 위주).
- **환경·아이템 보강(F-16~18)**: 인지 난도가 높은 것(F-16)은 필수 진행에 영향 없는 순수 보너스 디테일로만 기능하며, 놓쳐도 엔딩 이해에는 지장이 없다.
