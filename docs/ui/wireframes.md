## 0. 공통 원칙

### 0.1 게임패드 우선 내비게이션 (Switch 이식 대비)

모든 화면은 **마우스 없이 십자키/스틱만으로 완주 가능**해야 한다. 마우스는 항상 "추가 수단"이며, 마우스 전용 인터랙션(호버로만 열리는 정보 등)은 금지한다.

| 동작 | 게임패드 | 키보드 | 비고 |
|---|---|---|---|
| 포커스 이동 | 십자키 / 좌스틱 | 방향키 / WASD | 격자·리스트 공통. 화면당 기본 포커스 1개 항상 존재 |
| 결정 | A | Enter / 좌클릭 | |
| 취소 / 뒤로 | B | Esc / 우클릭 | 최상위에서 B = 화면 닫기 |
| **대분류 탭 전환** | **LB / RB** | Q / E | 화면 상단 탭바. 순환(끝→처음) |
| 서브 카테고리·필터 전환 | LT / RT | Z / C **(제안)** | 등급 필터, 도감 지역 필터 등 |
| 보조 액션 1 (정렬·상세 등) | X | Space **(제안)** | 화면별 문맥 액션 |
| 보조 액션 2 (분해·핀 삭제 등) | Y | X키 **(제안)** | 파괴적 액션은 홀드 0.5초 **(제안)** |
| 스크롤 / 지도 이동 | 우스틱 | 마우스 휠·드래그 | 리스트 페이지 스크롤, 지도 패닝 |
| 툴팁 고정/토글 | 우스틱 클릭(R3) | Alt **(제안)** | 비교 툴팁 좌우 전환 포함 |

- **포커스 표시**: 포커스된 요소는 나무 프레임 하이라이트 + 도트 화살표 커서(깜빡임 2프레임). 포커스만으로 현재 위치가 즉시 읽혀야 한다.
- **하단 입력 가이드 바**: 모든 전체화면 UI 최하단에 현재 유효한 입력을 아이콘+라벨로 상시 표시 (`(A)결정 (B)닫기 (LB/RB)탭` 형식). 패드/키마 입력 감지에 따라 아이콘 자동 전환.
- **탭 순서 기억**: 화면을 닫았다 다시 열면 마지막 탭·포커스 위치를 복원한다 **(제안)**.

### 0.2 등급 색상 6종 사용 규칙

GDD 6.1의 등급 정의와 1:1. 색상 값은 `game/ui/theme.tres`에서만 정의하고 하드코딩 금지. game-designer의 등급 테이블이 진실의 원천(source of truth)이다.

| 등급 | 색 | 색약 모드 대체 아이콘 **(제안)** | 적용 지점 |
|---|---|---|---|
| 일반 | 흰색 | ● (원) | 아이템 프레임 테두리·이름 텍스트·드랍 빛기둥·툴팁 헤더에 공통 적용 |
| 고급 | 초록 | ▲ (삼각) | 〃 |
| 희귀 | 파랑 | ◆ (마름모) | 〃 |
| 영웅 | 보라 | ★ (별) | 〃 |
| 전설 | 주황 | ✦ (사방별) | 〃 |
| 유물 | 붉은 금색 | ❖ (문장) | 〃 |

- 등급 정보는 **색 + 아이콘 이중 채널**로 항상 함께 표기한다(색약 모드 OFF에서도 슬롯 우상단에 소형 등급 아이콘 상시 표시 **(제안)** — 모드 전환 시 레이아웃이 변하지 않게).
- 등급 색을 등급 외 용도(경고, 강조 등)로 재사용하지 않는다.

### 0.3 도트 감성 프레임(양피지·나무) 적용 지점

| 모티프 | 적용 지점 |
|---|---|
| **나무 프레임** | 전체화면 UI 외곽 테두리, 탭바, 버튼, 슬롯 격자 테두리, HUD 미니맵 테두리 |
| **양피지** | 패널 내부 배경(인벤토리 목록, 툴팁, 퀘스트/의뢰 지면, 월드맵 지면, 도감 페이지) |
| **금속 장식(못·경첩)** | 프레임 모서리 4점, 탭 활성 표시 **(제안)** |
| 사용 금지 | 전투 HUD의 HP/스태미나 바 내부 — 가독성 우선, 장식 최소화 |

- placeholder 단계: 나무=갈색 단색+2px 테두리, 양피지=미색 단색으로 **규격만** 맞춘다(작업 규칙 4). 최종 아트는 pixel-artist 아트 바이블 팔레트 확정 후 교체.
- 내부 렌더 640×360 기준으로 UI를 설계하고 정수배 스케일한다. 최소 폰트 높이 8px **(제안)**.

### 0.4 텍스트

- 모든 표시 문자열은 narrative-writer의 로컬라이징 key를 사용한다 (`ui.inventory.title` 형식 **(제안)**). 본 문서의 한글 표기는 key의 한국어 값 예시다.

## 1. 타이틀 & 세이브 슬롯

**목적**: 게임 진입점. 3개 저장 슬롯(GDD 12장) 중 하나를 골라 이어하기/새 게임을 시작한다.

```
+----------------------------------------------------------------+
|                                                                |
|          (배경: 이슬란드 전경 도트 일러스트, 루프 애니메이션)          |
|                                                                |
|              ~ 이슬란드 연대기 ~                                  |
|         Chronicles of Isleland   (로고, 도트)                    |
|                                                                |
|                  +---------------------+                       |
|                  | > 모험 시작          |                        |
|                  |   설정              |                        |
|                  |   게임 종료          |                        |
|                  +---------------------+                       |
|                                                                |
|  v1.0.0                       (A)결정 (상하)이동                 |
+----------------------------------------------------------------+

[모험 시작 선택 시 → 세이브 슬롯 화면]
+----------------------------------------------------------------+
|  < 모험의 기록 >                                    (B) 돌아가기  |
|                                                                |
|  +------------------+ +------------------+ +------------------+|
|  | 슬롯 1            | | 슬롯 2           | | 슬롯 3            ||
|  | [핀 초상]  Lv.23  | |                  | |                  ||
|  | 안개숲 엘드우드    | |   - 비어 있음 -   | |  - 비어 있음 -    ||
|  | 플레이 12:34      | |                  | |                  ||
|  | 2026-08-15 저장   | |   새 모험 시작    | |   새 모험 시작     ||
|  +------------------+ +------------------+ +------------------+|
|                                                                |
|        (A)이어하기 (X)새로 시작 (Y)삭제[홀드] (B)뒤로             |
+----------------------------------------------------------------+
```

| 요소 | 표시 정보 | 인터랙션 |
|---|---|---|
| 메인 메뉴 | 모험 시작 / 설정 / 게임 종료 | 상하 이동, A/Enter 결정. Switch에서는 "게임 종료" 숨김 **(제안)** |
| 세이브 슬롯 카드 ×3 | 캐릭터 초상(선택 캐릭터+커스텀 반영), 레벨, 현재 지역명, 플레이 타임, 마지막 저장 일시 | 좌우 이동, A=이어하기, 빈 슬롯 A=새 게임(→화면 2) |
| 사용 중 슬롯 보조 | 새로 시작(덮어쓰기), 삭제 | X=새로 시작(확인 팝업), Y 0.5초 홀드=삭제(확인 팝업 2단) |
| 버전 표기 | 빌드 버전 | 없음 |

**상태·예외**
- 슬롯 전부 빈 상태: "이어하기" 라벨 대신 모든 슬롯이 "새 모험 시작". 메인 메뉴의 "모험 시작"이 곧바로 슬롯 화면으로.
- 세이브 파일 손상: 해당 슬롯에 "기록이 손상되었습니다" + 삭제만 허용 **(제안)**.
- 상위 버전 세이브(다운그레이드 실행): 로드 불가 안내 팝업 **(제안)**.
- 오토세이브 존재 시: 슬롯 카드에 "오토세이브" 뱃지, A 선택 시 수동/오토 중 선택 팝업 **(제안)**.

## 2. 캐릭터 선택 · 커스터마이즈

**목적**: 새 게임 시작 시 4명 중 1명 선택 + 헤어 8색·피부톤 6종 커스터마이즈(GDD 3장).

```
+----------------------------------------------------------------+
|  < 모험가 선택 >                                    (B) 돌아가기  |
|                                                                |
|  [핀]  [리라]  [모리]  [브람]        +------------------------+ |
|   ^선택중(테두리 하이라이트)          |  (선택 캐릭터 대형 도트)   | |
|                                    |   idle 애니메이션 재생    | |
|  +---------------------------+     |    32x48 → 4배 확대      | |
|  | 씩씩한 견습 기사             |     +------------------------+ |
|  | 주무기: 한손검+방패          |                                |
|  | 스타일: 근접 밸런스형        |      헤어 컬러                   |
|  | 고유: 패리 슬래시            |      [1][2][3][4][5][6][7][8]  |
|  | (스킬트리: 검술/수호/기사도)  |      피부톤                     |
|  +---------------------------+      [1][2][3][4][5][6]         |
|                                                                |
|  이름: [ 핀________ ] (기본값=캐릭터명)                           |
|                                                                |
|      (LB/RB)캐릭터 (십자)항목 (A)결정 (X)이름입력 (Y)랜덤          |
|                          [ 모험 시작! ]                         |
+----------------------------------------------------------------+
```

| 요소 | 표시 정보 | 인터랙션 |
|---|---|---|
| 캐릭터 탭 ×4 | 초상 아이콘 + 이름 (핀/리라/모리/브람) | LB/RB 또는 탭에서 좌우로 전환. 전환 시 미리보기·설명 즉시 갱신 |
| 캐릭터 설명 패널(양피지) | 컨셉, 주무기, 전투 스타일, 고유 메커니즘, 스킬 트리 3계열명 | 표시 전용 |
| 대형 미리보기 | 커스텀이 반영된 도트 스프라이트, idle 애니메이션(하품 등) | A로 공격 모션 1회 재생 **(제안)** |
| 헤어 컬러 스와치 ×8 | 색 견본 + 선택 테두리 | 좌우 이동, A 즉시 적용 |
| 피부톤 스와치 ×6 | 색 견본 + 선택 테두리 | 〃 |
| 이름 입력 | 현재 이름(기본값=캐릭터명) | X 또는 A → 온스크린 키보드(패드)/직접 입력(키마). 최대 8자 **(제안)** |
| 랜덤 버튼 | 주사위 아이콘 | Y = 헤어·피부 랜덤 **(제안)** |
| 모험 시작 | 확정 버튼 | A → 확인 팝업 "이 모습으로 떠날까요?" |

**상태·예외**
- 이름 공백/금칙어: 시작 버튼 비활성 + 안내 문구. 금칙어 필터는 로컬라이징 key 기반 **(제안)**.
- 커스터마이즈는 시작 후 변경 불가(치장 슬롯으로만 외형 변화) — 확인 팝업에 명시 **(제안, GDD 미정)**.
- 회차 데이터 존재 시: 캐릭터 탭에 "클리어" 왕관 뱃지 **(제안)**.

## 3. 인게임 HUD

**목적**: 전투·탐험 중 상시 정보. GDD 11장 "HUD 최소화" — 화면 중앙은 항상 비운다.

```
+----------------------------------------------------------------+
| [초상] HP  ████████████░░░░  234/300        +--------+         |
|        ST  ██████░░░░  (스태미나)            |미니맵   |         |
|  Lv.23  [화상][축복] (버프/디버프 아이콘)      | (토글)  |  N      |
|                                             +--------+         |
|                                                                |
|                                                                |
|                    (게임 필드 — UI 없음)                         |
|                                                                |
|                                        몬스터 처치! +12 EXP     |
|                                        철검 획득  ◆희귀         |
|                                          ^(우하단 획득 로그)     |
|   [Q스킬]  [E스킬]                                              |
|   (쿨타임)  (쿨타임)   [1포션x5][2폭탄x2][3음식][4-]              |
|                       ^퀵슬롯 4칸 (하단 중앙)                    |
+----------------------------------------------------------------+
```

| 요소 | 표시 정보 | 인터랙션 |
|---|---|---|
| HP 바 (좌상단) | 현재/최대 수치+게이지. 피격 시 감소분 잔상(흰색→소멸) **(제안)**. 정령 조각으로 칸 증가 시 바 길이 확장 | 표시 전용 |
| 스태미나 바 | HP 아래, 게이지만(수치 없음). 소진 시 붉게 점멸 | 표시 전용 |
| 캐릭터 초상+레벨 | 선택 캐릭터 얼굴 도트, 레벨. 레벨업 시 팡파레 연출 | 표시 전용 |
| 버프/디버프 아이콘 열 | 상태이상(화상·빙결·감전…)·음식 버프 아이콘+남은 시간 링 | 표시 전용, 최대 6개 후 +N **(제안)** |
| 미니맵 (우상단) | 주변 지형(방문 지역만), 플레이어 방향, 워프 비석·마을 아이콘, 핀 | **M / 셀렉트(-)** 토글: 표시→숨김 (2단) **(제안)**. 홀드 시 월드맵(화면 6) |
| 스킬 슬롯 ×2 (좌하단) | 스킬 아이콘, 쿨타임 시계형 오버레이+초 | Q·E / L·R 사용 |
| 퀵슬롯 ×4 (하단 중앙) | 아이템 아이콘+수량, 빈 칸은 반투명 프레임 | 1~4 / 십자키 사용. 인벤토리에서 등록 |
| 획득 로그 (우하단) | 아이템명(등급 색+아이콘), EXP, 골드. 3초 후 페이드 | 표시 전용, 최대 4줄 스택 **(제안)** |
| 보스 HP 바 | 보스전에만 하단 퀵슬롯 위에 대형 바+보스명+페이즈 표시 **(제안)** | 표시 전용 |

**상태·예외**
- 비전투 5초 경과: HP/ST 만땅이면 바 반투명화(도트 감성 유지, 화면 정리) **(제안)**.
- 퀵슬롯 아이템 소진: 수량 0 → 슬롯 회색+빈 프레임 유지(같은 아이템 재획득 시 자동 재연결) **(제안)**.
- 스태미나 부족 상태에서 구르기 입력: 바 흔들림+실패음.
- 저주(잿빛 안개) 지역: 화면 가장자리 잿빛 비네트 + HP 바 옆 저주 아이콘.
- 추위 게이지(설산)·온도(사막): 해당 지역에서만 HP 바 아래 서브 게이지 노출.
- 미니맵 토글 상태는 저장 데이터에 유지.

## 4. 인벤토리 & 장비

**목적**: 격자형 소지품 관리 + 8 장비 슬롯 & 치장 3슬롯 장착 + 비교 툴팁(GDD 6.2, 11장).

```
+----------------------------------------------------------------+
| [장비/가방] [스킬] [지도] [도감] [설정]        골드: 12,340 G     |
|  ^LB/RB 대분류 탭                                               |
| +---------------------+  +-----------------------------------+ |
| |      장비 (좌패널)    |  |  가방 (우패널, 격자 8x5 = 40칸)     | |
| |      [투구]          |  | 필터: [전체|일반|고급|희귀|영웅|전설|유물]|

- 가방 가득: 필드 획득 시 HUD 경고 + 우편함 없이 바닥 유지 **(제안, 미정 — 하단 미결정 참조)**.
- 필터 결과 0개: "이 등급의 아이템이 없어요" + 필터 해제 안내.
- 요구치 미달 장비(STR 등): 슬롯에 붉은 요구치 표기, 장착 시도 시 거부+사유 툴팁.

## 5. 스킬 트리

**목적**: 캐릭터별 3계열 × 6단계 스킬 습득·강화(GDD 4.3). 예: 핀 = 검술/수호/기사도.

```
+----------------------------------------------------------------+
| [장비/가방] [스킬] [지도] [도감] [설정]     스킬 포인트: 3 SP     |
|                                                                |
|  [ 검술 ]   [ 수호 ]   [ 기사도 ]      ← LT/RT 계열 전환         |
|  ---------------------------------------------------------    |
|   1단계   (O)---(O)          O = 습득  ◎ = 습득가능(빛남)        |
|            |     |          X = 잠김(회색)                     |
|   2단계   (O)   (◎)                                            |
|            |     |            +--- 스킬 상세(양피지) ---------+  |
|   3단계   (◎)   (X)           | 패리 슬래시 Lv.2/3            |  |
|            |                  | 저스트 가드 후 반격 데미지     |  |
|   4단계   (X)                 | 120% → 150%                  |  |
|            |                  | 필요: 1 SP / 선행: 가드 강화   |  |
|   5단계   (X)                 | (A) 습득하기                  |  |
|            |                  +------------------------------+  |
|   6단계   (X)  ← 세로 스크롤                                    |
|                                                                |
|  (십자)노드 이동 (A)습득 (LT/RT)계열 (X)리셋 안내 (B)닫기          |
+----------------------------------------------------------------+
```

| 요소 | 표시 정보 | 인터랙션 |
|---|---|---|
| 계열 탭 ×3 | 계열명+아이콘, 계열별 투자 SP 합계 | LT/RT 전환 (대분류 탭 LB/RB와 구분) |
| 스킬 노드 (단계당 1~2개 **(제안)**) | 아이콘, 습득 상태 3종(습득=금테, 습득가능=발광, 잠김=회색+자물쇠), 스킬 레벨 N/최대 | 십자키로 연결선 따라 이동, A=습득/레벨업(확인 팝업 없음, 사제 리셋이 있으므로 **(제안)**) |
| 연결선 | 선행 조건 경로. 습득 경로는 밝게 | 표시 전용 |
| SP 잔량 | 우상단 상시 | 표시 전용 |
| 스킬 상세 패널 | 이름, 레벨, 효과 수치(현재→다음), 필요 SP, 선행 스킬, 액티브면 쿨타임·스태미나 | 표시 전용 |
| 슬롯 등록 안내 | 액티브 스킬 습득 직후 "Q/E 슬롯에 등록할까요?" 팝업 **(제안)** | A=슬롯 선택, B=나중에 |
| 리셋 안내 | X = "스킬 리셋은 마을 사제에게" 안내 토스트(이 화면에서 직접 리셋 불가, GDD 4.3) | — |

**상태·예외**
- SP 0: 습득 가능 노드의 발광 제거, 습득 시도 시 "스킬 포인트가 부족해요".
- 선행 미충족: 잠금 노드 A → 선행 스킬 노드로 포커스 점프+하이라이트 **(제안)**.
- 단계 해금 조건(레벨 제한 등): GDD 미정 — 잠김 사유를 툴팁에 표기(하단 미결정 참조).
- 사제 리셋 직후: 전 노드 미습득 상태, SP 전액 반환 표시.

## 7. 대장간

**목적**: 강화(+0~+10) / 제작 / 재련 / 분해를 한 화면에서(GDD 6.3, 6.4). NPC 대화로 진입.

> **상세 설계(M2-5)**: 640×360 탭별 ASCII·상태 흐름·입력 매핑·로컬라이징 키·결정 필요 목록은
> `docs/ui/blacksmith.md`로 이관했다. 이 절의 개략도는 4탭 공통 골격 요약으로만 유지한다.
> 우편함(D-10)은 대장간과 별개 화면(탭 없는 단일 팝업)이며 같은 문서 §1.5에서 다룬다.

```
+----------------------------------------------------------------+
| [ 강화 ] [ 제작 ] [ 재련 ] [ 분해 ]   ← LB/RB      골드 12,340 G |
|  ^활성 탭                                                      |
| +--------------------+  +-----------------------------------+  |
| | 장비 목록(좌)       |  |          강화 (우 패널)             |  |
| | ◆서리 철검   +4    |  |   [서리 철검 도트 확대]              |  |
| | ▲가죽 갑옷   +6    |  |   +4  →  +5                        |  |
| | ●나무 방패   +0    |  |   성공 확률: 100%                   |  |
| |  (장착중 표시 E)    |  |   공격 45 → 51 (▲6)                |  |
| | (스크롤)           |  |   필요: 강화석 x3 (보유 12)          |  |
| |                    |  |         500 G                      |  |
| |                    |  |   +7부터 실패 시 강화석만 잃습니다     |  |
| |                    |  |   (장비는 부서지지 않아요)            |  |
| |                    |  |        [ (A) 강화한다! ]            |  |
| +--------------------+  +-----------------------------------+  |
|      (십자)선택 (A)실행 (LB/RB)탭 (B)나가기                       |
+----------------------------------------------------------------+
  * 제작 탭: 좌=도면 목록(미보유 도면은 ??? 실루엣), 우=재료 체크리스트(보유/필요, 부족=적색)+제작 버튼
  * 재련 탭: 좌=장비 목록, 우=옵션 줄 목록에서 1줄 선택 → 재굴림 (남은 횟수 N/3 표시, 결과 전/후 비교 팝업)
  * 분해 탭: 좌=다중 선택 체크(장착중·잠금 제외), 우=환원 예상 재료 합계 + 일괄 분해 버튼

| 요소 | 표시 정보 | 인터랙션 |
|---|---|---|
| 탭바 ×4 | 강화/제작/재련/분해 | LB/RB 전환 |
| 장비 목록(공용 좌패널) | 아이콘, 이름(등급 색+아이콘), 강화치, 장착중 E 뱃지 | 십자키 선택. LT/RT=등급 필터(화면 4와 동일 규칙) |
| 강화 패널 | +N→+N+1, 성공 확률(+6까지 100%), 스탯 변화 미리보기, 필요 강화석·골드(부족분 적색) | A=실행. +7 이상은 확인 팝업 **(제안)**. 성공=팡파레+빛기둥 / 실패=연기+망치 낙심 모션 **(제안)** |
| 제작 패널 | 도면 목록(파밍 도면만 활성), 결과물 미리보기·등급, 재료 체크리스트 | A=제작. 브람 필드 간이 제작은 별도 간소 UI(본 화면 재사용, 탭 제작만 **(제안)**) |
| 재련 패널 | 랜덤 옵션 줄들, 줄별 남은 재굴림 횟수(N/3), 필요 재료+골드 | 줄 선택→A=재굴림→결과 전/후 팝업(**결과 선택 불가, 즉시 적용 — GDD 미정, 하단 참조**) |
| 분해 패널 | 다중 선택 체크박스, 선택 합계, 환원 재료 미리보기 | A=체크 토글, X=전체 선택(필터 범위), Y=일괄 분해(확인 팝업) |

**상태·예외**
- +10 도달: 강화 버튼 → "최대 강화!" 비활성, 장비명에 금빛 광택 이펙트.
- 강화 실패(+7~): 강화석 소실, 강화치 유지(GDD: 파괴 없음). 실패 후 확률 보정 여부 미정(하단 참조).
- 재료/골드 부족: 실행 버튼 비활성 + 부족 항목 적색. 부족 재료 포커스 시 "획득처: ○○ 몬스터" 툴팁 **(제안)** (도감 연동).
- 재련 3회 소진: 해당 줄 자물쇠 표시 "더 이상 재련할 수 없어요".
- 도면 미보유: ??? 실루엣 + 획득 힌트("사막의 상인이 알고 있을지도…") **(제안)**.
- 분해 대상 0개(빈 목록): "분해할 장비가 없어요".
- 영웅 이상 등급 분해: 확인 팝업에 등급 색 경고 강조 **(제안)**.

## 부록 B. 설계 중 발견한 미결정 사항

> **[2026-09-08 확정]** 아래 12건은 모두 `docs/brd/04-decisions.md`에서 확정되어 GDD v1.1에 반영되었다.
> 1→D-11, 2→D-10, 3→D-12, 4→D-13, 5→D-14/D-32, 6→D-33, 7→D-34, 8→D-20, 9→D-35, 10→D-36, 11→D-01, 12→D-37.
> 본문의 "(제안)" 표기 중 위 항목에 해당하는 것은 확정값으로 읽는다.

1. **가방 칸 수·확장**: 40칸은 제안값. 백팩(치장)과 무관한 확장 수단(구매? 퀘스트?) 미정.
2. **가방 가득 시 드랍 처리**: 바닥 유지 vs 우편함 회수 — 파밍 루프 스트레스에 직결.
3. **동일 반지 중복 장착 허용 여부** (반지×2 슬롯).
4. **재련 결과 확정 방식**: 재굴림 즉시 적용 vs 신·구 옵션 중 택1 — 파밍 타협 곡선에 큰 영향.
5. **강화 +7~+10 구간 성공 확률표** 및 실패 시 확률 보정(천장) 유무.
6. **스킬 단계 해금 조건**: 선행 스킬만인지, 캐릭터 레벨 제한 병행인지. 단계당 노드 수(1개/2개)도 미정.
7. **핀 8종의 의미 확정** 및 핀 최대 개수(제안 30개).
8. **게시판 의뢰 갱신 시각**(현실 자정? 게임 내 하루?).
9. **도감 완성률 보너스 임계치·보상표** (제안 25/50/75/100%).
10. **던전 내부 지도** 제공 여부(층 지도 vs 미니맵만).
11. **커스터마이즈(헤어·피부) 사후 변경 수단** 존재 여부(미용실 NPC 등).
12. **메뉴 진입 키 확정**: 전체화면 메뉴(Tab?)와 일시정지(Esc/Start)의 분리 여부 — 4.1 조작표에 메뉴 키가 없음.
