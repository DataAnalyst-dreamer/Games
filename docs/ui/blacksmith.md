> 문서 버전: v0.1 (2026-09-09) / 작성: ui-ux-designer / 이 태스크는 **문서만** — 구현은 후속 단계.

## 0. 전제 확인 (근거 문서 재확인 메모)

- 마을 배치: `docs/levels/hartland.md` — 대장간 NPC는 **핀토(대장간 견습생)**, 우편함은 게시판 옆
  **별도 필드 오브젝트**(2막 "테오의 우편" 재사용 지점, NPC 대사가 없는 상호작용 오브젝트 — 이 문서에서는
  작업 지시 원문의 "NPC 팝업" 표현을 이 오브젝트의 상호작용 팝업으로 해석한다). **브람**(플레이어블 캐릭터,
  드워프)은 대장간 NPC가 아니라 필드에서 "간이 제작"(D-31, 소모품·재료 가공)만 별도로 제공한다 — 제작 탭
  UI를 재사용하되 브람 필드 모드는 제작 탭만 노출한다(§1.4 참고).
- `game/scripts/core/events.gd`에 `item_mailed(item_id, quantity)`가 M2-1에서 이미 존재하고,
  `game/scripts/core/game_state.gd`의 `mailbox: Array`에 가득 찼을 때 자동 적재된다(D-10) — 즉 **저장소 자체는
  이미 있다**. 이 문서가 새로 요구하는 것은 "꺼내가기(수령)" API뿐이다(§7 요청 목록).
- `game/data/enhance.json`에 강화 10단·재련 3회·분해 산출표가 이미 확정돼 있다(D-14/D-32/D-13 수치와 일치).
  `blueprints.json`은 아직 존재하지 않는다 — 제작 탭은 스펙(F3-4) 기준으로 레이아웃만 확정하고 실데이터
  연결은 보류한다(§8 결정 필요 5).

## 1. 화면 구조

`InventoryMenu`와 마찬가지로 전체화면 팝업이며, `interact` 액션으로 필드 NPC/오브젝트에 접근했을 때 연다
(`menu` 액션이 아님 — 인벤토리 메뉴처럼 아무 때나 토글하는 화면이 아니라 특정 장소에서만 진입).
탭 4개(강화/재련/분해/제작)는 좌측 "장비·도면 목록" 공용 패널 + 우측 "상세" 패널의 골격을 공유하고,
분해 탭만 좌측이 다중 선택 리스트로 바뀐다. 우편함은 탭이 없는 단일 패널 팝업으로 별도 씬이다.

### 1.1 강화 탭 (640×360)

```
 | | +---------------------+ |  |     [서리 철검 아이콘 확대]        | |

 | | |●나무 방패  +0       | |  |   성공률: 100%                     | |
 | | | ...(스크롤)         | |  |   공격 45 → 51 (▲6)                | |
 | | +---------------------+ |  |   필요: 강화석 x3 (보유 12)         | |
 | |                         |  |         골드 500 (보유 12,340)      | |

 | |                         |  |     (장비는 절대 부서지지 않아요)     | |
```

- 좌측 목록·등급 필터·`[E]` 장착중 뱃지는 `inventory.md` §2 `InventoryCell`/필터칩을 그대로 재사용(등급
  색+아이콘 이중 채널 포함).
- +10 도달 시 우측 버튼이 `ui.smith.enhance.button_max`("최대 강화!")로 바뀌고 비활성.
- +7 이상 시도 시 A를 눌러도 즉시 소모되지 않고 확인 팝업 1회를 띄운다(§8 결정 필요 6 — 확정된 규칙은 아님,
  현재는 wireframes.md 화면7의 "(제안)"을 그대로 승계).

### 1.2 재련 탭

```
 | | (좌: 강화 탭과 동일    |  |  ◆서리 철검 +4    재련 잔여 2/3     | |
 | |  장비 목록·등급 필터)  |  |  ─────────────────────────────     | |
 | |                        |  |  [옵션 줄 목록 — 줄 단위 선택]       | |
 | |                        |  |  > 치명타 확률 +4%        [재련]    | |
 | |                        |  |    공격력 +6%              (잠김,   | |
 | |                        |  |                             0/3)   | |
 | |                        |  |  필요: 재련석 x4, 골드 300           | |
 | |                        |  |  (재료 부족 시 적색)                 | |
 | |                        |  |                                     | |
 | |                        |  |        [ (A) 재련한다 ]              | |
 | +-------------------------+  +-------------------------------------+ |
 +----------------------------------------------------------------+
 | (십자)줄 선택 (A)재련 (LB/RB)탭 (B)나가기                          |
 +----------------------------------------------------------------+

[재련 결과 팝업 — A 누른 직후 오버레이, 좌우 비교]
 +----------------------------------------------------------------+
 |                 어떤 옵션을 쓸까요?                                |
 |   +----------------------+     +----------------------+          |
 |   |   기존 옵션 (구)      |     |   ▶ 새 옵션 (신)        |          |
 |   |   치명타 확률 +4%     |     |   치명타 확률 +7%        |          |
 |   +----------------------+     +----------------------+          |
 |        (좌우)비교 전환      (A) 이 옵션으로 확정                    |

```

- 일반(common) 등급, 즉 `affix_slot_count==0`인 장비는 재련 대상에서 애초에 제외한다(`enhance.json` 주석과
  일치) — 좌측 목록에서 회색 처리하거나 필터에서 자동 제외(§8 결정 필요 2 없음, 이건 데이터로 이미 확정됨).
- 옵션 줄이 여러 개(희귀=2, 영웅=3+고유, 전설=고유 스킬)면 줄마다 **개별** 잔여 재련 횟수를 갖는지, 장비
  전체가 공유 3회인지는 `enhance.json` 주석("장비 인스턴스당 카운터")상 **장비 전체 공유**로 읽힌다 — 이
  화면은 그 해석을 따라 우측 상단에 장비당 한 번만 "재련 잔여 n/3"을 표시한다(줄마다 표시하지 않음).
- 신·구 비교 팝업은 좌우 두 패널을 나란히 두고 우스틱(R3)/좌우 방향키로 강조 패널을 바꾼다(`ui.inv.compare`
  계열과 톤 통일). **확정 시점에 비용·횟수가 함께 차감**된다(§8 결정 필요 2 — 재굴림 버튼을 누르는 순간과
  확정 순간 중 비용이 언제 빠지는지는 로직 계층과 확인 필요).

### 1.3 분해 탭

```
(0,0)                                                              (640,0)
 +----------------------------------------------------------------+
 | [강화][재련][분해][제작]  ^LB/RB 탭 순환            골드 12,340 G |
 +----------------------------------------------------------------+
 | +-----------------------+  +-----------------------------------+ |
 | | 필터:[전체|...] ^LT/RT|  |   예상 획득                          | |
 | | [ ]◆서리 갑옷  +2     |  |   강화석  x9                         | |
 | | [x]●낡은 단검         |  |   재료    x6                         | |
 | | [x]●나무 방패         |  |                                     | |
 | | (장착중·잠금 자동 제외) |  |   선택됨: 2개                        | |
 | | ...(스크롤)           |  |                                     | |
 | |                       |  |   [ (X) 전체선택 ]                    | |
 | |                       |  |   [ (Y 0.8초 홀드) 분해 확정 ]         | |
 | +-------------------------+  +-------------------------------------+ |
 +----------------------------------------------------------------+
 | (십자)이동 (A)체크 (X)전체선택 (Y홀드0.8s)분해 (B)나가기            |
 +----------------------------------------------------------------+

[영웅 이상 포함 시 추가 확인 팝업 — Y 홀드 완료 직후 1회]
 +----------------------------------------------------------------+
 |   ★ 영웅 등급 이상 장비가 포함되어 있어요. 정말 분해할까요?          |
 |             [ (A) 분해한다 ]      [ (B) 취소 ]                    |
 +----------------------------------------------------------------+
```

- 장착 중·잠금(즐겨찾기) 장비는 목록에서 **자동 제외**(F3-3c). 단, 잠금 플래그 자체가 아직 인벤토리에
  없다(`inventory.md` 남은 이슈 8) — §8 결정 필요 4.
- Y 홀드는 이 화면의 파괴적 액션 기준 시간인 **0.8초**를 쓴다. 인벤토리 메뉴의 "분해 표시 토글"(가역적
  마킹)은 0.5초라 서로 다르다 — 의도된 차이인지 통일해야 하는지는 §8 결정 필요 1.
- 영웅 이상 포함 시의 확인 팝업은 Y 홀드가 끝난 **다음에** 뜨는 2차 확인이라 A(짧게 누르기)로 최종 확정한다
  (홀드를 두 번 요구하지 않음).

### 1.4 제작 탭

```
(0,0)                                                              (640,0)
 +----------------------------------------------------------------+
 | [강화][재련][분해][제작]  ^LB/RB 탭 순환            골드 12,340 G |
 +----------------------------------------------------------------+
 | +-----------------------+  +-----------------------------------+ |
 | | ◆서리 인챈트 검 도면   |  |    [결과물 아이콘 확대]                | |
 | | ??? (미보유)          |  |    서리 인챈트 검                     | |
 | | ??? (미보유)          |  |    등급: 희귀 (제작품 — 기본 스탯 고정) | |
 | | ▲여행자 갑옷 도면      |  |    필요 재료                          | |
 | | ...(스크롤)           |  |     철광석   x5   (보유 8)             | |
 | |                       |  |     마수 가죽 x2  (보유 0, 적색)        | |
 | |                       |  |     골드 800 (보유 12,340)             | |
 | |                       |  |                                       | |
 | |                       |  |        [ (A) 제작한다 ]                | |
 | +-------------------------+  +-------------------------------------+ |
 +----------------------------------------------------------------+
 | (십자)도면 선택 (A)제작 (LB/RB)탭 (B)나가기                          |
 +----------------------------------------------------------------+
```

- 미보유 도면은 `???` 실루엣 + 획득 힌트 라벨만 표시하고 포커스는 가능하되 제작 버튼은 비활성.
- 제작은 **즉시**(대기 큐 없음) — 성공 확률 개념이 없으므로 강화처럼 "성공률" 줄이 없다.
- **브람 필드 간이 제작 모드**: 같은 씬을 필드에서 열되(NPC 대화 대신 브람 본인의 스킬 메뉴 등에서 진입,
  진입 경로는 이 문서 범위 밖) 탭바를 숨기고 제작 탭 내용만 표시, 목록도 "소모품·재료 가공" 레시피로
  한정한다(D-31). 강화/재련/분해 탭 진입 불가.

### 1.5 우편함 (별도 팝업, 탭 없음)

```
(0,0)                                                              (640,0)
 +----------------------------------------------------------------+
 |                         우편함                                    |
 +----------------------------------------------------------------+
 | +----------------------------------------------------------------+ |
 | | ◆서리 인챈트 검 x1                              [ (A) 받기 ]     | |
 | | ●철광석 x12                                     [ (A) 받기 ]     | |
 | | ▲가죽 갑옷 x1                                   [ (A) 받기 ]     | |
 | | ... (스크롤, 보관 기한 없음 — D-10)                                | |
 | +----------------------------------------------------------------+ |
 |                                                                    |
 |         가방이 가득 차면 우편함에 그대로 남아 있어요                    |
 |                                                                    |
 |               [ (X) 전체 받기 ]                                    |
 +----------------------------------------------------------------+
 | (십자)이동 (A)받기 (X)전체받기 (B)나가기                             |
 +----------------------------------------------------------------+
```

- 개별 "받기"는 가방에 자리가 있을 때만 항목이 사라진다. 가방이 가득이면 받기 시도 시 실패 안내만
  표시하고 우편함에는 그대로 남는다(D-10 "보관 기한 없음"과 정합).
- 전체 받기(X)는 넣을 수 있는 만큼만 받고 나머지는 그대로 둔 뒤 결과 요약("N개 수령, M개는 가방이 가득 차
  남겨뒀어요")을 보여준다.
- 진입은 우편함 필드 오브젝트에서 `interact`, `menu`/`pause`와는 무관하다.

## 2. 상태 흐름 (강화/재련/분해/제작 공통 골격)

```
[탭 진입] → 목록에서 대상 선택
    │  (등급 필터 LT/RT, 스크롤은 InventoryFocusCalc.grid_neighbor와 동일 원리)
    ▼
[비용·성공률 상시 표시] ── 재료/골드 부족 → 실행 버튼 비활성 + 부족분 적색, 대상 변경 시 즉시 재계산
    │  (재련 탭은 "옵션 줄"까지 한 단계 더 선택)
    ▼
[확정 입력]
    ├─ 강화/제작 = A 1회 (강화 +7↑ 는 확인 팝업 경유 — §8 결정 필요 6)
    ├─ 재련 = A 1회 → 신·구 비교 팝업 → A로 택1 확정 (여기서 비용·잔여횟수 차감)
    └─ 분해 = 다중 체크(A) → Y 0.8초 홀드 → (영웅↑ 포함 시 추가 확인 A/B)
    ▼
[결과 연출]
    ├─ 강화 성공: 모루 타격 + 빛 이펙트, 스탯 즉시 갱신
    ├─ 강화 실패: 연기 이펙트, 강화석만 소실 안내(단계 유지 강조 — 페널티 최소화가 차별점이므로 반드시 문구로 안심시킨다)
    ├─ 재련: 신·구 비교 팝업이 곧 "결과 연출" — 별도 성공/실패 연출 없음(항상 새 값이 나온다)
    ├─ 분해: 획득 재료 합계 결과창
    └─ 제작: 결과물 카드 + "도감 등록" 뱃지(신규 등록 시)
    ▼
[복귀] → 목록으로 자동 복귀, 포커스는 방금 처리한 대상의 다음 슬롯(분해로 사라진 경우) 또는 같은 슬롯
         (강화/재련으로 값만 바뀐 경우) 유지 — `inventory.md`의 "탭·포커스 복원" 원칙과 동일하게 화면을
         나갔다 다시 들어와도 마지막 탭 복원.
```

- **재련 잔여 n/3 상시 표시**: 재련 탭 우측 패널 헤더에 항상 노출(위 §1.2 와이어프레임 참고). 강화/분해/제작
  탭에는 표시하지 않는다(맥락 밖 정보 과다 노출 방지, `wireframes.md` §0 "HUD 최소화" 원칙 연장).
- **실패 천장 없음(D-32)**: 강화 실패가 연속되어도 확률·연출이 전혀 바뀌지 않는다 — UI가 "다음엔 확률이
  오릅니다" 류의 오해를 주는 문구를 넣지 않도록 주의(로컬라이징 검수 포인트로 §5에 메모).

## 7. 로직 계층 인터페이스 — 가정 및 요청 목록

**가정(작업 지시 원문 그대로, M2-4 `scripts/systems/blacksmith.gd`가 제공 예정)**:
`enhance(item_uid)`, `refine(item_uid, line_index)`, `refine_commit(item_uid, line_index, keep_new: bool)`,
`salvage(item_uids: Array)`, `craft(blueprint_id)` + `Events.blacksmith_result`, `blacksmith_opened`,
`mailbox_opened`, `mail_received`, `mail_claimed`, `gold_changed`(이미 존재, `game_state.gd:add_gold()`).

**UI가 추가로 필요로 하는 것 (요청 목록)**:

1. **미리보기(부작용 없는 조회) 함수** — `enhance()`/`refine()` 자체가 재료를 소모하며 실행되는 함수라면,
   버튼을 누르기 *전에* 성공률·비용·다음 단계 스탯을 보여줄 별도 조회 함수가 필요하다. 예:
   `blacksmith.gd`에 `get_enhance_preview(item_uid) -> Dictionary`, `get_refine_cost(item_uid, line_index)
   -> Dictionary`를 추가하거나, UI가 `enhance.json`을 직접 읽어 계산하도록 승인해 달라(후자면
   `blacksmith_ui_calc.gd`가 이미 그 역할이라 로직 함수 추가가 필요 없다 — 승인만 필요).
2. **재련 비용/횟수 차감 시점 확정 API** — `refine()`이 이미 재료를 소모하고 새 옵션을 굴리는지, 아니면
   "굴려서 보여주기"와 "차감하며 확정"이 `refine()`/`refine_commit()`으로 이미 분리돼 있는지 시그니처만으론
   불명확하다. §8 결정 필요 2와 함께 확인 요청.
3. **우편함 수령 API** — 작업 지시의 함수 5개(enhance/refine/refine_commit/salvage/craft)에 우편함 수령이
   없다. `mail_received`/`mail_claimed` 시그널은 있는데 이를 발신할 호출 진입점이 안 보인다 —
   `claim_mail(index)`/`claim_all_mail()`(어느 시스템이 소유할지는 `blacksmith.gd`든 별도
   `mailbox.gd`든 무방, `GameState.mailbox`를 이미 알고 있는 쪽이면 됨)을 요청.
4. **`InventoryUiCalc._enhance_multiplier()` 공개화** — 현재 `private`(밑줄 접두)로 `inventory_menu.gd`
   전용이다. 대장간 강화 미리보기가 같은 `enhance.json.stat_multiplier` 곱연산을 다시 구현하지 않도록
   `static func enhance_multiplier(...)`로 공개 전환 요청(로직 중복 방지, inventory 담당자 확인 필요).
5. **아이템 인스턴스 스키마 확인** — 재련 잔여 횟수(`refine_attempts_used` 등)·잠금(`locked`) 플래그가
   `ItemInstance` Dictionary에 실제로 존재하는지 확인 요청. `locked`는 인벤토리 쪽 남은 이슈로 아직
   미구현(§8 결정 필요 4)이라 분해 탭이 이 필드에 의존한다는 점을 인벤토리 담당자에게도 공유해야 한다.
6. **연출 강도 신규 설정 값** — §4에서 요청한 "화면 플래시 생략" 토글은 `settings.gd`에 필드가 없다.
   `Settings.effect_flash_enabled: bool`(기본 true) 신설 + `Events.settings_changed` 재사용을 요청.
