## 1. 게임 개요

| 항목 | 내용 |
|---|---|
| 가제 | 이슬란드 연대기 (Chronicles of Isleland) |
| 장르 | 오픈월드 액션 RPG (탑다운 2D) |

### 1.1 한 줄 컨셉
> "귀여운 모험가가 되어, 저주에 잠긴 중세 섬나라를 자유롭게 누비며 보물을 파밍하고 성장하는 도트 오픈월드 액션 RPG."

### 1.2 핵심 게임 루프 (Core Loop)
```
탐험 (새 지역 발견)
   ↓
전투 (몬스터 처치 / 던전 공략)
   ↓
파밍 (장비·재료·골드 획득)
   ↓
성장 (레벨업 · 장비 강화 · 스킬 습득)
   ↓
더 깊은 지역 개방 → 다시 탐험
```
- 15분 단위의 짧은 루프(사냥→보상)와 2~3시간 단위의 큰 루프(지역 해방→보스)를 겹쳐 설계한다.
- "저기 뭐가 있지?"라는 호기심이 항상 화면 안에 보이도록 지도 곳곳에 시각적 랜드마크를 배치한다.
- 상세 플로우: `docs/brd/user-flows.md` (온보딩 / 코어 루프 / 파밍·성장 / 던전 / 사망 / 퀘스트 / 경제)

## 2. 세계관 & 스토리

### 2.1 배경 설정
- 무대는 대륙에서 떨어진 중세 섬나라 **이슬란드(Isleland)**. 다섯 개의 지방(초원·숲·설산·사막·화산)이 하나의 심리스 맵으로 이어져 있다.
- 300년 전, 왕국을 지키던 다섯 개의 **수호 성물(聖物)** 이 '재의 마녀'에 의해 흩어지며 땅 곳곳에 **잿빛 안개(저주)** 가 스며들었다.
- 안개에 닿은 생물은 마물로 변한다. 마을들은 성물의 파편이 지키는 좁은 안전지대 안에서만 살아간다.

### 2.2 메인 스토리 (3막 구조)
| 막 | 내용 | 플레이 목표 |
|---|---|---|
| 1막: 출항 | 주인공은 유물 조사단의 견습으로 섬에 도착. **섬 도착 → 첫 마을(민들레 마을) 습격 = 튜토리얼 전투 → 마을 확보** 순서로 진행되며, 습격 중 주인공만이 성물 파편에 반응한다는 사실이 밝혀진다. | 튜토리얼, 첫 던전, 거점 마을 확보 |
| 2막: 다섯 성물 | 다섯 지방에 흩어진 성물을 회수. 각 지방마다 지역 스토리 + 중간 보스(성물의 수호자)가 존재. 자유로운 순서로 공략 가능(권장 전투력만 표시, 입장 제한 없음). | 오픈월드 본편, 파밍·육성의 중심 구간 |
| 3막: 재의 마녀 | 성물이 모이자 드러나는 진실 — 마녀는 과거 왕국의 희생양이었다. 최종 던전 '잿빛 첨탑'에서 엔딩 분기. | 최종 던전, 엔딩 분기, 회차 요소 개방 |

- **엔딩 분기 조건**: 맵에 숨겨진 수집물 **'마녀의 기억' 5개**를 모두 모은 상태로 최종전에 진입하면 진 엔딩, 아니면 노멀 엔딩. 1~2막 대사에 복선을 심고 복선 목록은 `docs/story/foreshadowing.md`로 추적한다.

### 2.3 톤 & 무드
- 겉은 아기자기하고 밝지만, 지역 스토리에는 잔잔한 슬픔과 온기가 있는 "귀엽지만 뭉클한" 서사 지향 (예: 언다인 호수의 잃어버린 노래 퀘스트).
- 대사는 짧고 위트 있게. 긴 컷신 대신 도트 연출(표정 이모지, 말풍선, 소품 애니메이션)로 감정 전달.

## 3. 플레이어블 캐릭터

게임 시작 시 4명 중 1명 선택. 외형·시작 무기·고유 스킬 트리가 다르며, 회차 플레이 유도 요소.

| 캐릭터 | 컨셉 | 주무기 | 전투 스타일 | 고유 메커니즘 |
|---|---|---|---|---|
| 🗡️ 핀 (Fin) | 씩씩한 견습 기사 | 한손검+방패 | 근접 밸런스형 | 저스트 가드 성공 시 반격 '패리 슬래시' |
| 🏹 리라 (Lyra) | 숲 출신 사냥꾼 | 활 | 원거리 기동형 | 구르기 직후 사격이 자동 조준 '헌터 마크' |
| 🔮 모리 (Mori) | 졸린 눈의 견습 마법사 | 지팡이 | 원거리 폭발형 | 서로 다른 속성 마법 2개 연속 적중 시 융합 마법 발동 (**주요 조합 6종**) |
| 🔨 브람 (Bram) | 먹보 드워프 대장장이 | 대형 해머 | 근접 파워형 | 공격 유지 시 3단 차지, **필드에서 간이 제작**(소모품·재료 가공) 가능 |

- 모든 캐릭터는 SD 비율(2.5등신), 유휴 상태에서 하품·두리번거림 등 아기자기한 아이들(idle) 애니메이션 보유.
- 외형 커스터마이즈: 헤어 컬러 8종, 피부톤 6종 + 파밍으로 얻는 코스튬(성능 없는 치장 슬롯 분리).
- 시작 후 외형 변경은 **마을 미용실 NPC에서 골드 지불**로 가능. 캐릭터(직업) 변경은 불가.
- 장비 내구도 시스템은 **도입하지 않는다** (브람의 필드 능력은 '수리'가 아닌 '제작').

## 4. 전투 시스템

### 4.1 기본 조작
| 입력 (키보드·마우스 / 패드) | 액션 |
|---|---|
| WASD / 스틱 | 이동 (8방향) |
| 좌클릭 / X | 기본 공격 (3타 콤보) |
| 우클릭 / ZR | 강공격 / 차지 공격 |
| Space / B | 구르기 (무적시간 0.3초, 스태미나 소모) |
| Q·E / L·R | 스킬 슬롯 1·2 (쿨타임제) |
| Shift / ZL | 가드 — 적중 직전 **6프레임(0.1초, 60fps 기준)** 내 입력 시 저스트 가드 |
| 1~4 / 십자키 | 퀵슬롯 (포션, 투척물, 음식) |
| Tab / −(Select) | 전체 메뉴 (인벤토리·스킬·도감·퀘스트) — 열려 있는 동안 게임 일시정지 |
| Esc / +(Start) | 일시정지·설정 |

- **모바일**: 가상 스틱 + 가상 버튼. 컨트롤러 연결 시 자동 전환.
- 키 리매핑 지원. 모든 프레임 수치는 60fps 기준으로 정의하고 delta 기반으로 구현한다.

### 4.2 전투 설계 원칙
1. **손맛 우선**: 히트스톱(0.05~0.1초), 화면 흔들림, 도트 이펙트, 넉백을 통한 타격감. 모든 공격은 "맞았다"가 눈과 손에 즉시 느껴져야 한다. 데미지 숫자는 **기본 표시**(옵션에서 끔).
2. **읽고 피하는 전투**: 몬스터 공격 전 예고 동작(플래시/바닥 장판 표시) 최소 0.5초. 회피·가드가 항상 유효한 해답이 되도록. 가드 불가 공격은 붉은 예고로 구분.
3. **스태미나 관리**: 구르기·강공격·가드는 스태미나 소모. 무한 회피 방지, 리듬 있는 공수 교대 유도. 완전 고갈 시 회복 딜레이 페널티.
4. **속성 상성**: 화(火)·수(水)·뇌(雷)·풍(風)·성(聖) 5속성. **순환형 상성 — 화→풍→뇌→수→화** (앞이 뒤에 강함), **성은 마물 계열 특효**. 상성 적중 시 데미지 1.5배 + 상태이상(화상=지속 피해 / 빙결=정지 / 감전=행동 중단). 파밍한 무기·부적으로 속성을 세팅하는 재미와 직결. 보스는 상태이상 저항치 보유.

### 4.3 스킬 시스템
- 캐릭터별 스킬 트리 3계열 × 각 6단계, **단계당 노드 2개** (예: 핀 = 검술 / 수호 / 기사도).
- 단계 해금: 이전 단계에 1포인트 이상 투자하면 개방. **레벨 제한 없음**.
- 레벨업 시 스킬 포인트 1 획득, 던전 보물·업적으로 추가 획득. 액티브 스킬은 슬롯 2개에 장착.
- 스킬 리셋·스탯 리셋 모두 마을 사제에게 **레벨 × 100 골드**로 전체 리셋 가능 (빌드 실험을 장려).

## 5. 성장 & 레벨업

### 5.1 경험치와 레벨
- 최대 레벨 50. 몬스터 처치, 퀘스트, 최초 발견(지역·던전·요리 등)으로 경험치 획득.
- 레벨업 시: HP/스태미나/공격력 소폭 자동 상승 + 스킬 포인트 1 + 스탯 포인트 3 + HP 전량 회복.

### 5.2 스탯 (수동 분배)
| 스탯 | 효과 |
|---|---|
| 힘 STR | 물리 공격력, 무거운 무기 요구치 |
| 민첩 DEX | 공격 속도, 회피 스태미나 효율, 원거리 데미지 |
| 지능 INT | 마법 데미지, 스킬 쿨타임 감소 |
| 체력 VIT | 최대 HP, 방어력 |
| 행운 LUK | 아이템 드랍률, 크리티컬 확률 ← **파밍 게임의 핵심 재미 스탯** |

### 5.3 레벨 외 성장 축 (수평 성장)
- **장비 파밍/강화** (6장 참조) — 전투력의 60%는 장비에서 나오도록 설계.
- **요리**: 필드 채집 재료로 요리 → 버프 음식 (예: 매콤 버섯구이 = 10분간 공격력 +8%). **서로 다른 효과 2개까지 동시 적용**, 같은 효과는 대체.
- **수집 도감**: 몬스터/아이템/요리/낚시 도감 완성률 **25 / 50 / 75 / 100%** 달성 시 영구 보너스 스탯.
- **정령 조각**: 맵 곳곳에 숨겨진 수집물 → 4개 모으면 HP 또는 스태미나 최대치 영구 +1칸 (젤다의 코로그/사당 포지션, 탐험 동기의 핵심).

## 6. 아이템 & 파밍 시스템

### 6.1 아이템 등급
| 등급 | 색상 | 획득처 | 비고 |
|---|---|---|---|
| 일반 | 흰색 | 필드 몬스터 | 상점 판매·분해 재료 |
| 고급 | 초록 | 필드·미니 던전 | 접두어 옵션 1개 |
| 희귀 | 파랑 | 던전·정예 몬스터 | 랜덤 옵션 2개 |
| 영웅 | 보라 | 보스·비밀 상자 | 랜덤 옵션 3개 + 고유 효과 |
| 전설 | 주황 | 지역 보스·히든 퀘스트 | 고유 스킬 부여 (예: 검기 발사) |
| 유물 | 붉은 금색 | 회차·최고난도 던전 | 세트 효과, 엔드 콘텐츠용 |

- 색약 모드에서는 등급을 아이콘(●▲◆★✦❖)으로 병기한다.

### 6.2 장비 슬롯 & 인벤토리
- 무기 / 보조(방패·화살통·마도서) / 투구 / 갑옷 / 신발 / 반지×2 / 부적(속성 결정) — 총 8슬롯. **동일 반지 2개 중복 장착 허용**.
- 치장(코스튬) 슬롯은 별도 3개(모자·의상·백팩)로 성능과 완전 분리.
- 인벤토리: 격자형 **기본 40칸**, 파밍으로 얻는 백팩 아이템으로 **최대 80칸** 확장.
- 인벤토리가 가득 찬 상태의 드랍·확정 보상은 **마을 우편함으로 자동 전송** (보관 기한 없음).

### 6.3 랜덤 옵션 (파밍 리플레이성의 핵심)
- 옵션 풀 예시: 공격력 %, 특정 속성 데미지, 크리 확률, 이동속도, 골드 획득량, 스킬 쿨감, 흡혈 등 20종.
- 같은 '철검'이라도 옵션 조합이 달라 "한 번 더 돌자"를 유도.
- **재련 시스템**: 재료+골드로 옵션 1줄 재굴림. 결과는 **신·구 옵션 중 택 1**로 확정하며, 확정 시 횟수 차감(장비당 3회). 극한 파밍과 적당한 타협 모두 허용.

### 6.4 강화 & 제작
- 강화: +0 ~ +10. +6까지 실패 없음, **+7~+10 성공률 70 / 55 / 40 / 25%** (밸런싱 단계 조정 전제). 실패 시 강화석만 소실하고 단계 유지, 장비 파괴 없음 — 캐주얼 톤 유지. 실패 천장(확률 보정)은 두지 않는다.
- 제작: 몬스터 소재 + 광석 + 도면(파밍, 소모되지 않음)으로 대장간 제작. 제작 장비는 동급 드랍보다 기본 스탯이 안정적(드랍 운의 천장 역할). 브람 선택 시 소모품·재료 가공을 필드에서 가능.
- 분해: 미사용 장비 → 강화석·재료로 환원(등급 높을수록 산출 증가). 장착 중·잠금 장비는 제외. 인벤토리 압박을 보상으로 전환.

### 6.5 파밍 콘텐츠 소스
| 콘텐츠 | 리스폰 | 주요 보상 |
|---|---|---|
| 필드 사냥터 | 상시 | 재료, 일반~희귀 장비 |
| 정예 몬스터 (필드 네임드) | 30분 | 희귀~영웅, 도면 |
| 미니 던전 (동굴·유적, 5~10분 규모) | 1일 | 보물상자, 정령 조각 |
| 지역 던전 (30~40분, 퍼즐+보스) | 재입장 자유 | 영웅~전설, 성물 파편 |
| 월드 보스 (지역당 1) | 3일 | 전설 확정 1개 |
| 낚시·채광·채집 | 상시 | 요리 재료, 광석, 희귀 수집물 |
| 보물 지도 (몬스터 드랍) | - | 지도의 X 지점을 찾아 파면 보물 (탐험×파밍 결합) |

- 리스폰 타이머는 **실제 플레이 시간 기준** (오프라인 시간 미포함).
- 첫 클리어 확정 보상과 반복 파밍 보상은 별도 테이블로 구분한다.

## 7. 오픈월드 & 맵 디자인

### 7.1 월드 구조
- **심리스 오픈월드** (지역 간 로딩 없음, 던전 진입 시에만 로딩).
- 전체 크기: 약 400×400 타일 × 5개 지방 (도보 횡단 약 25분 분량).

```
        [설산 프로스트헤임]      난도 ★★★☆
              │
[안개숲 ]──[중앙 초원  ]──[사막 사마르 ]
[엘드우드]  [스타팅 지역]  [    ★★★   ]
  ★★        ★              │
              │          [화산 이그니스]
        [항구도시 브릿지포트]   ★★★★ (최종)
```

### 7.2 지역별 콘셉트
| 지역 | 테마 | 주요 기믹 | 지역 보스 |
|---|---|---|---|
| 중앙 초원 하틀랜드 | 밝은 초원, 시작의 땅 | 튜토리얼, 거점 마을 '민들레 마을' | 거대 슬라임 킹 |
| 안개숲 엘드우드 | 신비로운 숲, 반딧불 | 안개 미로(랜턴 필요), 요정 마을 | 고목 정령 '올드바크' |
| 설산 프로스트헤임 | 눈보라, 온천 마을 | 추위 게이지(방한복·모닥불), 빙판 퍼즐 | 서리 늑대왕 |
| 사막 사마르 | 모래언덕, 오아시스 시장 | 낮/밤 온도차, 모래폭풍, 유사(流沙) | 모래거상 골렘 |
| 화산 이그니스 | 용암, 폐허 요새 | 용암 피하기, 내화 장비 필요 | 재의 드래곤 |

- 기믹 대응 수단(방한복·랜턴·내화 장비)은 해당 지역 진입 전에 파밍·구매로 확보할 수 있어야 한다.
- 기믹 피해로도 **사망할 수 있다** (HP 1에서 멈추는 보호 규칙 없음).

### 7.3 탐험 편의 & 동기 부여
- **시야 랜드마크**: 어디서든 화면에 탑·거목·연기 등 "가보고 싶은 곳"이 1개 이상 보이게 배치.
- **비석**: 워프 비석과 부활 비석은 **동일 오브젝트**. 한 번 상호작용하면 활성화되어 워프 목적지·부활 지점이 된다. 워프는 **무료**, 전투 중 불가.
- **지도**: 방문한 곳만 밝혀지는 안개 지도 + 수동 핀 (**보물/몬스터/채집/낚시/NPC/던전/위험/메모** 8종, 최대 30개). 던전 내부는 방문 구역만 표시하는 미니맵 제공(별도 층 지도 없음).
- **낮/밤 & 날씨**: 게임 내 하루 = **현실 24분**(1분 = 게임 1시간), 여관 숙박으로 아침까지 스킵. 밤에만 출현하는 몬스터·유령 상인, 비 오는 날만 나오는 낚시 어종 등 시간대 파밍 요소.
- **탈것**: 중반부 '통통 조랑말' 획득 (이속 +60%, 탑승 중 전투 불가, 피격 시 하차, 아기자기한 포인트 요소).

### 7.4 마을 & NPC
- 지방마다 거점 마을 1개: 대장간(강화/제작/재련/분해), 상점, 여관(**저장 무료 / 숙박은 유료**: 버프+시간 스킵), 사제(스킬·스탯 리셋), 미용실(외형 변경), 우편함, 게시판(일일 의뢰).
- NPC 호감도: 지역당 3~4명의 주요 NPC. 선물(하루 1회)·퀘스트로 상승, **3단계(지인 → 친구 → 단짝)** 마다 상점 할인 → 전용 코스튬 → 미니 스토리 개방.

### 7.5 퀘스트 시스템
| 유형 | 수주처 | 성격 | 보상 |
|---|---|---|---|
| 메인 퀘스트 | 스토리 진행 자동 등록 | 3막 순차, 포기 불가. 2막 성물 5개는 자유 순서 | 성물 파편, 전설 장비, 스토리 개방 |
| 사이드 퀘스트 | 지역 NPC | 지역 스토리·호감도 중심, 순서 자유 | 장비·도면·코스튬·정령 조각 |
| 일일 의뢰 | 마을 게시판 | 매일 3개, 토벌·납품형 가벼운 파밍 목표 | 골드+재료, 주간 7회 누적 보너스 |

- 일일 의뢰는 **현실(로컬) 자정**에 갱신. 갱신 시점에 완료했지만 미보고한 의뢰는 **24시간 보고 유예**, 미완료분은 소멸. 동시 보유 3개, 포기 시 당일 재수주 불가.
- 퀘스트 로그는 메인/사이드/의뢰 탭으로 구분, 추적 중인 퀘스트는 HUD에 한 줄 표시.
- 퀘스트 데이터는 `game/data/quests/`, 대사는 `game/data/dialogue/` 로컬라이징 key 구조.

## 8. 몬스터 & 보스 디자인

### 8.1 몬스터 설계 기준
- 지역당 일반 몬스터 8~10종 + 정예 2종 + 지역 보스 1종 (총 약 60종).
- 모든 몬스터는 귀여운 실루엣 + 명확한 공격 예고 동작. 처치 시 도감 등록.
- 예시 (초원): 방울 슬라임(분열), 뿔토끼(돌진), 버섯돌이(포자 장판), 고블린 정찰병(호루라기로 증원 호출 — 우선순위 타겟 학습 유도).
- 정예 몬스터는 일반 몬스터의 강화 변종(고유 이름 + 강화 패턴 1개)으로 골격을 재사용한다.

### 8.2 보스 설계 원칙
- 3페이즈 구성(HP 100~66% / 66~33% / 33~0%): 패턴 학습 → 패턴 강화 → 발악(연출 강화).
- 보스마다 "이 지역에서 배운 기믹"을 전투에 재활용 (예: 설산 보스전 중 빙판 미끄러짐).
- 첫 클리어 시 전설 장비 or 성물 파편 확정. 재도전은 주기 리셋 파밍 대상.
- **보스방 앞에는 반드시 체크포인트 비석**을 둔다. 보스전 사망 시 **골드 손실 없이** 그 비석에서 즉시 재도전(보스 HP 초기화). 던전 내 퍼즐·개방된 문 등 **구간 진행도는 사망 후에도 유지**된다.

## 11. UI / UX
- HUD 최소화: HP·스태미나 바(좌상단), 퀵슬롯(하단), 미니맵(우상단, 토글 가능), 추적 퀘스트 한 줄, 보스전 전용 HP바. 요소별 표시/숨김 옵션.
- 인벤토리: 격자형 + 자동 정렬 + 등급 필터. 장비 비교 툴팁(현재 장비와 스탯 증감 화살표). 전체 메뉴가 열려 있는 동안 게임은 **일시정지**.
- 모든 UI는 **게임패드만으로 완주 가능**해야 한다 (Switch 이식 대비). 파괴적 액션(분해 확정)은 홀드 입력으로만.
- 저장: 여관 저장(무료) + 오토세이브(지역 이동/보스 클리어/워프/메인 단계 완료 시), 슬롯 3개.
- 사망: 골드 **5% 손실(상한: 레벨 × 50 골드)** 후 마지막 비석에서 부활. 아이템·경험치 손실 없음. 튜토리얼 구간과 보스전은 골드 페널티 없음 (하드코어 아님, 캐주얼 지향).
- 접근성: 화면 흔들림 강도 4단계(0%는 완전 off), 색약 모드(등급 색상 대체 아이콘), 폰트 크기 2단계, 데미지 숫자 토글, 키 리매핑.
- 화면별 상세 레이아웃: `docs/ui/wireframes.md` (10개 화면).

## 12. 기술 사양 (제안)

| 항목 | 선택 | 이유 |
|---|---|---|
| 엔진 | **Godot 4.x** (대안: Unity 2D) | 2D 특화, 무료, 타일맵·2D 라이팅 내장, 경량 |
| 언어 | GDScript (+ 성능 구간 C#) | 빠른 프로토타이핑 |
| 맵 제작 | LDtk 또는 Tiled | 오픈월드 청크 단위 스트리밍 로드 |
| 데이터 | JSON/CSV 테이블 (아이템·몬스터·드랍) | 기획자가 직접 밸런싱 가능 |
| 저장 | 로컬 JSON 암호화 슬롯 3개 + 슬롯별 오토세이브 | - |
| 도트 툴 | Aseprite | 애니메이션 파이프라인 표준 |

- 오픈월드 구현: 맵을 64×64 타일 청크로 분할, 플레이어 주변 3×3 청크만 활성화(몬스터 AI 포함) — 심리스 유지하면서 성능 확보.
- 드랍 테이블: `몬스터ID → [ (아이템ID, 확률, 수량범위) ]` 구조의 데이터 주도 설계. LUK 스탯은 희귀 등급 가중치에 곱연산.
- 모든 밸런스 수치는 `game/data/` 테이블에서 로드하고 부팅 시 스키마 검증. 코드 하드코딩 금지, 임시 상수는 `game/scripts/tuning.gd` 한 파일에만.
