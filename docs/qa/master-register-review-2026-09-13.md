## 전수 DAG 검사

`master-work-register.md`의 A/B/C/R 작업 행 33개를 읽기 전용 Python으로 추출했다. 각 행의 선행조건 열만 파싱하고 `A06~08`, `R02~05` 같은 범위를 개별 ID로 전개했다. 다른 열·공동명세 참조는 필수 간선에 포함하지 않았다. 등록되지 않은 ID 검사와 모든 선행이 처리된 노드를 반복 제거하는 위상 정렬을 실행했다.

실제 출력: **nodes=33, edges=54, missing=[], cycle_or_blocked=[]**.

위상 정렬 결과:

```text
A00,A01,A06,A07,A08,C01,C06,R04,A02,C02,R01,R02,R05,A03,B01,C03,C07,A04,A09,A10,B04,C04,A05,A11,A12,B02,R03,A13,C05,C08,R06,B03,R07
```

이는 관리표 ID 그래프에 순환이 없다는 검사다. 사용자 승인·도구 확보·실제 제작 가능성을 자동 보증하지 않는다. B03은 T12 첫 데모 검증, R07은 재전직 구현 범위의 별도 회귀 검사로 모두 추적한다.
