# 핀 정면 1차 실행 테스트

2026-09-12 · Godot 4.4.1 · 독립 시험 프로젝트

## 실행 가능 범위

`prototypes/fin-front-test`에서 FHD 렌더, 정면 대기·걷기, WASD/방향키 이동, 발밑 장애물·외곽 충돌, 모션 일시정지·한 프레임 넘기기, 초기화, 자동 앞뒤 이동, 격자·판정 표시를 제공한다. `Launch-Fin-Test.ps1`로 실행한다. 기존 게임 파일이나 세이브를 테스트 상태로 덮어쓰지 않는다.

기본 창은 1280×720로 FHD 렌더를 축소 표시한다. 1920×1080 디스플레이의 전체화면(F11)에서 1:1 확인한다. 캡처 PNG는 실제 렌더된 1920×1080이다.

## 에셋

64×96 정면 후보를 원본으로 사용, 몸체·장비를 포함한 96×128 셀에 배치했다. 걷기는 부위 분리 동작 블로킹으로, 머리43행의 픽셀이 1px 상하 이동을 보정하면 동일함을 자동 검사했다. 8프레임이 서로 다르며 여백 내에 들어간다. 기존 걷기 v1은 미사용. 수작업 최종 키프레임·팔과 망토의 2차 모션·완전한 픽셀 정리가 끝난 것은 아니다.

## 결과

- Godot 에디터 import: 종료 코드0, 독립 프로젝트 정상 로드.
- 사용자용 실행 스크립트 `-SelfTest`: 종료 코드0.
- 자동 검사14개 통과: FHD viewport, 8프레임, 최초 대기, 전진, 걷기 선택, 정지 대기 복귀, 장애물 충돌, 프레임 고정, 위치 초기화, Space 처리, 마침표 처리, R 처리, 외곽 충돌, 정규화 대각 이동 거리.
- OpenGL 실제 렌더 실행 및 화면 저장 성공. 최초 렌더 실행에는 확장 전 검사9개가 포함됐다. 키 검사는 핸들러에 이벤트를 전달한 코드 검사이지 실제 OS 키보드 입력 자동화가 아니다.
- `docs/art/preview/fin-front-test/engine-fhd.png`를 직접 확인: 한글 표시, 패널 겹침 없음, 캐릭터 2배/3배 비교와 장애물 표시 확인.
- `idle-walk.gif`와 `walk-contact-sheet.png` 제공. 정지화면/구조 검사 통과를 모션의 최종 미적 품질 승인으로 간주하지 않는다.

실행 로그는 저장소 상위 `reviews/games-2026-09-12/runtime/fin-front-import.log`, `fin-front-selftest.log`, `fin-front-render-test.log`에 있다. 확장14개 검사는 실행 스크립트 출력에서도 확인했다.

## 남은 작업

사용자가 직접 실행하여 접지·발 미끄러짐·얼굴 선명도를 확인할 수 있다. 정면 검증 후 측면/후면과 전투 모션을 만든다. 현재 모든 방향 입력에서 정면으로 표시되는 것은 명시된 테스트 제한이다. 본 게임 FHD·UI·월드 이관, 몬스터/아이템 적용, 스킬 구현, 20~30분 콘텐츠 데모 완주는 아직 완료하지 않았다.
