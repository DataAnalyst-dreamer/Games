## 먼저 해 볼 것

1. WASD 또는 방향키로 이동하고 테오 근처에서 E를 누릅니다. 수락은 패널의 버튼에서 별도로 합니다. Esc는 패널 닫기입니다.
2. 테오와 대화하고 화물을 조사하여 첫 목표를 진행한 뒤 테오에게 돌아와 완료합니다. 두 번째 의뢰의 안내와 NPC 대화도 확인합니다.
3. 인벤토리의 젤리·뿔·버섯·소형체력물약 아이콘과 설명을 확인합니다. 아이템은 플레이로 획득해야 하며 QA가 주입한 아이템은 플레이 세이브에 넣지 않았습니다. 새 아이콘은 제한적으로 적용된 AI 시안이며 모든 아이템 아트가 교체된 것은 아닙니다.
4. 필요할 때 F5로 **수동 슬롯 0**에 저장하고 F9로 같은 수동 슬롯을 불러옵니다. 시작 화면의 세이브 선택/자동 저장 불러오기 UI는 아직 없습니다. F9는 자동 저장을 불러오는 키가 아닙니다.

게임 창의 닫기 버튼으로 종료합니다. 실행 중 다른 Godot 프로세스를 종료하거나 준비 명령을 동시에 실행하지 마세요. 본 게임의 기존 일시정지·입력 규칙을 그대로 사용하며 별도 강제 전체화면 기능은 추가하지 않았습니다.

## 격리 방식

보유 Godot 실행 파일을 새 폴더로 복사하고 공식 `_sc_` self-contained 모드를 사용합니다. APPDATA/LOCALAPPDATA는 자식프로세스에만 지정하고 부모·전역설정을 바꾸지 않습니다. 실제 `OS.get_user_data_dir()`와 의도 경로가 일치하는지 **autoload 없는 작은 프로젝트로 먼저 확인**하며, 불일치하면 본 게임을 시작하지 않습니다. 준비단계마다 별도새QA사용자공간, 기본Play는 QA와분리한 같은snapshot의 `player-session`을 사용합니다. 복사본에서는 editor 전용 플러그인 활성 목록만 비웁니다. 런타임 autoload·입력·화면 설정은 보존하고, 기록된 staging시험guard/기대키수만 치환합니다. 정상import에서편집할씬은InventoryCell로명시하되실제게임Main설정은유지합니다.

근거: [Godot 4.4 EditorPaths](https://docs.godotengine.org/en/4.4/classes/class_editorpaths.html), [Godot 4.4 Windows 경로 구현](https://github.com/godotengine/godot/blob/4.4-stable/platform/windows/os_windows.cpp). `_sc_`만으로 저장 경로를 추정하지 않고 실제 probe 결과를 사용합니다.
