# 핀 리디자인 — CQ 방향 1차

2026-09-12 · D-136~138 · 시안 검토용. 게임에 적용되는 최종 스프라이트는 T04에서 별도 제작한다.

## 캐릭터

현재 제작 규격: **몸체 64×96, FHD 1920×1080**(D-140 사용자 확정). 이전 32×48 및 48×72 비교안은 제작 기준에서 제외한다. 정면 B를 기준으로 `fin-64-production-spec.md`에 따라 픽셀 정리 후 모션을 제작한다.

씩씩한 견습 기사. 명령대로 정면만 지키다 다른 곳의 위험을 놓쳤던 경험 때문에 먼저 방패를 들고 동료를 지키려 한다(`story/characters.md` 2.1). 이를 걷기 중 두리번거림, 대기 중 방패 손잡이를 다시 쥠, 피격 뒤 바로 자세를 되찾는 동작으로 표현한다.

시안 조형: 얼굴이 보이는 작은 은색 투구와 짧은 붉은 깃털, 따뜻한 황토색 튜닉, 짧은 세이지색 망토, 진한 가죽 부츠. 오른손 짧은 검·왼손 둥근 나무 방패. 2.5~3등신 SD이며 얼굴과 큰 장비의 형태로 캐릭터를 읽는다. 색상은 시안 제안으로, 기존 핀 시안의 그림을 확대·재활용하지 않는다.

## 관찰 기준

후속 진행: 사용자 승인에 따라 코드 기반 투명화·픽셀 정리를 수행했다. 산출물과 검증 결과는 `../qa/fin-postprocess-2026-09-12.md` 참고. 걷기 후보 시트는 생성됐고, 기존 Player 전면 교체와 전용 전투 모션은 아직 수행하지 않았다.

1. 정면에는 얼굴, 후면에는 투구 뒤통수와 망토가 보여야 한다.
2. 좌우 방향을 바꿀 때 장비가 다른 손으로 이동하지 않는다. 단순 전체 좌우 반전은 최종 원화에서 확인한다.
3. 몸·검·방패의 연결이 자연스럽고, 튜닉과 금속의 명암이 구분된다.
4. 필드 축소 상태에서도 투구/깃털·방패·망토 색이 식별된다. 확대 원화만 예쁘면 통과하지 않는다.
5. 준비–타격–회수 실루엣은 서로 다르고, 가드와 공격도 실루엣만으로 구분된다.
6. 디자인 방향 및 64×96 규격 선택과 별개로 픽셀 정렬·알파·프레임 수·엔진 재생을 검사한다.

## 시안 파일·출처

내장 이미지 생성 도구로 신규 시안을 제작했다. 실제 생성 프롬프트는 `fin-cq-concept-prompt.txt`에 보관한다. 원작 CQ의 스프라이트를 입력으로 사용하지 않았다.

- `preview/fin-cq-concept-v1.png`: 외형 콘셉트. 사용자 답변 “현재 시안의 외형으로 진행”으로 승인됨. 은색 투구·붉은 깃털·황토색 튜닉·초록 망토 유지. 1536×1024 일러스트이며 게임용 32×48 스프라이트가 아니다.
- `preview/fin-cq-walk-draft-v1.png`: 승인 시안을 참조한 4방향 × 8프레임 걷기 초안. `fin-cq-walk-prompt.txt`에 프롬프트 보관. 1536×1024, 행 순서 아래/왼쪽/위/오른쪽.
- 초안 검사: 4px 간격 알파 샘플이 모두 255로, 배경의 체크무늬는 실제 투명이 아니다. 고해상도 디테일도 목표 논리 픽셀보다 촘촘하다. 따라서 게임 미적용, T04 미완료. 투명화·축소 가독성·접지·좌우 장비 일관성 검증을 통과해야 반입한다.
- 모든 생성물은 신규 제작 자료이며 기존 외부 에셋의 라이선스를 변경하거나 대체하지 않는다. 특정 생성물의 독점권을 주장하는 기록은 아니다.
- 투명 배경만 추출하도록 내장 도구로 1회 재시도했으나 결과도 4px 간격 샘플 알파가 모두 255였다. `fin-cq-walk-alpha-prompt.txt`에 재시도 프롬프트 보관. 실패한 재시도는 게임에 반입하지 않았다. 후속은 사용자 동의하에 이미지 후처리로 배경 제거·픽셀 규격 정리를 수행하는 방안이며, 캐릭터 내부의 은색 장비가 훼손되지 않는지 별도 검사해야 한다.
