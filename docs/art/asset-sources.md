# 애셋 소싱 정책 & 소스 목록

《이슬란드 연대기》에 사용할 수 있는 외부 애셋의 **라이선스 기준**과, 기준을 통과한 소스 목록. 상용 출시(Steam·Switch·모바일)가 목표이므로 라이선스가 곧 사용 가능 여부다.

## 1. 사용 원칙

| 등급 | 조건 | 저장소 커밋 | 용도 |
|---|---|---|---|
| **A · CC0** | 저작권 포기. 상용·수정·재배포 전부 자유 | 가능 | 프로토타입 + 출시 버전 일부(소품·이펙트·UI·사운드) |
| **B · 상용 허용, 재배포 금지** | 상용 OK, 크레딧 불필요/권장, 파일 재배포·재판매 금지 | **불가** (`.gitignore`, 로컬 `assets_local/`에만) | 프로토타입 + 출시 버전 |
| **C · 조건부** | 카피레프트(CC-BY-SA) 또는 유료 프리미엄 구매 시 상용 가능 | 구매·조건 확인 후 | 캐릭터 대량 확보 시 검토 |
| **✕ · 사용 금지** | 상용 게임에서 추출한 립(rip) 스프라이트, 라이선스 불명 | 절대 불가 | 레퍼런스(프레임 수·비율 연구)로만 |

- **The Spriters Resource 등 립 사이트**: 스프라이트의 저작권이 원 게임사(닌텐도 등)에 있다. 사이트 규정도 상용·배포 프로젝트 사용을 금지한다. 이 프로젝트에서는 아트 바이블의 "레퍼런스 링크"로만 쓰고, 파일 다운로드·트레이싱은 금지한다.
- 외부 애셋은 **프로토타입(M1~M2) 가속 수단**이다. 출시 버전의 캐릭터·주요 몬스터·지역 타일은 아트 바이블(`docs/art/art-bible.md`) 기준의 **원작 도트로 교체**한다 — 여러 팩을 섞으면 화풍이 깨지고, 무료 팩은 다른 게임에도 쓰여 정체성이 희석되기 때문이다.
- 모든 외부 애셋은 `game/assets/third_party/<팩이름>/` 아래에 두고, 각 폴더에 원본 `LICENSE` 파일을 함께 둔다. 집계는 `docs/art/LICENSES.md`.
- 크레딧 불필요라도 **전부 크레딧에 기재**한다(제작자 관례 존중, 분쟁 예방).

## 2. 규격 호환 메모

GDD 아트 스펙은 32×32 타일 / 32×48 캐릭터(640×360 내부 렌더)다. 무료 팩 대부분이 16×16이므로:
- 16×16 팩은 **정수배 2× 확대**로 32×32 월드 단위에 맞춘다. 단 **한 씬 안에서 16px 계열과 32px 계열을 섞지 않는다** (픽셀 밀도가 달라 즉시 티가 남).
- 프로토타입 기간에는 16px 팩(Ninja Adventure 등)을 기준 밀도로 삼고, 원작 아트로 교체할 때 32px 밀도로 올리는 것을 권장한다.

## 4. 확보 절차

1. 다운로드 전 **페이지의 라이선스 문구를 그대로** `docs/art/LICENSES.md`에 복사 (날짜·URL 포함).
2. A등급 → `game/assets/third_party/<팩>/` + `LICENSE` 커밋. B등급 → `game/assets_local/<팩>/`(gitignore) + `LICENSES.md`에 출처만 기록.
3. pixel-artist 에이전트가 `tools/art/`에 규격 변환 스크립트(2× 확대, 시트 슬라이스, 네이밍 규칙 적용)를 두고 `game/assets/sprites/`로 가공본을 생성한다. 가공본도 원본 라이선스를 따른다.
4. 출시 전 체크: `third_party/`·`assets_local/`에 남은 외부 애셋 목록 → 원작 교체 여부 결정 → 크레딧 화면 생성.
