# AI 스프라이트 제작 연결 후보

확인일: 2026-09-13 · 상태: 공식 자료 조사 / 미연결 / 생성 품질 미시험

## 판단

외주 의뢰는 보류한다. **PixelLab의 기존 이미지 기반 8프레임 보행을 첫 기술 실험으로 검토**하고, Scenario는 스타일 변형·배경·아이콘 등 후속 후보, Runway는 영상형 동작 참고의 비교 후보로 둔다. 이는 문서상의 적합도 판단이지 보행 품질 해결 보장이 아니다. 계정 생성·설치·인증·이미지 업로드·생성 API 호출·결제는 수행하지 않았다.

| 비교 | PixelLab — 1순위 | Scenario — 차선 | Runway — 비교용 |
|---|---|---|---|
| 참조 이미지→동작 | 시작 PNG와 동작 설명, 선택적 끝 프레임; 캐릭터 참조 회전 별도 | 기존 asset 참조 및 image-to-video 워크플로 제공. 픽셀 전용 보행 엔드포인트는 이번 범위에서 미확인 | 이미지 URL/data URI와 동작 프롬프트→영상 |
| 64×96 대응 | 문서상 최대 256×256 내 참조 이미지 사용 후보. 정확한 직사각형 반환 크기는 실호출 미검증 | 직접 64×96 애니메이션 미확인. Pixelate는 후처리 효과이며 보행 생성기가 아님 | 직접 64×96 스프라이트 미확인. 문서 예시는 1280×720 영상; 프레임 추출·축소 필요 |
| 투명 | animate_image의 no_background, 투명 입력 유지 명시 | RGBA 마스크 처리 지원과 영상 알파는 별개. 애니메이션 투명 출력 미확인 | 조사한 영상 API 자료에서 투명 스프라이트 출력 미확인 |
| 연결 | 공식 REST API + HTTP MCP, Bearer 토큰 | 공식 REST API + HTTP MCP, OAuth 또는 키/시크릿 | 공식 REST API/SDK 확인. 공식 MCP는 이번 범위에서 미확인 |
| 현재 상태 | 연결되지 않음, 핀 생성 미시험 | 연결되지 않음, 핀 생성 미시험 | 이 조사에서 연결/시험 없음; 플러그인 경로는 별도 검토 |

표의 근거와 제약은 아래 공식 페이지에 한정한다. ‘지원’과 ‘우리 핀으로 검증 완료’를 혼동하지 않는다.

## PixelLab 확인 범위

주의: 캐릭터 생성 문서의 size는 본체가 아닌 전체 캔버스이며, 본체가 캔버스 높이의 약 60%라는 안내가 있다. 64×96을 그대로 size로 지정해 본체 64×96을 얻는다고 가정하지 않는다. 아래는 신규 v3/animate_image 조사이며, 구형 자동 애니메이션 도구의 64×64 제한과 혼합하지 않는다.

[공식 MCP 문서](https://api.pixellab.ai/mcp/docs)는 `animate_image`에 시작 PNG(최대 256×256), 선택적 동일 크기 끝 프레임, 짝수 프레임 수, 투명 입력을 따르는 `no_background`를 명시한다. `get_image`는 프레임 인덱스로 결과를 조회한다. `create_character` v3는 남향 참조에서 8방향을 만들며, size 미지정 시 참조 크기를 따른다고 설명한다. 따라서 64×96 또는 후보 셀 96×128 입력은 **문서상 범위 안의 시험 후보**다. 모든 프레임의 실제 크기·알파·동일성을 측정하기 전 직접 대응을 확정하지 않는다. MCP는 Bearer API 토큰이 필요하다. 결과 다운로드 링크는 UUID가 접근 키 역할을 하므로 공개 공유에 주의한다.

[공식 REST API 개요](https://api.pixellab.ai/v2/docs)는 참조 기반 캐릭터·애니메이션·타일셋을 제공하고 비동기 작업 ID를 반환한다고 설명한다. AI 결과 PNG가 나온다는 것은 관절별 편집 레이어가 있는 Aseprite 원본까지 제공한다는 뜻이 아니다. 레이어/리깅 원본 제공은 미확인이다.

[공식 API 가격표](https://www.pixellab.ai/pixellab-api)의 animate-with-text-v3는 최대 256×256, 최대 16프레임을 명시한다. 예시 추정가는 256×256 8프레임 USD 0.0302, 128×128 16프레임 USD 0.0424다. **64×96 가격이나 MCP 청구액으로 환산하지 않는다.** 가격은 GPU 처리시간에 따라 달라지는 추정치다. PixMiniMax는 별도 모델이며 Tier 1 이상 구독 조건이 명시된다. 기본 API/MCP의 최소 결제·크레딧 구매·구독 포함량은 이번 조사에서 미확인이다. 실제 계정 화면에서 확인하고 지출 상한을 승인받아야 한다.

## Scenario 확인 범위

[공식 MCP 안내](https://help.scenario.com/articles/2664328768-getting-started-with-the-scenario-mcp-server)는 계정과 MCP 호환 클라이언트를 요구한다. OAuth 또는 API 키/시크릿의 Basic 인증을 지원하며 생성에는 Contributor/Owner 또는 쓰기 권한이 필요하다. 참조 asset ID, image-to-video 및 워크플로 실행을 안내한다. MCP도 웹과 같은 팀 Compute Units를 소비하며 배치/영상 전에 dry-run 비용 확인을 권장한다. 최소 유료 플랜·월 요금·우리 작업의 CU는 미확인이다. 공식 문서의 연결 가능 설명은 현재 Codex에 설치됐다는 뜻이 아니다.

[공식 이미지 처리 모델 목록](https://docs.scenario.com/get-started/generation/third-party-model-generation/third-party-model-generation-scenario)의 Pixelate는 축소/확대·색상 보정·팔레트 양자화 효과다. pixelGridSize는 1~512지만 이것을 64×96 프레임별 동작 생성 지원으로 해석해서는 안 된다. [공식 Generate API](https://docs.scenario.com/api/typescript/resources/generate)는 이미지 마스크를 RGBA PNG로 반환하는 옵션을 명시한다. 이것은 영상 전체가 일관된 투명 알파를 가진다는 보장이 아니다. 참조 애니메이션의 정확 입력/출력 크기·프레임 수는 선택할 모델별 추가 확인이 필요하다.

## Runway 확인 범위

[공식 API 시작 안내](https://docs.dev.runwayml.com/guides/using-the-api/)는 이미지 URL 또는 data URI, 프롬프트, 영상 비율과 길이를 입력하는 image-to-video 및 Bearer 인증을 보여 준다. 예시는 1280:720, 5초다. 이는 픽셀 스프라이트 시트나 4방향 보행 납품 규격이 아니다. 영상에서 프레임을 추출해도 발 미끄러짐·형태 변화·배경 제거·팔레트 변화 문제가 남을 수 있으므로 현재 우선순위를 낮춘다.

[공식 API 가격](https://docs.dev.runwayml.com/guides/pricing/)은 1크레딧 USD 0.01, Gen-4.5 초당 12크레딧을 명시한다. 따라서 해당 모델 5초 기본 생성은 60크레딧(USD 0.60) 계산이며 세금·추가 출력 형식·재시도는 별도다. 이는 전체 핀 제작비나 앱 구독 비용이 아니다. 실제 결제 또는 생성은 하지 않았다.

## 승인 후 첫 실험 제안 — 아직 실행하지 않음

1. PixelLab 연결 방법, 인증 주체, 이미지 외부 전송 및 지출 상한을 사용자와 확정한다. 비밀 키는 채팅/문서/저장소에 기록하지 않는다.
2. 승인된 핀 외형에서 실제 픽셀 격자와 알파가 확인된 남향 기준 PNG를 준비한다. 현재 AI 디자인 시트 전체를 곧바로 런타임 스프라이트라고 취급하지 않는다.
3. 한 방향 8프레임 보행만 제한된 횟수로 시험한다. 본체 64×96과 후보 셀 96×128은 구분하고, 반환 크기가 다르면 강제 축소로 성공 처리하지 않는다.
4. 프레임마다 알파·실루엣·발 접지·검/방패 손·투구 동일성·루프 이음새를 검수한다. 흔들기나 신원 변화가 남으면 탈락으로 기록하고 사용자에게 결과를 공유한다.
5. 통과 뒤에만 4방향·공격으로 확대한다. 스프라이트 시트/애니메이션 메타데이터/Godot 적용과 FHD 화면 검수는 별도의 구현 단계다. 전용 픽셀 AI를 연결해도 전체 게임 완성이나 원본 편집 가능성이 자동으로 보장되지 않는다.

공식 주요 자료 8개를 근거로 작성했다. 가입·설치·인증·생성·업로드·결제 및 게임 데이터 변경 없이 조사 문서만 작성했다. 출력물 상업 이용과 공개 GitHub 재배포 조건은 이번 기술 조사와 별도 확인 대상이다.
