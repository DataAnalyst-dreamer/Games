# 핀 64×96 제작 기준

2026-09-12 · D-140 · 규격 선택 완료 / 제작 중

## 확정 사항

- 몸체 작업 영역 64×96. 검·방패와 공격 궤적은 이 영역에 억지로 축소하지 않는다.
- 게임 기준 FHD 1920×1080. 표시 배율 2에서 몸 높이 192px를 첫 검토값으로 사용하며 최종 카메라 줌 확정은 아니다.
- 외형 참조: `preview/fin-resolution/front-64-source.png`; 소형 기준 후보: `preview/fin-resolution/front-64.png`.
- 기존 후보 PNG는 장비 포함 66×96으로, 규격명이 파일 전체 폭 64를 뜻하지 않는다.
- 은색 투구·붉은 깃털·갈색 앞머리·황토 튜닉·초록 망토 유지. 검은 오른손, 방패는 왼손.

## 다음 제작 단위

정면 1프레임의 외곽선, 눈, 투구 홈, 장비 경계를 먼저 정리한다. 독립 생성 프레임을 이어붙이는 방식으로 걷기를 만들지 않는다. 정리된 얼굴·투구·몸통을 공통 기준으로 사용하고 다리·팔·장비·망토의 움직임을 설계한다.

기본 모션 캔버스는 96×128을 작업안으로 둔다. 몸체는 수평 중앙, 발 기준점 (48,112). 이 위치는 패딩 규칙이지 모든 프레임의 최하단을 자동 정렬하라는 뜻이 아니다. 접지 발은 바닥을 지키고, 공중 발과 몸통은 의도된 높이로 움직여야 한다. 공격이 잘리면 별도 캔버스/레이어를 사용한다.

## 정면 걷기 8프레임 설계

| 프레임 | 동작 | 검사 |
|---|---|---|
| 0 | 왼발 접지 | 기준 실루엣과 무게 중심 |
| 1 | 왼발 지지·무게 수용 | 몸통이 작게 내려감 |
| 2 | 오른발 통과 | 지지 발 미끄러짐 없음 |
| 3 | 오른발 전진 | 몸통 복귀, 망토 지연 |
| 4 | 오른발 접지 | 반주기, 얼굴 형태 동일 |
| 5 | 오른발 지지·무게 수용 | 반대 다리 움직임 |
| 6 | 왼발 통과 | 검/방패 손 바뀜 없음 |
| 7 | 왼발 전진 | 0번과 자연스럽게 연결 |

8fps는 첫 재생값이다. 걷는 속도와 보폭을 실제 엔진에서 맞춘다. 머리 형태 변화·무작위 좌우 이동·프레임별 크기 재조정은 허용하지 않는다. 망토만 움직이거나 몸 전체를 좌우 흔드는 것으로 걷기를 대체하지 않는다.

## 완료 기준

- 확대뿐 아니라 FHD 실제 표시 크기에서 얼굴·장비가 읽힌다.
- 투명 여백, 잘림, 원치 않는 마젠타 잔여, 불필요한 색 잡음을 확인한다.
- 정면 정지/걷기 비교에서 같은 캐릭터로 보이고 접지·체중 이동이 읽힌다.
- 엔진에서 정지→걷기→정지와 반복 경계를 확인한 후 다른 방향으로 확장한다.
- 이번 기록은 제작 규격과 작업 순서 확정이며, 정면 픽셀 정리 또는 걷기 제작 완료 보고가 아니다.
