## 아틀라스 정보

생성된 파일:
- **아틀라스 이미지**: `game/assets/sprites/items/item_icons.png`
  - 크기: 272×68 픽셀 (16×16 아이콘 4행 × 16열 + 1px 패딩)
  - 포맷: PNG/RGBA
  - 아이콘당 크기: 16×16 픽셀
- **좌표 매핑**: `game/assets/sprites/items/item_icons_atlas.json`
  - 아이템 ID → {x, y, w, h} 좌표 매핑

## Fallback(대체 아이콘) 필요 여부

**0개 — 모든 아이템이 완전 배정됨**

- 장신구(ring, amulet)·방어구(head, armor, boots) 대표 아이콘 × 각 카테고리별 1개 사용
  → 동일한 아이콘으로 표시되나, 이는 게임 기본 설정상 카테고리별 placeholder 로직을 따르는 것으로 의도된 것 (item_drop.gd 원설계)
- 향후 개별 아이콘이 필요하면 M3 단계에서 pixel-artist 원작으로 교체 예정

## 재빌드 방법

아이콘 추가/변경 시:

```bash
cd /home/user/Games
python3 tools/art/build_item_icon_sheet.py
```

- `game/data/item_icons.json`을 수정 후 위 스크립트 실행
- 아틀라스와 좌표 JSON이 자동 재생성됨
- 스크립트는 재실행 가능 (증분 빌드 아님, 매번 전체 재생성)
