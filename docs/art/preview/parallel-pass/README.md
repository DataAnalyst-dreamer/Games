## 뿔토끼 v2 마무리 조건

- 밝고 어두운 실제 게임 배경에서 윤곽의 색 잔여·거의 투명한 픽셀을 확인한다. 본체 다수가 alpha253/254인 점을 포함해 최종 알파 정책을 정한다.
- 기존 핀64×96 몸체와 나란히 표시하여 귀 포함 상대크기·탑다운 시점·가림을 확인한다. 현재1254 원본을 단순 축소한 결과를 완성으로 간주하지 않는다.
- 최종 격자·피벗·프레임 여백·방향·모션·판정은 별도 제작 및 엔진 검증 대상이다. v2는 배경 추출 결과만이며 이 조건들은 아직 미완료다.

## 핀 진행 보류 사유

이번 접지 시안 한 장으로 자연스러운 움직임을 입증할 수 없다. 기존의 잘라낸 다리 압축·사각형 골반 덧대기는 사용 중단한다. 다음 제작에서는 기준 얼굴·투구를 고정한 편집 가능한 픽셀 원본에서 골반–무릎–발목이 이어지는 네 핵심 포즈를 **직접 편집**해야 한다. 독립 생성 포즈를 정렬만 해서 완성 보행으로 납품하지 않는다. 4포즈 실루엣/체중 이동 검수 후에만 중간 프레임·8fps 반복·FHD 게임 검사로 진행한다.

현재 제공 환경에서 완성 수작업 스프라이트 품질이 확보되었다고 주장하지 않는다. 정확한 픽셀 편집 원본 확보 또는 전문 픽셀 아티스트 제작으로 전환해야 할 경우, 사용자에게 작업 방식/비용 선택을 요청한 뒤 진행한다.

확인한 기준 원본은 [정면 PNG](../fin-resolution/front-64-source.png), 파생 시안은 [접지 A PNG](fin/contact-a-v1.png)다. 프로젝트 자체 제작 영역에서 핀의 레이어·프레임이 있는 `.ase`/`.aseprite` 원본은 찾지 못했다(외부 팩 파일은 핀 편집 원본으로 간주하지 않음). 현재 대화의 네이티브 앱 제어는 비활성화되어 있어 Aseprite UI를 직접 조작해 그리는 경로도 사용할 수 없다. **편집 도구를 설치하는 것만으로 손그림·접지 설계·애니메이션 품질이 자동 완성되지는 않는다.**

필요한 결정은 새 그림 양산이 아니라, 편집 가능한 핀 원본을 사용자/제작자가 제공할지 또는 전문 제작으로 원본·핵심 포즈를 만들지에 관한 작업 경로다. 이 문서는 구매·설치·외주를 승인하거나 실행하지 않는다. 원본과 제작 방식이 정해지기 전에는 핀 수작업 보행을 완료했다고 보고하지 않는다.
