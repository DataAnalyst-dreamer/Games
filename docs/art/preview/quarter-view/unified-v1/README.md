## 알파 읽기 검사

System.Drawing의 읽기 전용 픽셀 순회. `bbox=[x,y,width,height]`이며 alpha>0과 alpha≥128을 구분한다. 후자는 표시 크기 참고용 주요 실루엣일 뿐 픽셀 삭제·불투명도 수정은 수행하지 않았다. 처음 C# 검사 보조 코드의 GDI+ assembly 참조 누락 실행은 실패(결과 없음); 참조를 보완한 순회에서 아래 결과를 얻었다.
