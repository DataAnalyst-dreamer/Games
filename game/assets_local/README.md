# assets_local — 재배포 금지 애셋 보관함 (git 제외)

`docs/art/asset-sources.md`의 **B등급**(상용 허용, 재배포·재판매 금지) 애셋은 이 폴더에 둔다. 내용물은 `.gitignore`로 커밋되지 않으며, 팀원은 각자 원 배포처에서 직접 다운로드해 같은 경로에 넣는다.

| 폴더 | 팩 | 출처 |
|---|---|---|
| `cainos/basic/` | Pixel Art Top Down – Basic v1.2.3 (32×32) | https://cainos.itch.io/pixel-art-top-down-basic |
| `pixel_crawler/` | Pixel Crawler – Free Pack 2.11 (Anokolisa) | https://anokolisa.itch.io/free-pixel-art-asset-pack-topdown-tileset-rpg-16x16-sprites |

각 팩의 라이선스는 `docs/art/LICENSES.md`에 기록되어 있다.
