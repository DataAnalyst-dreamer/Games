# assets_local — 재배포 금지 애셋 보관함 (git 제외)

`docs/art/asset-sources.md`의 **B등급**(상용 허용, 재배포·재판매 금지) 애셋은 이 폴더에 둔다. 내용물은 `.gitignore`로 커밋되지 않으며, 팀원은 각자 원 배포처에서 직접 다운로드한다.

- `cainos/` — Pixel Art Top Down – Basic / Village (32×32)
- 그 외 B등급 팩은 팩 이름으로 하위 폴더 생성

각 팩의 출처·라이선스는 반드시 `docs/art/LICENSES.md`에 기록한다.
